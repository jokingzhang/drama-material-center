# 《限时婚约：霍总的对家前妻》剧本大纲

（适配竖屏短剧·60集体量·全室内场景·适配MiniMax H3制作）

## 一、核心设定

- **核心标签**：双强契约婚姻+职场对家+先婚后爱+成年人拉扯
- **故事背景**：现代都市互联网科技圈，全程聚焦办公室、公寓、商务餐厅等室内场景，无大场面、无多人群戏，制作成本可控
- **核心钩子**：谈判桌上死磕三个月的对家上司，转头成了自己的契约老公；上班是针锋相对的竞争对手，回家是客气疏离的合约室友

## 二、人物小传

### 女主：江砚秋（28岁）

云智科技高级产品总监，业内公认的“铁娘子”。业务能力顶尖，独立清醒，原则性极强，信奉“工作和感情绝对分开”。主导的AI养老项目卡在男主公司的算法授权上，三个月谈判无果，项目濒临被砍。 接受契约婚姻的理由：用一年婚姻换男主公司的独家算法授权，保住自己的项目和团队，同时躲开家里无休止的催婚。

### 男主：霍景深（30岁）

星途科技创始人兼CEO，技术出身的禁欲系大佬。行事果决克制，情绪稳定，没有传统霸总的油腻强制，做一切事都讲究“等价交换”。 提出契约婚姻的理由：奶奶立下遗嘱，他必须在30岁生日前登记结婚，才能保住公司的绝对控股权，否则股权将被稀释，公司控制权旁落。他不信爱情，也不想随便找人结婚，选中江砚秋是因为她足够理性、边界感强，不会假戏真做缠上自己。

### 配角（控制出场人数，同框不超3人）

- **林特助**：男主专属特助，全剧最强助攻，知道契约内情，负责给男主递台阶、打掩护。
- **夏淼**：女主闺蜜兼下属，活泼话痨，不知道契约，一直撮合女主和男二。
- **沈亦辰**：男二，女主的大学学长、公司技术总监，温润儒雅，暗恋女主多年，男主的头号情敌。
- **霍奶奶**：男主奶奶，表面慈祥，实则心里门儿清，是推动两人感情的关键人物。

## 三、分集阶段大纲

### 第一阶段：契约签订，尴尬同居（第1-15集）

**核心看点**：强冲突开局，快速进入同居正题，主打成年人的清醒拉扯与初次暧昧

1. **第1-3集 谈判桌上的求婚** 江砚秋带着团队第三次去星途科技谈算法授权，被霍景深当场驳回。散会后霍景深单独留下她，直接甩出一份结婚协议：“和我结婚一年，授权我立刻签。”江砚秋震惊，以为对方在羞辱自己，愤然离场。 结尾钩子：江砚秋刚回到公司，就收到项目即将被砍掉的通知。
2. **第4-7集 等价交换，领证结婚** 江砚秋权衡再三，主动找到霍景深，逐条修改婚姻协议，定下“互不干涉私生活、职场公平竞争、不同房、对外保密”等约法三章。两人签完协议，第二天直接去民政局领证，全程零交流，领完证各自回公司上班。 名场面：领证出门，两人同时接到工作电话，一个往左一个往右，像两个拼单领证的陌生人。
3. **第8-12集 契约同居，初次磨合** 霍奶奶要求孙媳妇搬进来住，霍景深让江砚秋搬进自己的大平层。两人划分生活区域，定好作息时间表，吃饭、出门全错开，尽量不碰面。第一次一起吃晚饭，全程只有餐具碰撞的声音，尴尬到极致。 小糖点：江砚秋半夜加班忘了吃饭，厨房多了一份温着的三明治，霍景深说是阿姨做的。
4. **第13-15集 第一次查岗，被迫亲密** 霍奶奶突然打视频查岗，两人被迫挤在一个沙发上，霍景深自然地揽住江砚秋的肩，对着镜头语气柔和。挂了视频两人立刻弹开，气氛微妙。 结尾钩子：江砚秋发现，自己的项目组下周要和星途科技在同一个竞标会上正面竞争。

### 第二阶段：职场交锋，暗生情愫（第16-35集）

**核心看点**：职场互斗+私下关心双线并行，拉扯感拉满，细节糖密集

1. **第16-20集 竞标场上的手下留情** 竞标会上，江砚秋的方案被对手公司恶意针对，霍景深作为评委之一，看似中立，实则一句话点破对手方案的漏洞，间接帮了江砚秋。江砚秋事后去道谢，霍景深冷淡回应：“我只是说实话，不是帮你。” 同居细节：江砚秋熬夜改方案，霍景深书房的灯也一直亮到她关灯。
2. **第21-25集 酒局挡酒，醋意初现** 行业晚宴，江砚秋被客户灌酒，沈亦辰正要上前，霍景深先一步走过来，自然地拿过江砚秋的酒杯：“她酒精过敏，我替她。”全场震惊，都以为两人不和。 回家路上，霍景深冷着脸说：“别在外面喝酒，影响我霍太太的名声。”江砚秋第一次觉得，这个冰山好像没那么冷。
3. **第26-30集 奶奶突袭，假扮恩爱** 霍奶奶突然上门住两天，两人被迫开启“模范夫妻”模式：一起做饭、饭后散步、睡同一个房间（打地铺）。奶奶故意制造各种肢体接触机会，两人从僵硬别扭到慢慢自然。 名场面：下雨打雷，江砚秋从小怕雷，迷迷糊糊往床边靠，霍景深没推开，默默守了她半宿。
4. **第31-35集 情敌出现，男主破防** 沈亦辰送江砚秋回家，被霍景深撞见。霍景深全程冷脸，第一次打破契约规则，质问江砚秋“契约期间能不能注意影响”。江砚秋觉得他越界，两人第一次吵架。 转折：江砚秋发烧病倒，霍景深推掉所有会议在家照顾她，笨手笨脚地煮粥、量体温，嘴硬说是怕她传染给自己。

### 第三阶段：假戏真做，危机来袭（第36-50集）

**核心看点**：打破契约边界，确认心意，外部危机考验感情

1. **第36-40集 意外之吻，心意渐明** 江砚秋病好后，为了感谢霍景深，亲自下厨做饭。两人喝了点红酒，气氛暧昧，不小心碰在一起接吻。吻完两人都愣住，江砚秋慌乱躲回房间。 接下来几天两人刻意回避对方，却又忍不住关注彼此，都意识到自己动了真心。
2. **第41-45集 职场联手，共同破局** 有第三方公司恶意窃取两家公司的技术，同时抹黑江砚秋和霍景深，造谣两人权色交易。两人暂时放下竞争，私下联手调查真相，过程中默契十足，感情迅速升温。 名场面：发布会上，霍景深当众拿出证据，还江砚秋清白，公开表示“江总监是我很尊重的对手”。
3. **第46-50集 契约暴露，信任危机** 两人契约婚姻的文件被人泄露到网上，瞬间引发轩然大波。江砚秋被质疑靠婚姻换资源，项目被叫停；霍景深也面临董事会问责。 高潮点：霍奶奶找到江砚秋，告诉她其实自己早就知道是契约，问她“你现在对他，还是只有契约吗”。江砚秋第一次直面自己的感情。

### 第四阶段：双向奔赴，圆满收官（第51-60集）

**核心看点**：男主主动追妻，契约变真爱，甜宠收尾

1. **第51-55集 霍总追妻，契约作废** 霍景深在董事会上主动承担所有责任，保住了江砚秋的项目，同时公开表示：“契约是我提的，但我早就后悔了。我想和她做真夫妻。” 霍景深开始正式追江砚秋：送早餐、接下班、陪她加班，把当年没做过的追求流程全补了一遍，笨拙又真诚。
2. **第56-58集 双向确认，并肩同行** 江砚秋的项目大获成功，庆功宴上，霍景深当众求婚，拿出一份新的协议——“终身恋爱协议”，没有期限，只有爱意。江砚秋笑着答应。 名场面：两人回到公寓，把当初的契约书撕掉，正式开始同居恋爱生活。
3. **第59-60集 一年期满，余生为期** 一年契约到期，两人补办了小型婚礼，只有家人和朋友参加。结尾镜头落在两人牵手的背影上，配旁白：“本来是限时一年的婚约，没想到成了余生的起点。” 结尾彩蛋：一年后，江砚秋怀孕，霍景深从冰山老板变成了老婆奴，反差感拉满。

## 四、适配MiniMax H3制作说明

1. **场景高度集中**：全剧核心场景仅5个——男主公寓（客厅/厨房/书房）、男主办公室、女主办公室、会议室、商务餐厅，全部为室内小场景，生成稳定性极高。
2. **人物同框精简**：90%戏份为男女主双人对手戏，配角单集出场不超过2人，同框人数最高3人，完美规避多人同框崩坏问题。
3. **戏份以情绪为主**：核心看点是眼神拉扯、微表情变化、小幅度肢体互动，无大动作、无跑跳打斗，完全踩中H3近景表现力优势。
4. **造型固定易复用**：男女主造型以职场西装、居家休闲装为主，固定3-4套造型，角色资产一次锁定后全剧复用，一致性强。
