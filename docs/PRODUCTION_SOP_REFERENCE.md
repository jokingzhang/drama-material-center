本文档是 [短剧制作 SOP](../PRODUCTION_SOP.md) 的细则与历史说明补充，按需查阅，不要求每次开工通读全文。主流程、硬红线与必跑脚本以主 SOP 和 [AGENTS.md](../AGENTS.md) 为准。

## 1. 专项 Skill 路由表

用户只需说明剧情、想达到的感受和想法，不必报出专项 Skill 名称。SOP 管执行顺序和边界，`script-writer` 调度剧本写作，`ai-director` 调度分镜与图片素材；专项 Skill 解决具体创作问题，知识库从 [三个问题域入口](../director-knowledge-base/README.md) 按需查阅。

| 当前问题 | 使用方法 | 不额外增加的工作 |
| --- | --- | --- |
| 故事核心、人物动机、结构或场景推进不成立 | [script-writer](../.agents/skills/script-writer/SKILL.md) 按需选 `sw-premise-theme` / `sw-character-conflict` / `sw-story-structure` / `sw-scene-craft` | 不重写已经确定且未受影响的剧情 |
| 创建、修改或诊断对白 | [script-writer](../.agents/skills/script-writer/SKILL.md) 按需调用 [sw-dialogue](../.agents/skills/sw-dialogue/SKILL.md) | 不为口语化强加口头禅或新事实；导演只借演法，不改已确认台词 |
| 新人物外形、脸型区分、新造型或标准图一致性 | [人物外形设计](../.agents/skills/character-visual-designer/SKILL.md) | 换装保留已确认身份，不默认追加定妆照或多套候选图 |
| 新女性角色从图库选脸或指定 RuiC 人像 ID | [女性角色图库选型](../.agents/skills/ruic-character-reference/SKILL.md)，衔接人物外形设计 | 元数据筛选后实际看图；只导入选中原图，不重挑已接受身份 |
| 整场信息、节奏、切点和生成单元 | [叙事短片导演分镜](../.agents/skills/jimeng-narrative-director/SKILL.md) | 不默认每句话拆一个视频节点 |
| 构图、景深、光影、材质与相机选择 | [摄影与光影设计](../.agents/skills/cinematography-director/SKILL.md) | 不因选构图就补关键帧，不把每镜移动当成电影感 |
| 指定八种电影镜头（推拉变焦、环绕等） | [八种电影镜头提示词](../.agents/skills/cinematic-camera-prompts/SKILL.md) | 只选相关机制，保留四字段格式；不复制教程剧情或固定参数 |
| 人声、环境／动作声、跨镜声音和配乐 | [声音与配乐设计](../.agents/skills/sound-music-director/SKILL.md) | 不逐节点随机配乐，不默认新增音色或选音实验 |
| 连续动作、跟随或空间揭示 | [电影级长镜头](../.agents/skills/jimeng-cinematic-long-take/SKILL.md) | 不把未验证的两段拼接叫作一镜到底 |
| 脸红、克制、停顿、忍笑等局部表演 | [AI演员微表情导演](../.agents/skills/jimeng-micro-expression-director/SKILL.md) | 已有明确方向时不再要求用户多选一轮试戏方案 |
| 相邻镜头接得生硬或需设计转场 | [AI 视频转场导演](../.agents/skills/video-transition-director/SKILL.md) | 先修两端状态和剪辑点，不用特效掩盖错人、错空间或错道具 |
| 快速试机位、走位、节拍或白模平替 | [像素白模预演](../.agents/skills/pixel-previs/SKILL.md) | 内部预演不自动作为模型输入 |
| 检查真实三维边界、接触或道具几何 | [Blender 白模](../.agents/skills/blender/SKILL.md) | 只做必要局部，不给普通对白配白模，不做四肢精修 |
| LibTV 能力查询、节点、引用、运行、下载 | 已安装的 `libtv-cli` Skill 及当前 CLI 帮助 | 工具执行不代替故事和导演判断 |

## 2. 导演设计、接镜与多人空间细则

### 2.1 连续性组接三种做法

- **改变景别或角度**：用有动机的视点变化承接说听、反应或信息，避免把两个近似机位但姿势曝光不一致的片段硬接成假长镜头。
- **在动作中接**：跨镜延续动作时，前后素材保留短重叠覆盖，下一镜从相容动作阶段继续；剪辑只留一次动作，素材总时长与剪后净时长分别核算。跨门、递物等动作的接触到完成必须可追踪。
- **按剧情阶段组接**：一个生成单元可含多个真实镜头；只有容量、输入兼容性（如不同视角背景冲突）、叙事段落或复杂任务隔离需要时才拆单元，不为凑旧编号或模板秒数拆段。

### 2.2 空间与动作因果核对维度

对存在空间、接触、道具变化或接镜风险的单元，在分镜中写清：

| 维度 | 检查要点 |
| --- | --- |
| 起始与完成状态 | 谁在哪里、穿什么、拿什么；结束时谁及道具到哪里 |
| 空间与机位 | 先定房间地标、摄影机物理侧与可见边界，再推导画左／画右；切镜不凭空交换区域 |
| 动作因果 | 接触前 → 接触 → 转换中 → 完成后；关键动作与完成态在构图内可见 |
| 人物路线与道具路径 | 分开描述人走哪里、道具在哪里、何时易主，不混为一根抽象箭头 |
| 相邻片段 | 选定的景别／角度变化、动作重叠或声桥如何接住上段 |
| 跨场／跨集状态 | 门开合、证据摆放、服装归属等何时建立、持续或撤销；未定后续标未知 |

### 2.3 情绪转折与抽象词落地

- **抽象词必须落到可见机制**：“心软、愤怒、紧张、电影感、缓慢推近”等可保留为意图，但正文必须同时写出可见身体反应（呼吸、肌肉、手势、视线）或相机机制（起始物理侧、路径、速度、落点）。
- **情绪余波**：有实际情绪转折时按 `触发 → 可见身体反应 → 台词或动作峰值 → 残留／回收状态` 展开；台词结束不能让身体与视线无因归零（戛然而止、主动伪装或外力打断须写明中断机制）。

### 2.4 俯视站位与镜头调度图的演进与边界

- **2026-11-23 最新决定（当前生效）**：用户明确指出站位与运镜调度图的核心价值是**辅助导演在设计分镜时想清空间布局、座次、轴线、机位与背景选型**，对视频生成模型参考意义不大，因此**默认仅作导演内部排演工具**，存于 `创作记录/<agent>/空间调度/<run-id>/`，**生成视频时不裁切上传，也不绑进 `referencePlan` 或视频节点**（不占参考位）。
- 仅当用户针对特定高难度空间调度镜头明确要求将裁切后的单阶段调度图作为视频参考时，才允许例外接入（校验脚本可传 `--allow-blocking-binding` 放行），且仍须遵守“逐单元裁切、不整张投入跨单元总览、不替代基础场景/人物/道具参考”原则。
- 历史已验收或已建画布的早期剧集（如 EP45–46）保留原样，不追溯重跑。

## 3. 生图工具路由依据与特殊规则

### 3.1 历史实测与演进记录

- **2026-09-23**：两轮实测确立 `imagegen` 与 `libtv-cli` → Lib Image（`high / 4K`）的用途分工，实测依据见 [生图工具选择与实测结论](../director-knowledge-base/图片素材/生图工具选择与实测结论.md)。
- **2026-10-25**：人物标准图新制默认版式确定为 3:4 竖版四宫格（左上正面胸像、右上四分之三侧胸像、左下全身背面、右下全身正面，浅灰中性背景、柔和均匀光，无文字边框），见 [人物标准图](../director-knowledge-base/图片素材/人物标准图.md)。已有可用人物图不追溯重做。
- **2026-11-04**：所有角色的人物形象与标准图统一默认走内置 `imagegen`（不再按主配角切 Lib Image），用户明确指定 LibTV 时经官方 `libtv-cli` 调用。
- **2026-11-23**：① 同一场景基于已验收母版派生的分视角场景图，统一归口 `libtv-cli` → **Lib Image**（`image2image`，`high / 4K`，参考母版图），保证同场景多视角建筑、材质、光向与分辨率一致；② 经 EP47 实战验证，即使是 9:16 竖屏短剧，**场景背景参考图（含母版与派生视角图）也统一使用 16:9 横版大图，不用 9:16 竖屏局部图**，避免把多人戏的长桌纵深与座次锚点切丢（场景图比例不改变剧级 9:16 视频画幅锁）。

### 3.2 纯文生、图生图与昼夜对位

- **纯文生限制**：用户要求纯文生时，`imagegen` 不传参考图，`Lib Image` 使用文生图模式并核实无图片媒体与入边，不得偷偷传入原图或上一张生成图。
- **昼夜成对与多视角派生**：两次独立文生图必然漂移建筑结构。同一场景需要严格对位昼夜版本或不同机位视角时，必须基于已确认母版做有约束的参考图生图/编辑，并逐项核对固定地标与光向。
- **像素与清晰度检查**：`4K` 是请求档位，下载后必须记录真实像素尺寸并放大原图核对皮肤、发丝、衣料与四视图一致性。含中文文字的图片须在提示词中逐字写全正文、数字与单位，生成后打开原图逐字核验（OCR 仅辅助）。

### 3.3 关键帧例外写法（仅用户明确审核通过时适用）

默认不使用关键帧（含关系帧、首尾帧、视频尾帧截图）。仅当静态关系是主要风险且已展示实际候选图并获用户针对该版本和用途的明确审核后：

1. **摘要下增加 `**接镜资产：**`**，写明获批帧、来源单元/时间点、适用镜头、首帧/尾帧/关系用途与继承要素（站位、朝向、机位）。
2. **保留基础参考**：人物、环境、道具各自保留，覆盖后续镜头新出现的人物、机位与道具；禁止仅绑一张接镜帧跑剧情视频。
3. **入口核实**：首尾帧模式若只支持端点图，沿用混合参考方式并写清约束职责；要求硬锁首帧像素时先核实模型同时支持硬首帧与辅助图。

## 4. 视频提示词格式与历史兼容

- **现行标准**：新写或语义修改统一使用 [video-shot-prompt-v2](../.agents/skills/doubao-creative-studio/assets/templates/video-shot-prompt-v2.md)（`format: "single-level-shots-lighting"`）：
  - 一行加粗摘要（总时长｜画幅｜声音约束｜地点时间）；
  - 资产分类（按需列出 `接镜资产`、`人物资产`、`环境资产`、`物品资产`、`声音资产`，缺某类就省略整栏，不写“无/不适用”）；
  - `[整体场景与氛围]`（全场布局起点、情绪基调、物理光源与方向、材质与有因环境动态）；
  - `【多分镜时间轴】`：每镜标题 `### 0.0s–2.0s｜镜头1：镜头标题`（从 `0.0s` 累计连续覆盖，不归零、不重叠、不越界），下方固定四字段：`**景别与镜头运动：**`、`**画面与动作：**`（内按需用普通段落“构图与主体：”“道具布局：”“动作与表演：”）、`**光影表现：**`、`**音效：**`。
  - 镜内禁止再列秒数节拍、子镜头或对白时间表。
- **历史格式**：旧三字段 `single-level-shots`、`timedBeats: true` 仅供历史稿回查，不再用于新写或语义返修；已审正文的纯上传/Node 等价替换不为格式变化重写。详见 [镜头块规范](../.agents/skills/ai-director/references/shot-block-format.md)。

## 5. 失败现象与分层返修速查表

| 现象 | 下一步 |
| --- | --- |
| 提交失败或通用平台错误 | 保留任务号和报错，先核对实时约束、累计音频/参考量与残留引用；不原样盲目重提 |
| 提交结果未知、等待中或用户暂停 | 先查已有任务避免重复提交；遵守暂停边界，不擅自重跑或承诺已取消 |
| 节点多个引用字段不一致 | 恢复同一已检查输入并回读；无法可靠修复则在授权内建干净新版节点，保留旧节点 |
| 动作方向或道具因果反复失败 | 查空间、机位、顺序动作容量与参考状态；先修设计/输入或拆复杂动作，不堆负面词 |
| 单条可看，连起来跳色/跳姿/断动作 | 连看接点窗口，改有动机的景别/角度切换或动作重叠，不把近似构图硬接成假长镜头 |
| 脸红/说话/拿物主体错误 | 对照剧本用规范全名明确动作与听者反应，修受影响片段及接镜，不改剧情迁就错片 |
| 全局音色、造型、模型或映射错误 | 暂停尚未运行的受影响下游，修共同根因并复查消费者；无关片段继续 |
| 特殊运镜或转场未实现 | 对照预定成功标志看原片，调整运动/输入方案或生成+后期分工，不靠叠技巧名重试 |
| 微小表演、时间或审美偏差 | 记非阻塞备注，满足当前用途即止；不追加付费生成 |

## 6. 媒体验收与交付细则

- **下载无水印原链**：按 `AGENTS.md` 使用当前账号支持无水印原链的 CLI 参数下载，核对完整解码并人工查看四角；出现任何平台 Logo/AI 生成角标直接 `REJECTED_WATERMARKED`，严禁用裁切/模糊掩盖。
- **完整看听与状态转换窗口**：每条选片正常速完整播放试听；开门、递物、贴线、戴手铐等状态变化加查接触前→接触→转换中→完成后的连续密集帧，不能只看首中尾三帧。
- **相邻接镜连看**：按播放顺序用实际入出点（去掉重叠动作后）连看接点，单条通过不等于组接通过。
- **三级验收标准**：
  - `HARD_REJECT`：错人/错造型、人数错、动作主体反、跨错边界、道具凭空变、明显穿模、改变剧情的错词、损坏、水印或违反硬约束 → 标时间点与影响，阻断进剪辑并局部返修。
  - `PASS_WITH_NOTES`：故事、关系和剪辑成立，仅有不影响叙事的小偏差 → 可继续，不自动提升为人工 `ACCEPTED`。
  - `OPTIONAL_POLISH`：厘米级站位、理想表情等纯审美精修 → 无明确要求不阻塞、不重跑。
- **顺序打包交付**：每集/每批集中复制到版本化交付目录，按剧情播放顺序命名为 `1-原文件名.mp4`、`2-原文件名.mp4`……（编号不补零，保留原主体与版本号），映射与 SHA-256 留存生产记录；交付报告严格分开说明：**正式成果与本地接入 / 运行证据 / 实际看听与接镜覆盖 / 未完成项 / 人工接受状态**。
