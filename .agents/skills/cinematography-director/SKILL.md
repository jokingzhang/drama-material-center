# 摄影与光影设计

由当前主会话执行，可由 [ai-director](../ai-director/SKILL.md) 调用，也可独立用于已明确的镜头。叙事分镜决定信息顺序，本技能决定观众站在哪里、看清什么、光怎样塑造可见主体；连续体验需要专门路径设计时再用长镜头技能。

## 进入条件与输入

新写整场分镜时，在确定观看目的后使用本技能完成相关摄影选择，不必等用户说“构图”或发现画面失败。只改音频、节点绑定或复用已检查镜头时不重做摄影。

恢复本场目的、项目画幅、当前人物造型、地点与光源、关键动作和已有参考。先实际看图；尚无图片时写明设计假设和待核对内容，不编造场景母版中存在某扇窗、灯或通道。不能为一个构图改变确认剧情、隐藏必要动作或挪走已锁定空间地标。

## 从观看目的到摄影决定

1. **确定画面必须同时交代什么。** 是人物判断、双方关系、手与物的接触，还是前后景的信息差？据此选景别和机位。微表情看不清就调整可见尺度；手部承担剧情时不能用裁掉手的特写替代完整动作。
2. **用位置和遮挡表达关系。** 确定摄影机物理侧、人物相对位置、视线对象、前后景和运动出口，再写画左／画右。居中、留白、框架或引导线仅在能改变注意力和关系时使用；写实际边界与方向，不仅写术语。移动后再判断构图是否仍成立。
3. **设计清晰范围与焦点交接。** 写谁清晰、背景哪项信息必须辨认、焦点为何转移及转到哪里。焦距和光圈只是表达意图的辅助：不把一个毫米数等同于固定情绪，不把“浅景深”用于必须同时读清前后景的镜头。必要时比较改变机位、景别和焦点的方案，而非堆参数。
4. **决定相机是否需要移动。** 固定机位能完成表达就可以固定。运动须有触发、起点、相对主体的路径、速度行为及落点；区分人物走动、摄影机移动、摇转和变焦。不要用推近自动代表情绪增强；需要揭示的信息必须在终点出现。指定特殊效果时写出实际可观察的结果和生成／后期分工。
5. **让光源与可见结果对应。** 从已建立的窗、门、灯或环境光恢复世界中的方向、软硬和明暗冷暖。换机位可以改变画面上的受光侧，但不能让同一灯无因换位置。逐镜写光落在脸、手、衣物及背景上的作用；关键表演和物品保持可读。皮肤、织物、金属等按当前素材呈现不同反射与纹理，不统一涂上“高光、磨皮、颗粒”。环境动态须有风雨等实际原因。
6. **检查动作终态和下一镜。** 必须保留的朝向、视线、物品状态、光色与曝光接得住；有意改变的地方说明叙事依据。构图方案依赖不存在的空间、互相冲突的参考或不可见动作时先修设计。

按当前问题查阅 [导演设计方法](../../../director-knowledge-base/分镜提示词/导演设计方法.md) 的景别、构图、空间和光影段落，具体路径查 [运镜选择与执行](../../../director-knowledge-base/分镜提示词/运镜选择与执行.md)。无需每次通读两篇。

## 写进现有产物

在《分镜执行表》的“导演设计”中保留会改变观看效果的选择及一句理由。正式正文遵循 [当前四字段格式](../ai-director/references/shot-block-format.md)：

| 位置 | 摄影工作交付什么 |
| --- | --- |
| `[整体场景与氛围]` | 本单元共同的空间、光源、影调与有因环境动态 |
| `景别与镜头运动` | 机位、构图、清晰范围、焦点和有动机的相机路径 |
| `画面与动作` | 人物及道具的实际位置、连续变化和可见终态，与摄影安排相容 |
| `光影表现` | 本机位下主体与背景如何受光、阴影如何分布、材质如何呈现 |
| 现有剪辑备注 | 两端光色、动作／视线接点，以及确需后期完成的工作 |

例：剧情要求观众先察觉后景有人进入、前景人物暂未发现时，可保持固定中景和前后景可辨的清晰范围，入口与进入动作可见；不会同时要求“背景完全虚化”和“清楚看见后景身份”。是否露脸、何时移焦由既定信息顺序决定。此例是本地教学设计，不是已生成案例。

## 在同一次检查中判断是否实现

- 文本检查：观看重点有具体载体；取景容得下必要动作；焦点不泄露信息；世界光源连续；每个特殊效果有可观察的标志。缺项修正文，不追加评分表。
- 实际视频：正常速度看注意力是否按计划转移、动作是否可读、相机是否到达落点、接镜是否跳空间或曝光。构图轻微漂移但叙事成立记为备注，遵守原有停止条件；指定效果未实现不能仅凭术语或参数称成功。
- 沿用 [SOP](../../../PRODUCTION_SOP.md) 的台词锁、最小相容参考、关键帧审核、运行授权和媒体验收。构图需求不自动授权生成关系图、白模或试片；含箭头和网格的研究图不直接进入视频模型。
