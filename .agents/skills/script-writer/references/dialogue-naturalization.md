# 台词拟人化、称呼系统与短剧对白密度

> 适用于新写或修改短剧对白，解决“台词机械、AI 书面腔、全员同口吻、满屏展示不开口、网文套话出戏”等问题。与 [sw-dialogue](../../sw-dialogue/SKILL.md) 和 [对白、梗与情绪节拍](../../../../director-knowledge-base/剧本/对白、梗与情绪节拍.md) 配合使用：本文件侧重**落笔生成时的口语质感与短剧对白密度**。

---

## 1. 短剧对白密度与信息通道铁律

### 1.1 短剧以台词+反应驱动，忌长段纯展示空转
- 竖屏短视频里，连续十余秒只有人物干走/翻手机/摆造型却无人开口、也无强动作奇观的“展示段”，极易造成划走。
- **参考密度（以 90 秒–3 分钟短剧为例）**：常规对白推进段落约 **3.5–6.5 字/秒**（90 秒单集约 300–580 字，需视打斗/高信息慢镜留白浮动；核心是**不靠废话注水，而靠交锋与信息对撞撑密度**）。

### 1.2 世界观与背景优先由“交锋中的角色”说出，严控旁白
- 旁白天然“听书化”，尽量不让旁白承担人物关系和世界观解释。
- **正解**：把设定塞进**正在生气、质疑、威胁或求助的角色嘴里**（如与其旁白说“这是蚀念会的高阶怪物”，不如由反派冷笑或知情者急喝点出直接威胁）。

## 2. 称呼四轴系统（关系温度计）

一个称呼由四个变量决定：**身份轴 × 关系轴 × 场合轴 × 情绪轴**。全剧无论吵架还是暧昧永远叫同一个死称呼，是典型的 AI 机械化症状。

| 情境变化 | 称呼策略 | 示例（都市 / 校园） |
| --- | --- | --- |
| 公开/正式/生疏 | 职务、姓氏或礼貌尊称 | “陈总监”“林野学长” |
| 私下/熟识 | 简省称呼 | “老陈”“林野” |
| 亲密/动情 | 昵称、去姓、轻声小称 | “阿栀”“哥” |
| 恼火/决裂 | 降格、连名带姓喝名 | “林野！” |
| 挑衅/阴阳 | 贬称、反讽敬称 | “林大牌面”“陈大高人” |
| 划清界线 | **退回生疏称呼**（比直接说“我们完了”更有戏） | 从“老周”退回“周社长” |

> **铁律**：同一关系阶段称呼必须跨集一致；**称呼变化必须由具体事件触发**，不能靠改称呼代替剧情推进。不同角色对同一人物的称呼应有区分度。

## 3. 分题材去书面腔与「撒碎屑」四法

### 3.1 先分题材，不乱改风格
- **现代/都市/校园剧绝对禁用书面虚词**（只查台词文本，不查场景描述）：
  `是否 / 因此 / 从而 / 鉴于 / 予以 / 加以 / 可否 / 何以 / 颇为 / 甚为 / 以及 / 然而 / 由于 / 进行（+名词）`
  - 例：`是否 → 是不是`｜`因此 → 所以`｜`进行调查 → 查一下`
- **古装/年代剧禁用现代职场/网文黑话**：
  `逻辑 / 数据 / 机制 / 效率 / 系统 / 项目 / 团队 / 维度 / 复盘 / 闭环 / 赋能 / 抓手 / 情绪价值 / 经济损失`
- **句法拆解**：少用成对完整关联词（“虽然……但是……”“因为……所以……”）；口语大胆**省主语**、被动改主动、超 18 字的长句必须有自然停顿点。

### 3.2 「撒碎屑」四法（把工整句掰成活人话）
1. **自打断**：犹豫、隐瞒或心虚时改口（“我本来想——算了，你先吃”）。
2. **掉尾**：威胁、心酸或告白说一半留给对方反应（“你要是敢碰他一根手指……”）。
3. **关键词重复**：受冲击或慌乱时重复一个核心词，不重复整句。
4. **自然语气词与垫词**：句尾助词（`啊/吧/呢/嘛/呗/啦/呀`）、起话垫词（`我说/那什么/行吧/得了`）、应答词（`嗯/啧/哎/哟`）。

> **豁免边界**：冷静宣判段、权威人物刻意端着官腔、古装文言体本就不需要加语气词；口语化 ≠ 变啰嗦、≠ 拉低人物身份。

## 4. 金句改造四式：端着的网文句 → 带刺的活人话

能当场接招还嘴的才是短剧金句；像在给观众念宣言、或需要想三秒才懂的都是废话。

1. **先接住对方上一句，再拐一刀**：不要各说各话，用对方的话头反刺回去。
2. **用对方逻辑归谬堵嘴**：当场拆穿对方伪装的身份或借口。
3. **把陈述改成反问或指令**：减少自我总结，增加面对面的压迫感或拉扯感。
4. **掺入具体生活/生理细节词**：用眼前物件、动作和生活常识落地狠话（忌空喊“献出你的本源”“动他你配么”“天凉王破”类廉价中二套话）。

## 5. 机械化 AI 腔 10 条认症表与三测

写完对白快速扫一遍，命中即改：
1. **等长句**：每句字数和节奏像排比一样齐整。
2. **零语气词**：整场日常戏干巴巴没有一个自然助词或停顿。
3. **全完整主谓宾**：谁说话都像在念书面报告。
4. **人人同口吻**：遮住名字认不出是谁在说话。
5. **信息均匀对答**：像两个人轮流念设定资料，没有信息差。
6. **说明式台词**：“我是你学长，八年前我外婆给我……”——应转入动作与冲突。
7. **情绪结果词**：直接说“我很愤怒”“我好感动”“我好怕”。
8. **模板化反派/绿茶套话**：如“野哥哥人家脚扭了”“成为我的养料吧”。
9. **全员油腻粗口或全员礼貌**：粗话/敬语没有随身份、关系分层。
10. **无升级复读**：相邻两集原样重复同一句口号或吹牛台词。

**快速三测**：① **遮挡名测试**（遮住说话人还能分清谁是谁）；② **朗读气口测试**（长短句交替，不拗口）；③ **听者反应测试**（每句台词有没有让对面的人产生真实反应或策略变化）。
