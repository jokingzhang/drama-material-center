# 反捧杀五维审稿、分层改稿与外来剧本适配

> 适用于剧本诊断、自我复核、大改前的问题定位，以及接收外部剧本直接进分镜前的适配。核心原则：**不捧杀、凭原文证据说话、先修结构再修句子；单主会话内部完成，不建外部 Reviewer 团队，不设多余审批弹窗**。

---

## 1. 反捧杀硬规则（诊断与自检必守）

### 1.1 五条纪律
1. **严禁空泛夸奖**：禁止出现“整体不错 / 节奏可以 / 人物还可以 / 立意很好 / 很有爆款潜力 / 这里可以再加强一下”等废话。
2. **先找真实硬伤**：即使底子很好，也必须指出最可能拖垮完播率、导致出戏或后续写崩的真实风险点（做一次“最坏情况推演”：如果观众在这里划走或评论区开骂，最可能是因为哪一句/哪一场）。
3. **每条意见必须绑原文证据**：格式统一为 `【位置与问题】+【引用原文/事实】+【对观众的影响】+【最小/最优改法】`。
4. **标明修改优先级**：区分 **P0（不改必死：开篇划走、人设崩塌、逻辑硬伤、审核红线）**、**P1（严重降质：套路重复、AI 腔严重、反派纸糊）**、**P2（锦上添花）**。
5. **严守确认边界**：只诊断或提建议时保持只读，不擅自替换原文；针对已确认锁定台词发现问题时，只指出影响与建议方案，获明确授权后再改词。

## 2. 单主会话五维审稿透镜

通读草稿或评估外部剧本时，在同一会话内快速过一遍五个独立视角（发现各视角全无异议时，须警惕“作者滤镜”，强制补充最坏情况推演）：

| 审稿透镜 | 核心拷问（只看致命点） | 典型红牌 |
| --- | --- | --- |
| **① 故事因果** | 能否用“因为—但是—于是—结果”连贯复述？人物动机、知情边界、道具/伤势是否前后一致？ | 人物降智、道具穿帮、方案毫无抵抗直接成功 |
| **② 商业与平台** | 第 1 集前 5–30 秒有没有强抓手？集尾钩子够不够硬？单集时长与平台匹配吗？ | 开篇平淡铺垫超 30 秒、假黑屏钩子、血腥限流风险 |
| **③ 题材核心观众** | 答应观众的甜/爽/燃/悬疑兑现得够不够痛快？核心关系和人设反差有没有立住？ | 卖点藏太晚、主角不讨喜、情绪铺垫不足就强行煽情 |
| **④ 信息流新观众** | 假设没看过简介和上一集，前 10 秒能看懂谁遇上什么麻烦吗？哪一秒最可能划走？ | 专有名词轰炸、进场无定向、展示空转无台词 |
| **⑤ 连刷挑剔观众** | 上集钩子有没有在本集第一动作兑现？连续几集是否重复同一套路？答案是否拖太久？ | 连续 2–3 集同一套路、“装瞎”反复生效、悬念拖十集不推 |

## 3. 十大反碎片化硬病灶速查

锁稿或交付前扫描，命中即优先修复：
1. **连续场机械硬拆**：同一场对话因时长被生硬拦腰截断成两集，上集无局部兑现。
2. **零抵抗方案**：角色提出办法后无人质疑、无现实检验、一步到位成功。
3. **突兀共识**：敌对/疏离关系靠一句漂亮话瞬间和解或信任，无行动与代价。
4. **口头代价**：设定宣称“很危险/会遭清算”，正文无人真的失去或承担后果。
5. **未建赌注**：拿某种资格、秘密或亲人施压，但前文从未让观众在意过它。
6. **标签情感**：只靠“摸信物 + 旁白说爱了八年”，情感没有真正改变角色当下的行动选择。
7. **纯说明对白链**：连续多句只为向观众科普世界观，说话双方没有眼前博弈。
8. **预期内空钩**：集尾只确认观众早就猜到的事，没有打开新的行动压力。
9. **时间/状态断层**：日夜、伤势、道具归属、知情范围跨集冲突或凭空重置。
10. **金句复读机**：同一种口号或标志桥段在相邻集无升级地原样重复。

## 4. 分层改稿与「改稿六把刀」

### 4.1 先定层，再动刀
- **结构层**（行动链、人物选择、反派博弈、集尾钩子、防重复）没成立时，**先修结构**，不用润色台词掩盖剧情硬伤。
- **叙述层**（开场抓手、信息先后、场次过渡、快慢节奏、视角距离）顺畅后，再落到 **表达层**（去 AI 腔、称呼、金句打磨）。

### 4.2 短剧改稿六把刀（授权改稿时按需选用）
1. **砍平铺直叙**：把解释性对白和慢热寒暄砍掉，改成行动和正面冲突。
2. **砍无效场次**：删掉不改变信息、关系、资源或风险的纯过渡场/注水配角戏。
3. **压缩前情提速**：把开篇铺垫压到最薄，必要时前置高光反差镜头锁前 5 秒。
4. **强化对立与反制**：给反派长脑子，让主角先受压或受挫再换策反击，爽感才有重量。
5. **磨台词与重音**：按 `dialogue-naturalization.md` 去 AI 书面腔、补称呼变化与带刺还嘴句。
6. **收紧集尾钩子**：把软塌塌的收尾改成“局部兑现 + 具体新危机/反转/选择”。

## 5. 台词七维诊断（精修对白时使用）

1. **角色辨识度**：遮住角色名能否分清谁在说。
2. **潜台词层级**：是否全是 0 层直白念心理，有无反话/错位/借物说话。
3. **冲突推进力**：连续 3 句以上没改变局势、立场或情绪温度的，删。
4. **类型语感**：都市忌公文/文言、古装忌现代职场黑话、写实忌中二网文腔。
5. **信息效率**：能否一句兼顾行动、关系与设定，拒绝连句科普。
6. **节奏与音乐性**：长短句交错、有停顿气口、朗读顺嘴。
7. **金句潜力**：每集 1–3 句可切片传播的带刺活人话即可，满篇金句等于没有金句。

## 6. 外来剧本直通分镜的适配边界

当用户已有**外部成型剧本**（如第三方工具、外包或网文改编稿，只有“角色：台词”和少量结果性动作）并希望直接进入 `ai-director` 拆分镜时：
- **允许（只补不改）**：在 `ai-director` Stage 1–2 导演预览阶段，补足可拍的**表演层**（神态、动作相位、视线、语气）与**调度层**（站位、进出场、道具状态、场次过渡）。
- **严禁越权**：**不得顺手改台词、删改事件、变更人物动机或剧情顺序**——必须守住 `AGENTS.md` 逐字台词零擅改铁律。
- **发现硬伤只报告**：若发现逻辑穿帮、人物降智或抖音完播风险，单独列出《剧本硬伤清单》交用户拍板：用户决定改剧本则先走 `script-writer` 修订并重新确认台词；用户决定不改则原样按剧本拍。
