# 世界观、人物开发与跨集连续性

> 适用于**无完整剧本**、需要从一句话想法/梗概/旧稿重构世界观、补齐能力规则、立住人物与反派，或维护多集连续性的任务。核心原则：**规则必须进入生活并改变选择，拒绝无用百科设定表**。

---

## 1. 从点子到可写压力链（构思与取舍）

### 1.1 把“不够好看”缩到具体卡点
不要空泛地重想故事，先定位缺口属于哪一项：起点钩子弱、人物下一步没理由、中段靠拖延凑集数，还是设定只是背景板。

| 常见卡点 | 可试的机制改变 | 留用前提 |
| --- | --- | --- |
| 人物总用同一办法过关 | 改变资源、权限、知情或求助对象 | 限制有来由，不靠角色突然变笨 |
| 反派只是拦路工具人 | 推演他不受干扰时的真实计划 | 计划有收益、能力边界与约束 |
| 关系只剩单纯敌友/发糖 | 引入欠情、误信、共同利益或身份冲突 | 变化有具体事件与利害依据 |
| 设定只是开场旁白背景 | 让规则直接影响获取、成本、风险分配 | 不只送金手指便利，也制造代价 |
| 反转只有“藏身份掉马” | 改变证据可信度、工具用途或隐藏代价 | 旧事实成立，揭晓后局面不可逆变化 |
| 中段反复重置、没有积累 | 让每次行动留下不可逆的义务、伤势或暴露风险 | 下一次不能无成本重来 |

### 1.2 候选方案必须三步推演
给用户提供方向选择时，**只改职业/地名但行动链相同的方案视为同义方案**。每个候选必须向前推三步：
1. 主角当下最想保住或得到什么；
2. 第一种惯常办法为什么失效或代价变高；
3. 这次受挫留下的新条件，如何迫使下一集换策略。

把“最吸引人的视觉画面（让人点进来）”与“最能长出后果的机制（让人追下去）”分开校验；两者都成立才定案。

## 2. 世界观与超自然/制度规则落地

只发展会影响当前故事与人物选择的规则，不写人物永远用不到的世界史。

### 2.1 核心规则四要素（超能力 / 道具 / 组织制度通用）
凡剧情反复依赖、或用于决定胜负与结局的能力、道具、组织禁令，必须写清四项：
1. **使用条件**：谁有权限、需要什么媒介/准备、什么情形下能触发。
2. **能力边界**：做不到什么；范围、持续时间、精度上限在哪里。
3. **使用成本**：每次动用会付出什么身体、资源、暴露风险、信誉或关系代价。
4. **可被利用的弱点**：对手怎么发现它、怎么针对它设局。

> **硬约束**：只写在设定表里却从不改变人物选择的“代价”等于没有生效。严禁危机时临时取消限制，也严禁临近结局临时发明此前未建立的新规则或新限制来强行翻盘/拖延。

### 2.2 组织与生活后果
- **组织不是一个有很多成员的人**：写清组织的资源来源、核心利益、执行权限与内部约束（如“撤离令”由谁签发、违抗后由谁追责、为什么不能靠主角一句嘴炮豁免）。
- **规则进入日常**：优先看这项规则改变了什么日常行为、禁忌、称呼或利益交换；尽量让观众通过一次具体交易、一次惩罚或一次避险看见规则，而不是大段设定宣讲。

## 3. 人物、反派与关系弧设计

### 3.1 主角不能是被动挂件或降智工具
- 即使采用“扮猪吃虎 / 凡人配满级大佬”的反差结构，双方也必须各自拥有**主动选择权与不可替代的功能**。
- **逐集弧光可测**：不要把短剧快节奏曲解为“人物无需变化”。主角的认知、能力或关系立场不得连续 3 集以上完全原地踏步。

### 3.2 反派能力基线（防止爽感贬值）
反派太蠢太弱，主角的保护和反杀就没有含金量。核心反派须满足：
1. **有合理信息来源与独立计划**：反派如何盯上主角、为何此刻动手，必须有据可查。
2. **具压迫感**：重要对手在被彻底击溃前，至少在信息、局面或局部冲突中占过一次上风，迫使主角换策略或付出可见代价；避免每集反派都是出场即被一招秒杀的纸糊怪。
3. **随阶段升级**：小反派靠骚扰/试探、中层反派靠信息差与规则设局、核心反派直击主角最深软肋与关系底线。

### 3.3 关系推进靠行动与代价
- 从疏离到信任、从试探到并肩，必须落到具体事件（替对方扛责、暴露风险、放弃退路、共同解决危机）。
- 禁止只靠“改称呼”“旁白宣布感情升温”或无休止的“低级误会”撑关系线。

## 4. 跨集连续性与因果五账

多集开发或改稿时，严格区分五类状态，**绝不混为一谈**：

| 账目 | 记录什么 | 常见错误（禁止） |
| --- | --- | --- |
| **已确认设定** | 用户定案的世界规则、人物关系、硬边界 | 把未采纳的讨论草稿当事实 |
| **已呈现信息** | 正文实际已写出、观众已经看见的内容与集次 | 把大纲计划当成“前面已铺垫” |
| **人物知情** | 谁在何时经何渠道知道、怀疑或误信了什么 | 把“作者/观众知道”当成“角色也知道” |
| **可用条件** | 道具归属与形制（如单哨/双哨）、伤势、资源、承诺 | 道具前后矛盾，或伤势/消耗下集凭空重置 |
| **观众等待** | 已种下的伏笔、悬念问题、承诺兑现位置 | 伏笔种下十集不提醒，或未埋先收 |

### 4.1 改稿沿依赖传播
删改或移动任意一场戏前，先核对它建立了哪些前置条件（人物第一次知情、道具归属、伤势状态、情绪承诺、下集钩子）。授权范围内同步修正下游依赖；超出授权范围的受影响集次，明确列出待衔接位置，不悄悄放任穿帮。
