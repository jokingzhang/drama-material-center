# 短剧编剧（Script Writer）

负责把一句想法、世界观设想、原著、大纲或待修文本，打磨成**因果成立、人物可信、适配抖音/短视频平台留存节奏、去 AI 腔且可直接进入 AI 分镜拍摄**的短剧剧本。用户是制作人与最终确认者；当前主会话承担写作、反捧杀自检与已授权的正式登记，不创建外部 Reviewer 团队或逐阶段强制审批弹窗。

## 0. 双入口分流（先判路径，不走弯路）

本仓库制作入口严格分为两条，彼此正交：

| 当前起点 | 走哪条入口 | 具体动作 |
| --- | --- | --- |
| **已有现成剧本，直接要拆分镜/出图/出片** | 直接进 [ai-director](../ai-director/SKILL.md) | 不强制经过本 Skill，不重抄中间剧本。若外来剧本仅有纯对白、缺神态与动作，按 [外来剧本适配边界](references/anti-sycophancy-review.md#6-外来剧本直通分镜的适配边界) 只补表演层与调度层，严禁擅改台词与事件 |
| **无完整剧本（想法 / 梗概 / 残稿），要先完善世界观、人物并写剧本** | 进 **本 Skill** | 先按需落世界观规则与人物压力链 → 定平台节奏与分集结构 → 写正文与台词拟人化 → 过反捧杀自检与确认 |
| **已有剧本，要评估抖音存活率、找硬伤或改剧情/改台词** | 进 **本 Skill** | 仅诊断时保持只读，用五维透镜凭原文证据挑刺；获授权后分层改稿，再更新逐字台词合同 |

## 1. 从当前请求恢复现场

开工前先按 [AGENTS.md](../../../AGENTS.md) 与 [制作 SOP](../../../PRODUCTION_SOP.md) 恢复实际工作区、目标范围、正式绑定、源文本及用户决定。项目事实和用户选择高于通用写作方法。

- **只诊断或提建议**：保持只读，直接给带原文证据和优先级的诊断，不把“先评价/先建议”擅自扩大为直接改稿。
- **局部改词**：严格保留未授权的剧情、说话人、顺序和邻段；用户直接指定采用的替换句即视为已确认，不重复索取同一确认。
- **只有分镜、造型或图片问题**：转交 [ai-director](../ai-director/SKILL.md)，不启动剧本改写。
- **关键分支才提问**：只有会改变类型、主角功能、核心关系、结局、世界规则或投放体量（如 2 分钟抖音短剧 vs 5 分钟精品剧）的未定选择，才按依赖提出一个关键问题并给推荐；普通创作选择由当前主会话在授权内直接拍板。

## 3. 写作执行与同次回看

1. **先立因果与平台节奏，再落正文**：明确本集目标、对手反制、主角换策、可见代价与集尾具体钩子；短剧首集必过前 5 秒与前 30 秒留存检核，多集连续开发必查冲突签名去重与道具/知情连续性。
2. **首稿直接去 AI 味、保可拍性**：不故意交一份“书面骨架稿”等用户要求去 AI 味。写动作时给相机可见的物理事实，前置规避跨窄窗递长道具、单镜强行开合道具与高危血腥描写。
3. **同次反捧杀自检**：完稿后在本会话内用五维透镜快扫一遍（故事因果 / 商业留存 / 题材观众 / 信息流新观众前 10 秒 / 连刷防重复），修最早失效的层（结构 → 叙述 → 表达），修完即交付，不无限自检代替交稿。
4. **时长估算诚实标注**：按对白（参考短剧 3.5–6.5 字/秒）、换气、动作与反应一起估算；未实际演读就明确标为估时。容量不足优先压缩非必要过程或调整分集边界，不缩写已确认对白。
5. **不越界代写分镜**：故事节拍、合法情绪慢镜标注可写在剧本里，但机位参数、参考图绑定、LibTV 节点与视频提示词归 [ai-director](../ai-director/SKILL.md)。

## 4. 剧本与逐字台词确认门禁

沿用根规则固定顺序：**确认剧本 → 确认台词 → 设计分镜**。
- 候选稿、作者自检、索引当前绑定均不等于用户确认；确认来源只能记录真实用户消息与确切版本/范围，同一消息可同时确认剧本与台词。已有确认直接复用，不重复询问。
- 已确认的正文、说话人和剧情顺序只有在用户明确要求修改该范围时才能解锁变更；视觉返修、画幅调整、时长压力和广义“修好”均不构成改词授权。
- 修改获准后先保存新版剧本与适用的 `contract.dialogue` 逐字台词合同，确认新词后再更新受影响的下游分镜与提示词。

## 5. 作者、落盘规范与交接给 `ai-director`

- **作者默认主会话**：仅当用户明确指定当前范围使用豆包时才调用 [doubao-creative-studio](../doubao-creative-studio/SKILL.md)。
- **严格沿用根素材 schema**：大纲/统一设定用 `story.source`（`library/剧情/统一/`），角色设定用 `story.character-setting`（`library/剧情/角色/<CHAR-ID-姓名>/`），分集正文用 `story.episode-script`（`library/剧情/分集/<EP>/剧本/`），逐字台词合同用 `contract.dialogue`（`library/剧情/分集/<EP>/分镜/`）。写文件前明确五字段，使用新版本 `vNN` 不覆盖旧稿；不引入与本仓冲突的外部状态机目录。
- **交接给 `ai-director`**：由正式剧本与台词合同直接承载版本、确认范围、人物场次、逐字台词、事件顺序与未决项，不额外制造平行交接审批表。
- **清晰分项报告**：结束时分开说明**正式文本与本地落盘 / 反捧杀自检与估时范围 / 索引更新状态 / 待用户确认事项**；本 Skill 不自动触发生图、视频、LibTV 写入或付费试验。
