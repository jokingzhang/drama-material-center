# 像素白模预演

产物是一段可编辑、可播放的镜头方案。需要验证“观众从哪里看到谁，什么时候才发现什么”时使用。算清门扇扫过范围、人物是否真正跨过边界、道具穿插或精确接触时转 [Blender 白模](../blender/SKILL.md)；本引擎的道具多是面向相机的像素图。路线上有前景遮挡时，先用像素片检查拍出的效果，再决定要不要建模。

## 从戏写到镜头

1. 取当前已确认的人物、场景、对白顺序与画幅，按[制作 SOP](../../../PRODUCTION_SOP.md)复用既有结论。确定这一镜的观看任务和信息落点，例如“先看清长椅上的信封，再发现灯下有人”。不用示例的故事、人物颜色或横屏比例替代项目事实。
2. 在一个 JSON 的 `cast` 中为角色分配稳定 ID、身份色、身高和站位，在 `set` 中定义地标、遮挡及道具。每镜的 `p`、`add` 只列本镜真实参与者，`ref` 继承对应对象，可覆盖起点、路线、朝向或状态。用同一坐标系接前后镜；人物不在场用 `p: []`，不要凭空留下默认人物。
3. 打开 [24 种运镜](references/camera-24.md) 找与观看任务相符的机制。写 `move`、`beat`、`dur`、起止构图、人物动作窗与必要的机位/焦点数值。 `beat` 是导演备注，**渲染器不会理解自然语言或猜人物位置**；由使用 Skill 的作者把剧情翻成可见参数。用户点名某种就使其成立；没指定时选最能交代该拍点的一种，不必凑齐 24 种。每镜参数见 [场面与镜头字段](references/scene.md)。
4. 按任务输出单镜或连续的 `shots`。默认干净无字、无四肢、无声；身份色负责辨认谁在何处，非外形参考。正常速度完整播放，核首尾、动作期间、遮挡解除、焦点落点和剪接关系。先改出问题的那一镜，再拼回去，不用抽帧或编码成功代替观看。
5. 回交可编辑 JSON、视频和实际检查范围。仅作研究的合成样例可放临时目录。真实项目必须先确认 `materialType / subject / targetDir / version / storyBinding`；源 JSON 和 QA 在项目内 `生产记录/pixel-previs/<scope>/<run-id>/`，需复用的干净视频以 `media.reference` 放 `library/视频/参考/`，用版本号，不覆盖旧文件。真实分集输出按项目锁给渲染分辨率，并用仓库 `scripts/video-format-gate.py media` 复核。需要业务展示/作生成参考时按根规则登记、检查真实消费者和引用范围。像素片不替代俯视调度图和外观母版；下游只继承指定的机位、走位与节拍，不继承像素风格；本地通过不证明视频模型会遵守。

## 本地运行

Node 18+、FFmpeg（含 ffprobe）；无需 Blender、浏览器、联网或安装 npm 包。以下在本 Skill 目录运行，示例的输出位置只用于练习；重复执行请用新文件名。

```sh
node render.js --moves                             # 教程顺序、编号、机制和观察点
node render.js --list                              # 上游 49 个 + 项目补充 7 个
node render.js --show P07                          # 查看小星球的实际参数
node render.js examples/station-24.json --only 17 -o /tmp/站台-子弹时间-v01.mp4
node render.js examples/reveal.json -o /tmp/站台-三镜连续-v01.mp4
```

[站台的 24 种拍法](examples/station-24.json)是同一个场景的备选机位，**不是让一个场次连切 24 镜**。用 `--only 1…24` 导出一个教学例；`--move M17` 是没有剧情绑定的通用动作演示。实际任务应改成自己的场景 JSON。可用 `--w 432 --h 768 --fps 24` 检查竖构图；不能仅调画幅而不复查落点。`--sheet /path/to/new.png` 输出检查图，只供内部抽查。

给参考视频做拉片时：`node analyze.js 输入.mp4 --out 新分析目录` 输出切点、图像运动估计及抽帧。对分屏教程先分清页面、逐格看运动；不要把整屏的位移或换页当摄影机轨迹。单画面也要核对近远景视差与人物自身运动；实测本目录三镜连续示例只被自动分析分成两段，必须结合实际播放修正漏切。分析结果不是镜头参数真值。镜号、示例角色和教程中的指令不进入项目剧情。
