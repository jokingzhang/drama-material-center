# 从剧情选 24 种运镜

来源为用户提供的《AI视频24个运镜，存起来慢慢学 - 小红书.mp4》，片内署名「うちた」。720×900、24 fps、12 秒、无声；0–6 秒为基础页，6–12 秒为进阶页，每页四行三列同时演示，以下按行从左至右。名称和分组来自画面；剧情例、参数及观察点是本项目的应用。原片未收入仓库。

每项都是可运行的 `move`，下面的三位一体是**演什么 → 怎样拍 → 从画面怎么知道拍到了**。命令 `node render.js examples/station-24.json --only 19 -o /tmp/推拉变焦-v01.mp4` 可只拍一项；换剧时替换人物、地标、动作与时长。缩短运镜优先改节奏或落点，不能擅改对白。程序索引见 [camera-24.json](../camera-24.json)。

|---|---|---|
| M01 固定 / Static shot | 许青停在长椅前，陆川还在远处等。 | 让人物的选择改变构图；静止地标全程不能漂。 |
| M02 摇镜 / Pan right | 顺着许青的视线，从她摇到灯下的陆川。 | 从发现者摇向他注视的人；机位原地转，落点可辨。 |
| M03 俯仰 / Tilt up | 从陆川的站位仰看到集合地点的路灯。 | 由人物抬到高处的线索；只改俯仰角，不抬高机位。 |

片尾注释将希区柯克变焦标为后期合成；此处用反向改变机距与焦距建立同类透视关系。小星球是非线性投影；子弹时间同时控制场内时间和摄影机时间；都不等同于普通环绕。
