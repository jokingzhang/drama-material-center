# 写一场能拍的戏

完整可运行的 [站台场景](../examples/station-24.json) 展示了每种镜法怎样绑定同一对人物。最小例：导演要拍“信封已经在眼前，许青这才看见远处是谁”。此时移焦比向前推更合适，后者会改变两人的空间关系。下面用箱形标记信封、蓝色标记许青的位置（主观镜中不画）、棕色标记远处的人：

```json
{"w":768,"h":432,"fps":24,
 "cast":{"chuan":{"v":2,"x":1.2,"z":8}},
 "set":{"letter":{"s":"box","x":-0.6,"z":2.2,"y":0.72,"wd":0.42,"h":0.18}},
 "shots":[{"beat":"许青的注意力由信封转向陆川","move":"移焦","dur":3,"w":0,
   "c":{"y":1.05,"mm":24},"t":[0.8,2.0],"focus":[2.2,8],
   "p":[{"ref":"chuan"}],"add":[{"ref":"letter"}]}]}
```

| 控制项 | 写法与边界 |
|---|---|
| 舞台 | 米；x 向右、y 向上、z 向前。光轴初始朝 +z，水平视场按 mm/36 投影。根级 w/h 是输出像素；**镜头级 w:0** 关闭示例随机方块，grid:0 隐藏地面网格。单镜也建议写入 shots，消除 w 的歧义。 |
| 角色 | `p:[{"ref":"qing","x":-1,"z":8,"to":[2,8],"t":[0.5,2]}]`；转折路线用 path 给多个 [x,z]，移动时自动朝前。静态 h 是朝向角，height 是米；v=1/2/3/4 或用 color 的 #RRGGBB。没有肢体、手持物或精确表演。 |
| 道具 | add 可用 box、pillar、lamp、door、wall、bench、bag 等。x/z 是地面位置，y 是离地高度，h/wd 是高/宽；`keys:[{"t":0,"y":1.5},{"t":2,"y":0.5}]` 可表示信封下落。单一道具保持同一个 ref，别用复制/消失代替动作。 |
| 机位 | c 为一个对象或关键帧数组，用 x/y/z、yaw/pitch/roll（度）、mm（等效焦距）；at 为注视目标 [x,y,z] 或一对起终点，会覆盖朝向角。变焦只改 mm；真实推镜改位置，给足近、中、远参照。 |
| 人与相机 | `follow:{"who":0,"off":[0,1.3,-4],"look":[0,1,0]}` 中 who 是本镜 p 的零基索引。o 为 [起半径,终半径,起角,终角]；默认圆心取首位角色初始位置，道具用 pivot:[x,z] 明定圆心。空人物的道具环绕务必给 pivot。 |
| 节奏与切镜 | dur 为秒，t 为运动起止窗；相机/物件关键帧 t 为镜内绝对秒。e 取 lin/io/in/out。改变 dur 会等比缩放继承自预设的运动窗，自己覆盖的 t 按新秒数写；shots 按顺序硬切。使用 --only N 提取第 N 镜。 |
| 特殊机制 | M15 是以相机正下方为中心的立体投影，planetRadius 是以短边为单位的起止地平线半径；调相机 x/z 选中心，完整亮相时半径小于 0.5。M17 freezeWindow:[a,b] 冻结场内人物和道具时间，相机照走，b 后从冻结点继续；冻结前后须可见物体状态。M19 让 mm/主体距离近似恒定；M20 焦点距离是相机空间深度；M22 使用自写相机线时以 path:null 覆盖预置路线。M24 只表达成片轨迹、速度和停点，不解算机械臂关节。 |
| 身份与输入 | 只写 ref 表示继承，镜内同名字段覆盖；p、add、c 等数组整体替换预设。上游 F/Y 的说明文案可能提及真人脸、手与步态；仅参考相机参数，本地角色渲染始终是无四肢标记。抽帧、原片拼板、带标签教学对照均非自动生产输入。 |
