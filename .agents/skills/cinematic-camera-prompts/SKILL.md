# 八种电影镜头提示词

把镜头名称翻译成当前剧情可用的摄影、调度和时间表现。由主会话执行，可直接调用，也可由 [AI Director](../ai-director/SKILL.md) 或摄影技能按需进入。导演姓名是本教程的检索别名，不代表该导演全部风格，也不能代替具体机制。

## 按当前戏选择

用户指定某种镜头时保留指定效果；未指定时先看观众应当发现、感到或等待什么，再选相关方法。剧情不需要特殊镜头时可以保持普通拍法，不为用齐技巧添加事件、灾难、道具、人物或台词。

| 当前观看任务 | 技巧与按需读取的写法 | 与近似镜头的区别 |
| --- | --- | --- |
| 人物突然意识到危险、真相或心理失衡 | [01 希区柯克推拉变焦](references/dolly-zoom.md) | 人物尺度近似稳定，背景相对尺度与透视关系变化；普通推近不算 |
| 人物起身、登场或取得主动，让周围空间衬托力量 | [02 迈克尔贝式英雄环绕](references/hero-orbit.md) | 相机围绕人物换侧，背景有视差；人物自转不算 |
| 由一件线索进入隐蔽空间，最终抵达秘密核心 | [03 大卫芬奇式不可能运镜](references/impossible-camera.md) | 受控虚拟相机穿越微小开口；与人体可通行的跟拍分开 |
| 从箱内、后备箱等受限位置看俯身的人物 | [04 昆汀式箱内视角](references/trunk-pov.md) | 相机可以完全固定，由开盖、靠近和伸手改变画面 |
| 与人物共同经历不断升级的现场 | [05 阿方索式沉浸长镜头](references/immersive-long-take.md) | 人物与环境事件共用连续时间，机位随发现改变 |
| 把行走与街头流动变成记忆、孤独或主观时间 | [06 王家卫式抽帧跟拍](references/step-printed-tracking.md) | 横向跟拍加时间采样／拖影；普通慢动作或全局模糊不算 |
| 用走廊、重复结构与稳定前进形成秩序或压迫 | [07 库布里克式低机位对称跟拍](references/symmetrical-tracking.md) | 低位、单点透视与恒定主体关系同时成立 |
| 通过后门、服务空间、许可与让路交代身份进入 | [08 斯科塞斯式空间穿越长镜头](references/spatial-access.md) | 路线中的社会反应承担叙事，不只是参观多个房间 |

先用 [分镜句式与模型适配](references/prompt-writing.md) 确定写法，再只读当前类型的参考；需要比较时读最接近的另一种。05 的重点是同一时间里人物和环境事件如何相互影响，08 的重点是通行路线与社会关系如何揭示身份。二者都可一镜到底；指定混用时可以有主次。

## 从故事到可执行分镜

1. **恢复输入。** 取得当前剧情与观看目的、完整人物姓名和当前造型、逐字台词、空间地标、道具状态、已有参考及上下镜接点。在本项目先遵守 [SOP](../../../PRODUCTION_SOP.md)，从真实工作区与正式绑定取事实；正式分镜复用真实用户的剧本、台词确认和剧级画幅锁。单纯研究、讲解或虚构教学例不要求立项或媒体生产。
2. **选承载变化的机制。** 说清为何现在用该镜头、运动或调度由什么触发、结束时观众新知道什么。方向已明确就直接写；教学假设须注明，不让用户填摄影参数表。
3. **走一遍空间与观看路径。** 明确起始机位和物理侧、高度／距离、人物路线、相机路线、转向及落点。区分相机移动、旋转、变焦、焦点交接、人物移动和播放时间效果。先写可以看见的关系，再以术语作简短辅助；环绕注明俯视方向或起终侧；箱内固定视角不凭空加跟拍；虚拟穿越明确开口与净空，不默认相机缩小或物件变形。
4. **让动作带动拍法。** 连贯展开触发、反应、行动与余波，取景容得下必要接触、过门和完成态。保留确认台词、说话人与顺序。时长按正常表演和路线估计，装不下先调整拍法或生成单元，不缩写台词。
5. **写入当前格式。** 沿用 [video-shot-prompt-v2](../doubao-creative-studio/assets/templates/video-shot-prompt-v2.md)：摘要 → 实际参考分类 → `[整体场景与氛围]` → `【多分镜时间轴】`。每个真实镜头只有一个累计时间范围和四个字段：`景别与镜头运动`、`画面与动作`、`光影表现`、`音效`。连续运动阶段用正文自然展开，不照搬教程的镜内秒级时间表；无实际参考的整类资产栏省略。一个完整固定镜头或长镜头可以独立成单元。
6. **说明实现边界。** 在现有设计／剪辑备注写特殊效果由生成还是后期完成、目标消费者和成功标志。只做提示词时到文本交付即止。生成、光学拍摄与后期模拟是不同实现方式，不能凭 AI 正文的“真实推轨”证明用了实拍设备。

正式项目产物进入 `library/剧情/分集/<EP>/分镜/`，按根 schema 列出 materialType、subject、targetDir、version、storyBinding，使用新版本与稳定业务绑定。本 Skill 不建立第二套目录、索引或运行入口。

## 交付与检查

默认给一小段拍法理由、完整提示词及相关检查／后期备注。只要正文就直接给正文；要求比较时给具体观看效果与取舍。来源、版本状态、待补输入和 QA 留在正文外。

参考中的八个完整例子均为虚构教学设计，没有真实资产、生成结果或人工接受记录。时长、比例、轨迹和光线仅属于该例，实用时替换为项目事实；不能当成已验证模板。

在同一次正文检查中核对：机制明确且起点、途中变化与落点相容；不同时要求背景完全不变与环绕视差，不同时要求箱内固定与相机移出箱外；身份、造型、台词、道具和空间连续；运镜未裁掉剧情变化；逐镜受光符合世界光源。

实际媒体须连续播放，并用对应参考的成功标志判断；状态转换还需密集检查转换窗口。正确术语、抽帧或解码不证明实现。明确要求的特殊效果未实现须如实记录；轻微构图或速度漂移沿用 SOP 的 QA 分级，不因可选精修自动返修或重跑。

默认用现有人物标准图、相容场景和必要道具。教程截图、字幕版、拼板与研究抽帧只用于学习，不进入生产参考；关键帧例外、视频门禁、远端写入与预算授权沿用现有规则。
