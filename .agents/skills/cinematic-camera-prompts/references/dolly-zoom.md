# 01 希区柯克推拉变焦

适合认知突然改变、危险被察觉或主观空间失衡。触发应来自已经确定的剧情事实；普通深情靠近或单纯展示人物不必套用。

## 必须写清的机制

- 相机沿视轴推近，同时缩短焦距／扩大视角，补偿人物在画面中的放大；或相机后退，同时延长焦距／收窄视角，补偿缩小。写实际方向，不只说“反向变焦”。
- 人物的可见尺度近似稳定，背景相对人物的尺度与空间关系改变。推近配合缩短焦距可让远处背景相对缩小、纵深拉开；后退配合延长焦距可让背景相对放大、纵深压缩。这里的“拉开／压缩”描述投影观看效果，不让建筑真的变形。
- 明确保持哪个尺度，如头部高度或上半身范围；允许人物自然表演，不机械冻结所有动作。背景须有可读纵深地标，避免纯色墙或完全虚化的背景承担效果。
- 由察觉触发相机运动，落在能读懂反应和继续行动的构图；若前后还有普通推近，要分清哪个阶段承担推拉变焦。

距离、焦段及补偿幅度按当前空间选择。近似投影下可用“焦距／主体距离大致恒定”检查方向，不强填固定毫米数。生成提示词只提出视觉目标，不能验证真实光学设备。

## 可改写的分镜句式

把四件事连在 `景别与镜头运动` 中：**相机实际位移 → 同时反向变焦 → 保留的人物尺度 → 背景相对变化**。选择其中一种，不把两个方向塞进同一段。

> 推近方案：摄影机正对林岚，以中近景开始；林岚察觉异常时，相机平滑向林岚推近，同时缩短焦距扩大视角，补偿靠近带来的放大，使林岚头部高度近似保持；远处门框相对林岚缩小，走廊纵深仿佛拉开，结尾保留林岚的反应。

> 后退方案：摄影机正对林岚，以中近景开始；林岚察觉异常时，相机平滑后退，同时延长焦距收窄视角，使林岚头部高度近似保持；远处门框相对林岚放大，走廊纵深仿佛压缩，结尾停在林岚与背景关系仍清楚的构图。

“拉焦”改变清晰深度，不承担尺度补偿；“数字放大整个画面”也不改变相机视点。人物突然站起时头部位置和尺度另有变化，须先设计表演与补偿的关系，不能同时锁死所有动作。

机制核对：[Maxon 官方 Dolly Zoom 说明](https://help.maxon.net/c4d/r23/en-us/Content/html/TMOTIONCAM-TMOTIONCAM_FOCUS.html)。上面的情境与背景变化句式为本地设计推导。

## 成功标志与返修

正常速度看人物尺度是否大致保持、背景地标是否相对变化，比较脸部与背景而非只看画幅整体。只有全画面一起放大、脸明显变大或背景被橡皮拉伸，不足以证明指定效果。若改由后期模拟，在现有剪辑备注标明主体分离、背景处理和目标镜头；没有深度信息的简单裁切不能自动视为等价实现。不因一次失败自动重跑。

## 完整教学例

虚构无对白场景：林岚发现一直亮着的走廊信号灯突然熄灭。以下数值仅服务本例，无真实参考输入；生产时补当前资产和确认事实。

```markdown
**总时长：7秒｜画幅：16:9｜无对白、不添加字幕｜场景：夜间值班室**

[整体场景与氛围]
林岚坐在值班室桌前，背后的玻璃隔断外是一条有连续顶灯的走廊。室内暖色桌灯照亮桌面，走廊冷白灯建立纵深，玻璃保持自然反射。

【多分镜时间轴】

### 0.0s–7.0s｜镜头1：突然察觉

**景别与镜头运动：** 摄影机在林岚正前方、坐姿视线高度，以中近景开始。林岚察觉走廊灯光异常时，相机沿视轴平滑推近，同时缩短焦距扩大视角，使林岚头部在画面中的高度近似稳定；走廊顶灯与门框相对林岚缩小，空间仿佛向远处拉开。运动末尾平稳停住，不用全画面拉伸替代。

**画面与动作：** 林岚原本翻看记录页，玻璃后的信号灯忽然熄灭。林岚视线先从纸面移到玻璃中的倒影，再看向走廊，翻页的手停在纸角，嘴唇微张但没有说话。运动结束后，林岚仍盯着熄灭的位置，手指缓慢压住纸页。

**光影表现：** 桌灯始终从林岚左前方照亮手与半边面颊，走廊顶灯在玻璃和门框上保持冷白亮点。只有既定信号灯熄灭，其他光源不随机位移动换侧。

**音效：** 纸页摩擦声在林岚停手时止住，室内通风低鸣持续，走廊传来一次清楚的开关轻响。
```
