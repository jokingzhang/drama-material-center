# 03 大卫芬奇式不可能运镜

适合用一条精密路径把物件线索带到其内部、隐藏地点或关键人物，让观众获得普通人视点无法取得的信息。不是给任意跟拍加一个导演名字。

## 必须写清的机制

- 定义视觉线索：从哪个有孔洞或通道的物件出发，经过什么可辨结构，最后揭示什么。每次尺度变化都沿可读路径连续发生；少量有职责的穿越点比无关障碍串烧更有效。
- 区分虚拟视点与实体相机。虚拟相机没有必须塞进开口的实拍机身，视点可沿孔道内部运动；不必让机身缩小，也不必让孔洞变大。穿越实心墙体只有在当前设计明确采用透视／CG 转换且用户允许时才成立。
- 写明开口方位、孔道深度、进入和退出方向、下一空间地标与落点。穿过某孔就应从该孔另一端出来，不瞬移到不相连房间。
- 各段速度为揭示服务，进入窄处可控制速度，退出后恢复合适观看尺度，结尾留得下反应。无剪切的空间连续不是“所有物件不遮挡镜头”。

正文用靠近开口、孔缘占据视野、内壁遮挡、出口揭示描述视点变化，不默认微缩变身，也不将这些阶段伪装成多个摄影镜头。若剧情确有微观世界，再单独设计尺度转换。若确需多段生成或后期拼接，在剪辑备注交代接缝、几何与遮挡；尚未验证的接缝不宣称已经完成一镜到底。

## 可改写的分镜句式

按 **受控虚拟视点 → 明确入口 → 连续穿过已有空隙 → 明确出口／内部落点 → 信息揭示** 写；物体表面和内部必须属于同一结构。

> 摄影机以受控虚拟视点正对机械钟背板通风孔，沿孔轴平稳推进；孔缘逐渐占满画面，视点穿过背板原有开口，内壁短暂遮住外部修表台，随后沿齿轮之间已有的空隙下降，最后减速停在底板戒指的近景。孔口、齿轮和背板保持原有形状与尺寸，路径始终通过空隙，观看过程连续。

想穿多个空间时，先说明结构如何相连，再加入观看转向；“穿过窗户、桌子、墙壁抵达秘密”没有交代开口、实体及路径。结尾揭示的线索由当前剧情决定。

[《战栗空间》视效主管 Kevin Tod Haug 的一手访谈](https://beforesandafters.com/2022/03/30/david-had-the-picture-of-the-movie-in-his-head/)说明了预演、运动控制和虚拟场景重建的结合。它支持“设计路径与连续空间”的思路，不能证明普通实拍设备或某个生成模型能直接完成本例。

## 成功标志与返修

入口、内部、出口与目标之间具有可追踪因果和空间关系；结构尺寸、材质与方向连续。物件熔化形成隧道、闭合孔口忽然变大、实体穿模或无因跳空间属于问题。目标模型是否能执行穿孔、连续遮挡与揭示尚需实际结果；默认不为此补关键帧、白模或生成试片。

## 完整教学例

虚构无对白场景：从机械钟的背板通风孔抵达钟内被放置的戒指。本例只用一个开口，不照搬教程的宫殿障碍链。

```markdown
**总时长：8秒｜画幅：16:9｜无对白、不添加字幕｜场景：修表台上的机械钟**

[整体场景与氛围]
机械钟放在修表台中央，背板朝向摄影机，一枚打开的圆形通风孔通向齿轮后方。桌灯从钟的左后方照入孔道，内部底板上放着一枚银色戒指。

【多分镜时间轴】

### 0.0s–8.0s｜镜头1：进入隐藏处

**景别与镜头运动：** 以虚拟相机在背板正后方开始，圆形通风孔位于画面中央。视点沿孔轴平滑靠近，孔缘逐渐占满画面，随后穿过有厚度的背板原有开口；进入后沿齿轮之间已有的空隙下降，离开狭窄区时内部空间逐渐显露，最后停在底板戒指前的近景。全程路径连续，孔口与金属实体保持原有形状和尺寸，视点始终通过空隙。

**画面与动作：** 通风孔边缘的漆面与积尘逐渐放大，孔内金属壁遮住外部工作台，随后齿轮和连杆分层显露。齿轮按同一机械结构缓慢转动，视点从空隙通过；到达底板后，完整戒指显露，戒指始终静置，没有变形或移动。

**光影表现：** 左后方桌灯沿通风孔照出一束窄光，内部齿轮有局部金属反光，阴影来自遮挡关系。戒指只在既定光束覆盖处闪出细亮边，不凭空出现第二盏灯。

**音效：** 外部修表间的环境声随视点进入钟体逐渐变闷，连续滴答声和齿轮轻响变得更近；落在戒指时保持机械声，不添加解释旁白。
```
