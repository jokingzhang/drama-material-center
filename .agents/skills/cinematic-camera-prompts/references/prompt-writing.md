# 把摄影机制写成分镜提示词

本页是八种镜头共用的写作方法。下面的句式供改写，正式使用时用当前人物全名、地点、状态和确认对白替换教学内容，并保留项目 `video-shot-prompt-v2`。

## 先写一条能在脑中播放的相机句

**起始机位／景别 → 触发 → 相机路径及速度 → 需要保持或改变的观看关系 → 结束构图。**

例如：“摄影机位于林岚右侧，以侧面中景跟随；林岚走到门边时，相机减速停住，保持林岚与门把手同框，落在林岚伸手前的等待状态。”然后把伸手、握住、转动、开门与通过写到 `画面与动作`，不要用“紧张地丝滑运镜”代替空间和动作。

这条相机句是本地写作组织法，不是所有模型必须遵守的固定语法。Google 的 Veo 3.1 指南将摄影、主体、动作、环境和氛围分开；Runway 的 Gen-4.5 图生视频指南把人物、环境、相机和时间运动分开，并强调清楚表达。二者支持这种拆职责思路，不证明某种中文长提示词会稳定成功。[Google 官方指南](https://cloud.google.com/blog/products/ai-machine-learning/ultimate-prompting-guide-for-veo-3-1/)、[Runway 图生视频指南](https://help.runwayml.com/hc/en-us/articles/48324313115155-Image-to-Video-Prompting-Guide)

## 哪些信息值得写

- **机位**写主体哪一侧、前方还是后方、箱内还是箱外、低位还是平视；“向前跟拍”不足以说明拍脸还是拍背。
- **运动**以相机作主语。人物走、相机走、相机原地转向、镜头变焦分别写清；同时发生用“同时”，先后变化用“随后／到达……后”。
- **稳定项**只保留本镜需要的关系：推拉变焦保留人物尺度，环绕允许背景视差，恒距跟拍保留距离，固定镜头保留机位。不要机械地把所有摄影条件都锁住。
- **可见变化**写背景相对缩小、手从开口上方靠近、门后人群逐渐显露等结果；情绪词放在这些机制旁边。
- **落点**写观众最终看见谁与什么、保留什么反应或完成态，避免只描述开始与过程。
- **参数**只在消除关键歧义时加入。整周与部分弧线要区分；任意高度、毫米数、角度、帧率和小数速度不能成为通用配方。

优先写希望发生的动作，如“相机固定，箱框始终位于画面边缘”。Runway 的 Gen-4 文档明确推荐正向措辞；这是该模型的建议，不能推广成所有模型均不支持否定或负面提示。项目硬约束仍保留，重复的失败清单放在设计／QA 备注。[Gen-4 官方说明](https://help.runwayml.com/hc/en-us/articles/39789879462419-Gen-4-Video-Prompting-Guide)

## 三组必须分开的词

| 容易混写 | 分镜中如何分开 |
| --- | --- |
| 推近、变焦、拉焦 | 推近改变相机位置；变焦改变焦距／视角；拉焦把清晰焦点从一个深度交给另一深度。推拉变焦必须说明前两者如何同时配合，不能写成反向拉焦 |
| 旋转、横移、环绕 | 原地摇摄改变朝向；横移改变位置；环绕改变相机围绕主体的方位。人物转身不能代替相机环绕 |
| 动作速度、播放速度、采样与拖影 | 人物怎样走属于表演；慢放属于播放；断续停留属于时间采样／帧重复；方向性运动模糊属于曝光或合成。分别决定职责再组合 |

Runway 官方相机词库可核对低角度、POV、对称、摇摄、推轨、横移、环绕和变焦的含义。该页部分示例的文字混用了术语，例如 Zoom 行用了 pull back 描述；采用定义并检查几何，不机械照抄示例。[官方相机词库](https://help.runwayml.com/hc/en-us/articles/46749315925395-Camera-Terms-Prompts-Examples)

## 按实际入口适配

**文生视频：** 把尚未由输入建立的人物、空间与光源交代清楚，再写运动；仅写“库布里克风格”无法确定走廊几何和人物路线。

**图生视频：** 先核对已授权输入中的机位、动作状态、朝向与遮挡，正文重点写之后如何变化。图片中已有清楚造型时，不堆叠重复外观；必要的身份、造型和状态绑定照常保留。输入仅支持正面时，不承诺已经证明背面或箱内结构。不得为了适配指南自行新增关键帧。

**长镜头：** 连续观看是一种成片目标。实拍、虚拟相机或经过接缝验证的合成均可能实现；“一镜到底”四字不能证明已消除剪切、瞬移或结构跳变。路线太长时先按实际入口容量调整设计，分段必须保留明确接点；研究资料不自动授权生成或后期执行。

**特殊时间效果：** 抽帧跟拍先定目标外观，再说明由当前模型还是后期承担。不要把教程中的“12fps”改成项目成片帧率，或认为删掉一半帧就自动得到同样曝光与时间感觉。

模型专属的时长、画幅、参考方式和音频能力只对对应入口成立。Runway／Veo 的资料用于理解语言和机制，不覆盖当前剧的画幅锁、台词合同、四字段格式、参考闸门或 LibTV 门禁。当前目标模型未明确时写通用机制，不宣称已支持某项复合运镜。
