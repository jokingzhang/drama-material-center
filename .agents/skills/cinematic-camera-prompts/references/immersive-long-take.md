# 05 阿方索式沉浸长镜头

适合让观众和人物在同一时间经历发现、选择和环境变化，保持现场感。人物的行动目标是观看主线，环境事件同时发生且逐渐被发现；不必是灾难片。

## 必须写清的机制

- 按已有剧情建立前、中、后景职责：近处人物持续做什么，旁人怎样反应，远处哪件事改变处境。背景人物不是全员同时看镜头的装饰。
- 相机与人物的关系有明确路径，如前方倒退 → 从可通行一侧移到侧跟 → 顺视线转向揭示 → 回到动作落点。写地标和走路净空，不用无因绕圈替代调度。
- 相机变化由人物发现、环境信号或行动触发。观众何时知道与人物何时知道分开安排；关键反应不能恰好在相机背向人物时发生却要求看清微表情。
- 实时连续意味着人物、牵手、道具与环境状态持续，不用变装、空间瞬移或多段时间跳跃补全镜头。必要的轻微行走起伏可以存在，不等于全程乱抖。

一个长镜头可以有多个动作与相机阶段，但只有一个时间范围。估算包含行走、发现、转向、反应和收尾的实际容量；空间／事件过载时先减少无关职责，仍超出实际入口再明确生成与剪辑分段，不谎称未验证拼接是一镜到底。

## 可改写的分镜句式

写 **人物当前目标 → 相机起始关系 → 现场信号引导观看 → 人物与环境的因果交接 → 回到行动或反应**。摄影机可以短暂离开主角查看现场，仍要保持人物的位置、路线与进行中的动作连续。

> 同一连续镜头中，相机在林岚与周宁前方倒退，以双人中景跟随；远处棚顶传来雨声时，相机从通道左侧净空移到两人侧前方，顺林岚视线转向雨线与收摊的人群，再随两人转入右侧摊棚，落在棚内侧方的双人中景。自然行走起伏轻微，通道、棚口与人物路线保持可追踪。

前、中、后景只安排实际承担剧情的事件。“背景很热闹”要落实为谁做什么、是否影响人物，以及相机如何发现；关键表演要在可见构图内。不是每个长镜头都需要摇晃、广角、灾难或几十名群众。

[ASC 对《人类之子》摄影的报道与 Lubezki 访谈](https://theasc.com/article/children-of-men-humanitys-last-hope/)支持相机在人物与现场语境之间交接注意力，也指出车内连续观看段落包含无缝接缝。这里写的是成片的连续体验；若实际分段制作，接缝仍须在授权任务中验证。

## 成功标志与返修

观众能追踪人物目标与现场变化，人物路线、注意力、必要动作及声音连在一起，揭示后仍能回到人物选择。摆动不是临场感证明，壮观背景也不能代替角色反应。持续播放检查靠近、接触与躲避等完整状态；轻微机位漂移按既有 QA 分级处理。

## 完整教学例

虚构无对白场景：林岚与周宁穿过集市，跟随突来的阵雨进入棚下。本例用普通现场变化展示连续时间，不添加外星灾难。

```markdown
**总时长：12秒｜画幅：16:9｜无对白、不添加字幕｜场景：傍晚露天集市**

[整体场景与氛围]
林岚与周宁沿集市主通道前进，右侧有已打开的摊棚，远处可见连续摊位。阴云下的柔和天光照亮人群，摊棚内的暖灯已亮起，雨尚未落到两人所在位置。

【多分镜时间轴】

### 0.0s–12.0s｜镜头1：雨来到身边

**景别与镜头运动：** 相机在林岚与周宁前方倒退，以双人中景跟随步速。林岚抬头时，相机从通道空出的左侧移到两人侧前方，顺林岚视线轻轻转向远处雨线，再随林岚与周宁转入右侧摊棚，落在棚内侧方的双人中景。路线始终位于通道与棚口净空内，保持连续行走重量，不穿过摊位或人群。

**画面与动作：** 远处摊主先把布帘拉下，随后雨点击打相邻棚顶，周围行人依次加快脚步。林岚听到棚顶雨声后抬头，林岚看向右侧棚口并握住周宁手腕，周宁顺着林岚的视线转向。林岚与周宁一起跨过棚口停到干燥处，林岚放松握力，周宁拂掉袖口雨珠，两人仍望向外面变密的雨幕。

**光影表现：** 通道天光随阴云加深而缓慢变暗，进入棚口时，固定在棚内右侧的暖灯逐渐照亮林岚与周宁的脸和手。棚外保持冷灰雨色，受光变化来自进入空间，不是瞬间换一套色调。

**音效：** 摊贩背景声持续，雨声从远处棚顶逐渐来到近处，脚步与握住衣袖的摩擦可辨；进入棚下后，雨滴敲击棚布的声音更清晰。
```
