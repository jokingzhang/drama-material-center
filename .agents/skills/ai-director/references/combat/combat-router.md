## 2. 全档通用战斗铁律（专治“站桩对打 / 慢动作推拿 / 爆心瞬移”）

1. **战斗过程严禁无意义静止段**：AI 视频没有“静止蓄势/对峙 2 秒”的张力表现力，写“停顿蓄力、对峙不动”极易变成呆立出戏。**一切情绪、神态与蓄力都必须在运动中完成**（边闪避边蓄力、甩刃转身时冷笑）。唯一允许的极短顿挫是命中瞬间微顿（Hit-Stop，视目标模型能力使用）。
2. **严禁单向打沙包与空气攻击**：双方必须有真实的攻守交换与有效威胁（R1 讲究格挡卸力与反抓破绽；R2/R3 讲究攻守轮次互换与双向受力反馈），不能对手全程被动挨打或攻击只擦破衣角。
3. **严禁站桩原地互殴**：所有出招必须挂在**步法位移、重心转换或空间错位**上（抢步、切侧、后撤卸力、绕背），禁止两人钉在原地轮流挥手。
4. **物理可行性与安全合规**：
   - 打斗动作必须落在可观测的接触与受力回执上（重心偏折、滑退留痕、衣摆甩动、镜头微震后挫）；
   - 如涉及平台合规限制，避免露骨血腥断肢描写，改用「气浪震散 / 火花四溅 / 重创砸嵌 / 暗劲透体 / 残兵落地」等影视化表现。
5. **与本仓库工程门禁完全兼容**：
   - 战斗镜头同样遵守**剧级画幅锁**、**四字段 `video-shot-prompt-v2` 格式**、**禁止在动作正文写画外未绑图人名**、**默认禁用关键帧**；
   - 单元长短依然按需灵活判断：高密度招式交锋与强视角切换宜用较短镜头/单元保打击颗粒度，连续追逐或单侧走位突进可用较长连贯跟拍减少跨节点穿帮。
