# R2 商业高燃 & R3 玄幻大招战斗专档

适用于高燃武侠/动作短剧（R2）与仙侠/异能/玄幻大招斗法（R3）。核心原则：**高对比视觉巅峰、三幕终结技结构、双向力量交换、以及防“爆心瞬移”的空间闭环**。

---

## 1. 视觉巅峰五要素 & 攻守轮次互换

### 视觉巅峰五要素（高潮窗口同时齐备）
`大幅度清晰动作 + 快慢呼吸节奏 + 中/全景空间纵深 + 实体化劲力/特效生长 + 因果随动运镜`

- **R2 商业高燃**：强调开局 0.5–1.5s 硬撞接触、密集近景对招、劲风/火星/碎石反馈与重锤终结；
- **R3 玄幻大招**：切换为**法术与法宝语言**（兵刃/法印起手 → 能量从媒介实体生长，具备核心/边缘/环境光三层质感 → 明确宏观尺度参照物对比，不拿普通拳脚硬套仙侠）。

### 强制攻守互换（拒绝单向殴打）
高燃战斗必须设计清晰的局势起伏，防止主语偏置把对手写成纯沙包：
1. **压制/硬撞段**：对手先手施压或双方正面硬撞，主角出现真实受阻反馈（滑退犁地、护体震裂、虎口震麻）；
2. **中段互搏/转折**：贴身双向受力或险中抓破绽，打破平衡；
3. **逆转终结**：在绝境或抓准空档后释放压轴招式完成反杀。

---

## 2. 终结技三幕结构（破局 → 绽放 → 余震）

压轴大招禁止一句话“一剑劈飞结束”，必须分三幕写出因果过程：
1. **第一幕 · 破局（Break）**：化劲引偏、重击砸开防御架、破坏下盘或切入死角，先制造明确破绽；
2. **第二幕 · 绽放（Burst）**：全力发力释放（凌空下劈、贯穿寸劲、旋风连斩、剑光/术法实体倾泻），写出能量从身体或兵刃长出的路径；
3. **第三幕 · 余震（Shock）**：命中点裂纹扩散、环形气浪掀尘、受击者沿清晰力学抛物线飞出，以及镜头受力后挫震屏。

---

## 3. R3 玄幻收尾三大空间闭环协议（防“爆心瞬移穿帮”）

> 大招把地面炸成深坑或强光吞没爆心后，模型常丢失人物位置，容易在前景凭空刷出一个跪地对手。收尾阶段必须明确选用以下三协议之一：

1. **协议 A · 遗物定场型**：前景不再出现败者肉身；爆心烟尘深坑边缘仅斜插一柄断裂冒烟的残兵/破损法器，镜头拍胜者背影与残兵拉远。
2. **协议 B · 远景抛飞隔离型**：禁止在同一平面同框；明确写败者被冲击波呈抛物线轰飞至远处断裂岩壁/立柱嵌住，拉出前景胜者与远景败者的强前后景纵深隔离。
3. **协议 C · 光粒消散型**：大招贯穿瞬间，败者或魔物当场瓦解化作漫天属性光粒/余烬随风倒卷消散，前景仅留胜者与残留战场环境。

## 4. 经典动作运镜模式速查（选 1–2 项组合，写清物理路径）

| 模式 | 适用瞬间 | 写入正文的可见相机机制 |
| --- | --- | --- |
| **低仰蓄力推近** | 大招起势 / 气场压迫 | 中景低角度 30° 仰拍缓推，能量在兵刃/掌心向内螺旋收束，凸显人物高大压迫 |
| **轨迹拖尾跟拍** | 高速斩击 / 飞踢 | 30°–60° 斜侧平视紧跟兵刃或肢体末端高速运动，拉出清晰速度拖尾与空气波纹 |
| **接触点急推** | 破防 / 兵刃硬撞 | 极速推至刀刃/拳面接触点特写，双色火星与气浪在接触面炸开咬合 |
| **全景冲击波急拉** | 绝杀爆点 | 双方重击对撞瞬间以爆心为圆心急速后拉至全景，展示环形气浪与地面放射裂纹 |
| **不对称压迫** | 实力悬殊 | 压制方剑光/火焰占据画面三分之二，被压制方缩在角落勉强格挡 |
| **攻击部位冲镜** | 窒息代入感 | 拳面/剑尖直冲镜头中心快速逼近，背景拉出强透视速度线 |
| **力量交换连切** | 高潮贴身互搏 | 斜侧双拳硬撞 → 弧形跟拍重击 → 局部特写受击形变 → 急甩跟拍倒飞 |

## 5. 高燃打戏避坑检查

- **单镜负载克制**：2–4 秒的高频节奏镜头里，**一镜只承担一个核心任务**（证规模 / 证速度 / 证力量碰撞 / 证情绪），绝不在 3 秒内塞入 8 个微操导致动作糊成一团。
- **不以静止收尾**：R2/R3 高潮段最后切点尽量停在冲击波扩散、嵌墙定格或残兵插地的高能瞬间，不加平淡的“慢慢收剑站好”。
- **合规安全转译**：以冲击波、火星、碎甲、尘爆、光粒替代血腥断肢描述。
