# Stage 3｜四类资产闭环（角色 / 场景 / 道具 / LibTV 固定音色）

本阶段承接 Stage 2《本集最小资产缺口清单》，负责**盘点复用 → 写提示词 → 授权内创建/生成 → 打开核看/试听 → 正式落盘登记 → 反校分镜**的完整闭环。

> 遵循仓库根 `AGENTS.md` 3.1 节五字段 schema（`materialType / subject / targetDir / version / storyBinding`）、跨项目自包含原则，以及 [关键帧审核门槛](../SKILL.md#keyframe-approval-gate)（默认禁用关键帧）。

---

## 1. 四类资产默认生成/创建路由（项目 Harness）

获得当前资产制作授权时直达对应默认入口（用户当次明确指定的工具/模型/画质优先）；未获得生成授权时交付完整资产提示词与缺口表，不自动花费。

| 资产类型 | `materialType` & 标准目录 | 默认生成 / 创建路由 | 核验与一致性硬标准 |
| --- | --- | --- | --- |
| **角色标准图** | `image.character`<br>`library/图片/人物/<CHAR>/<LOOK>/` | 新女性角色可先走 [ruic-character-reference](../../ruic-character-reference/SKILL.md) 选脸 → [character-visual-designer](../../character-visual-designer/SKILL.md) 设计外形与提示词 → 默认调用内置 **`imagegen`**（指定 LibTV 时经 `libtv-cli`） | 每人每套可见造型默认一张 **3:4 竖版四宫格**（左上正面胸像、右上四分之三侧胸像、左下全身背面、右下全身正面）；浅灰中性背景、柔和均匀光、无文字边框；四视图脸/发型/服饰/鞋履/伤病完全一致；**禁止手持独立道具或花哨摆拍** |
| **场景母版 & 分视角图** | `image.scene`<br>`library/图片/场景/<LOC>/` | 官方 **`libtv-cli` → Lib Image**（`high / 4K`，**16:9 横图**） | **即便 9:16 竖屏剧也统一出 16:9 横版大图**以保留空间纵深与多人座次锚点；先出干净无人物场景母版，再按 Stage 2 机位视角表用母版 **`image2image` 派生同场景分视角图**（正打/反打/侧向/过肩视角），确保建筑、材质、家具、光向与 4K 清晰度统一 |
| **关键道具图** | `image.prop`<br>`library/图片/道具/<PROP>/` | 默认调用内置 **`imagegen`** | 纯净无手、无人物入画；区分开合/完整/破损状态；**含中文文字（合同、票据、屏幕、标牌等）必须在提示词逐字写全正文、数字与单位，成图开图逐字核验**（OCR 仅辅助） |
| **固定音色（角色声音）** | `audio.voice`<br>`library/音频/人物/<CHAR>/` | **默认使用 LibTV**（`libtv-cli` → `audio` 节点；先执行 `libtv model search --type audio` 与 `libtv model <modelKey>` 核实可用语音模型与参数 schema） | 覆盖所有在画面或音效中发声的具名人物（**既包括逐字对白，也包括笑、惨笑、哭泣、怒吼、叹气、喘息等非台词人声**；仅一次性无台词/明确豁免配角可免）；先写 `prompt.voice`（年龄、音质、语速基准、情绪范围），授权后通过 LibTV 创建运行并**实际下载试听**，确认音色稳定、无杂音后再落盘登记 |

> **写实奇幻生物（如白龙）初始造型**：沿用 `libtv-cli` → Lib Image（`high / 4K`）；**获用户特批的关键帧或局部改图**：默认内置 `imagegen`（改图前必先打开原图）。

## 2. 执行五步法（每项资产走完闭环才算可用）

1. **先盘点复用，不造无消费者资产**
   - 读取 `production/asset-bindings.v1.json` 与现有原图/音频；已有且视角/造型/状态相容的直接复用，**不重复生成**。
   - **严禁跨项目直接引用**：确需借用其他项目资产时，必须先复制到本项目标准目录、使用带本项目标识的新文件名与版本号、核对 SHA-256 并重新登记。
2. **明确唯一主职责与消费者**
   - 每张拟生图片/音色必须绑定到具体消费单元与镜号（例如 `LOC-STUDIO-REVERSE-v04 → EP52 U03/U04/U06`），不能泛泛批量出图后再找用途。
   - 检查**可见相容性**（假设模型照单全收图中所有像素，会不会穿帮？如开门完成态图不能拿去拍闭门起点）。
3. **写纯净、自包含的资产提示词**
   - 提示词正文只写画面/声音描述，**禁止把“同上 / 见母版 / 图N / 流程编号”写进生成正文**；每条提示词必须能独立生图。
   - 场景图写清世界光源方向与固定地标（窗、门、长桌、通道），不塞路人；同场景昼夜成对或分视角必须基于已验收母版做有约束的图生图。
4. **授权内生成并实际核看 / 试听**
   - 图片：必须实际打开原图放大核看皮肤、五官四视图一致、手脚完整、空间地标、光向与中文文字，记录真实像素与 SHA-256。
   - 音频（LibTV 固定音色）：下载真实音频文件，实际试听音色、自然度、清晰度与时长（兼顾 Wan 3.0 引用音频累计 ≤15 秒上限约束）。
   - 局部不合格时定向返修新版（`vNN+1`），不覆盖旧版，确认替代后再将旧版标为 `SUPERSEDED`。
5. **正式落盘登记并反校 Stage 2 分镜**
   - 写入 `production/asset-bindings.v1.json` 与 `production/story-index.v1.json`（稳定 `assetId`、相对路径、`sha256`、`status`）。
   - **资产反校镜头（关键！）**：看完成图后立即回头核对 Stage 2 的机位、前景/后景地标、人物起点姿态与光向；如实图与初设构图有细微差异，先修正分镜与视角分配，确认无冲突后再进 Stage 4 编译提示词。

## 3. 边界纪律

- 生成成功、文件落盘、登记索引、视觉/听觉验收、用户 `ACCEPTED` 是五个独立状态，**交付报告必须分开写清**。
- 导演内部使用的俯视站位和镜头调度图留存在 `创作记录/`，**绝不登记为视频生成输入**。
- 声音混音、跨镜声桥与后期 BGM 安排另由 [sound-music-director](../../sound-music-director/SKILL.md) 协同落实；默认视频生成不带随机 BGM。
