# Stage 2A｜空间调度与演员表演（反 PPT 核心引擎）

本文件把 Stage 1 的导演决策落实为**活人之间的空间博弈与真实行为**。
核心公理：**表演是压力下的行为，不是站着展示情绪；空间是权力关系的可见图表，不是换景背景板。**

---

## 1. 空间调度环（图留在导演记录，字写进提示词）

### 1.1 内部俯视站位与视角图（必做于新写、重设计及多人戏）
- 先看已有场景母版，绘制/复用**俯视站位与镜头调度图**（固定地标、门窗光源、座次、朝向、持物、人物路线、每镜机位与朝向），统一存放在 `创作记录/<agent>/空间调度/<run-id>/`。
- **绝不把调度图绑进 `referencePlan` 或视频节点**（除非用户对特定镜头明确特批）。它是导演用来保证不越轴、选准每镜 16:9 分视角场景图的思考工具。

### 1.2 双重空间锚定法（绝对方位 + 画幅投影）
- **导演稿用绝对方位**：以固定地标定位（`靠拱窗北侧 / 玻璃门入口端 / 长工位中段`），绝不用易随切镜翻转的“画面左/右”当唯一坐标。
- **翻译进分镜与提示词用双重锚定**：写清 **画幅位置与纵深（画面左前景 / 画面右后方）+ 场内相对方位（以地标或某人朝向为基准）**。
- **每人有物理依托**：人物站位尽量绑定桌沿、椅背、门框、柱子等固定物；悬空站位最容易导致模型漂移。

### 1.3 权力几何（Power Geometry）
用空间变化演关系，不要全靠台词喊：

| 维度 | 受压 / 低权力 | 占优 / 高权力 |
| --- | --- | --- |
| **高度** | 坐、低头、俯身、处于低台阶 | 站立、直起脊背、居高俯视 |
| **领地** | 退至墙角或边沿、背对退路 | 占据中央活动区、卡住出口或桌面主场 |
| **遮挡** | 被门框/物件/对方肩背压住半身 | 视线开阔、占据主光区 |
| **距离（Proxemics）** | 被迫后撤或僵在原位 | 主动逼近破线（进入 <0.5m 亲密/侵略区）或冷然抽身拉开距离 |

> **硬规则**：除明确声明的纯过场戏外，**场末的权力几何必须与场初不同**（至少在高度、距离、领地或遮挡上发生一次可见翻转）。

### 1.4 动作五段闭环与群像开关
- **关键动作五段闭环**：`起势 → 路径（绕过固定物，禁瞬移穿模）→ 接触/阻挡 → 落点 → 接收者反应`。
- **群像三档开关（多人/公共空间必显式裁定）**：
  - **A 档（叙事群像）**：公共空间且旁人承担围观/偷听/施压作用 → 为可见次要人物分配具体低幅度事务（低头整理/交换眼神/停手侧耳），错峰反应，**严禁全员同步机械转头**；
  - **B 档（氛围密度）**：场景有背景人但不参与叙事 → 只写环境级低频活动密度，不抢主焦点；
  - **C 档（封闭聚焦）**：密闭双人戏、纯特写、打戏或四下无人 → 明确场地内仅限已绑图的在场角色，杜绝模型乱刷路人。

## 2. 演员表演设计（专治“站桩念词 + 表情包”）

### 2.1 行为五支柱（把“生气/难过”翻译成争夺）
为本场主要角色明确五项，**永远不要只写情绪形容词，要写压力下的可见行为**：
1. **目标（及物动词）**：此刻想从对手身上拿到什么（逼他签字 / 让她留下 / 守住尊严）。
2. **障碍与代价**：什么挡着他，拿不到会失去什么。
3. **战术换招**：战术失败就必须换招（施压 → 放软 → 威胁 → 抽离）。**一次换招必须伴随一次可见的身体/节奏/姿态变化**（停顿、换坐姿、放下手里的东西、压低声音、逼近一步）。
4. **潜台词**：嘴上说的话与手里/眼神暴露的真实意图之间的落差。
5. **物理四参**：重心（高挺/低垮）、节奏（急乱/沉稳——**最危险的人动得最少**）、开放度（敞开/抱臂收拢）、呼吸（浅急/深慢）。

### 2.2 打破 PPT 的三大表演抓手

1. **Business（手上活 / 身体任务）**
   - 角色不要干站着聊天——让他一边推回文件、摘戒指、合上文件夹、按住桌沿、整袖口、倒水、擦杯子，一边说话。
   - **最强的戏剧重音 = 停下手上的活**：正在收拾资料的手在某句话前突然顿住，比吼出来更有电影感。
   - 纪律：身体任务必须符合既有剧情与道具状态，**不为显生动凭空编造多余物件或频繁起坐**；手已承担关键动作时，不给同一只手派冲突任务。

2. **听与反应（表演活在台词之间）**
   - **听者不能等轮到自己说话才开机**：对方说到半句关键信息时，听者的视线、呼吸、手部或下颌就应该已经开始反应。
   - **想在前，说在后**：回答难问题前留出极短的评估瞬间（眼神微收、呼吸一顿、吞咽），告别“AI 抢答式背台词”。
   - **对白三链**：`说话者（发出）→ 听者（接收·必须可见）→ 第三方/道具（态度外化）`；长对白绝不能只拍说话者念完一整段。

3. **情绪残留闭环（严禁说完台词瞬间归零）**
   - 有实质情绪转折时，按连续因果展开：`触发 → 可见身体反应 → 表达或动作峰值 → 残留/回收状态`。
   - 残留不是强加静止特写，而是让已经变急的呼吸慢慢平复、抬起的手落下而非瞬间消失、紧绷的下颌微松、视线仍停在对手或落到桌上——给下一镜留出可继承的真实终态（戛然而止、主动伪装或外力打断则写明中断原因）。

## 3. 台词重音、标点演法与状态链

### 3.1 台词重音字显性化（逐字台词零改动）
- 在分镜规划阶段，为关键台词标出 **1 个核心重音词**（对比句最多 2 个），统一对齐三处：
  1. **挂特写/推镜点**：重音词所在句给视觉强调，不要每句都特写；
  2. **微表情峰值**：眼神/面肌/呼吸变化峰值对齐重音词，而非句首；
  3. **发声与重读**：在音效/表演描述中指明该词的咬字、压低或收住，**绝不改动合同里的任何一字**。

### 3.2 标点 → 可见表演转译（禁止写“说到逗号时”）
将标点意图转译为具体动作时机（如“说完前半句后”“语气一转时”）：
- **停顿/逗号**：轻吸半口气、视线掠向桌上物件、指尖微顿；
- **句末收尾**：视线不立刻移开、呼吸沉下、下颌微收（留余波）；
- **问号**：先定意图（试探 / 逼问 / 哀求 / 讽刺），再定视线压迫或收音，禁只写“疑惑地问”；
- **感叹号**：能量上冲或刻意压低重咬，**不默认一律吼叫**；
- **省略号 / 破折号**：气断卡喉、话头急刹、嘴唇微张又抿回；
- **沉默**：必须写视线去向 + 呼吸 + 身体微小泄漏，禁干写“两人沉默”。

### 3.3 视线与注意力转移规则
- **直接交流**：无操作或回避时，头脸与目光指向受话者（含画外受话者的真实场内方位）；听者目光随信息在说话者脸部、手部与关键道具之间有因转移。
- **物品操作**：需要辨认/对准时看物体，确认对方反应时再抬眼看人；目光转移按 `原对象 → 触发刺激 → 新对象` 写清。
- **防克隆/防错指**：画外且未绑图的人物，在景别与动作正文中**绝不写全名**，统一写成具体场内方向（如“画外入口方向”），仅逐字对白内的称呼保持原样。

### 3.4 镜级 `状态：前 → 后`（防姿态回退与道具瞬移）
- Stage 2 规划阶段，每凡发生起身/坐下、前倾/后撤、拿起/放下/推回/换手、开门/关门、视线大转等变化，必须显式写清 `状态：进镜姿态与持物 → 出镜姿态与持物`。
- **该标签仅存活在规划与预览层，Stage 4 编译进模型正文时转为自然动作描写，不保留元标签。**
