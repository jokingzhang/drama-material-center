# Writer role｜历史路径兼容

当前写剧本、改剧情、创作／修改／诊断对白的业务入口已独立为 [script-writer](../../script-writer/SKILL.md)。本页仅保留旧链接的可达性，不再定义 ai-director 内的 Writer 阶段。

用户直接提供剧本时，可直接进入 [ai-director](../SKILL.md) 做分镜与图片素材，不要求先调用编剧 Skill 或重写一份剧本。恢复真实来源、版本和已有确认范围即可；脚本与台词确认规则仍沿用根规范。

分镜发现台词问题不自动授权改词。只有用户明确要求修改相应范围时，才由 script-writer 更新剧本与逐字台词合同，再同步受影响分镜；用户明确采用的精确替换无需再次确认。
