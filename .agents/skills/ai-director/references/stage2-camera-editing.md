# Stage 2B｜摄影选镜、灵活长短单元、切点与转场

本文件整合了叙事选镜、摄影光影、长镜头、切点转场与特殊电影镜头的全部执行标准。
优先级铁律：**物理可行性与空间真实 > 叙事清晰与表演可读 > 形式多样性**。

---

## 1. 选镜三步法（先拍谁，再靠多近，最后填参数）

1. **先选拍谁（承载变化的对象）**
   - 每镜只有一个主要观看目标：发起者的选择、听者收到信息后的改变、第三方的态度，或手与关键道具的因果变化。
   - **说话者不自动获得镜头**：台词由原说话者连续发出，当关键反应发生在听者或证据落在桌上时，画面果断给听者或道具。
2. **再选靠多近（景别 × 表演幅度绑定）**
   - 每个景别只能承载它装得下的动作，**严禁在特写里写全身走位，也不在全景里堆五官微肌**：

| 景别 | 叙事职责 | 只能/优先写 | 禁止写 |
| --- | --- | --- | --- |
| **远景 / 全景** | 空间关系、领地压迫、行走路线、群体格局 | 身体线条、站位距离变化、进出画、环境吞没感 | 细微眼皮/嘴角微表情 |
| **中景 / 半身** | 身体策略、双手操作、双人距离与接触 | 手部动作(Business)、肩线重心、前压后撤、与固定物关系 | 堆满五官细节 |
| **中近景 / 近景** | 对话主力档、过肩关系、态度变化与肩颈联动 | 视线路径、呼吸起伏、手指小动作、前景遮挡关系 | 完整腿脚位移或跨桌长传 |
| **特写 / 大特写** | 情绪拐点、眼神记忆点、重音句、关键道具指认 | 眼神对焦、眼睑、唇线、喉结、下颌、局部手与道具触点 | 胸部以下大幅动作或多人站位 |

   - **影像基底感知**：写实/3D 风格下，人物脸部特写优先带角度（侧 45° / 微俯仰 / 过肩），避免无纵深的纯正面平视贴脸；2D 风格可放宽但同场不连用 ≥3 次。
   - **密度互斥**：镜头运镜复杂时演员动作简化；演员动作复杂或台词密集时运镜收稳，避免互相打架。

3. **最后填机位、焦段、景深与运镜**
   - **方向 × 高度双轴**：对话默认优先**侧 45° / 过肩 / 双人同框**；用**微仰/仰拍**与**微俯/俯拍**服务权力几何，不靠全程平视正反打。
   - **焦段与透视**：广角（24–35mm）用于定场、空间纵深或刻意压迫畸变；标准（35–50mm）用于客观中景互动；中长焦（85–135mm）用于肖像、情绪逼近与压缩背景；微距用于关键小道具与局部触点。**透视由机位距离决定，只写有效光学倾向，不堆砌无意义器材参数。**
   - **景深服从信息**：前后景必须同时读清时（如前景说话、后景有人推门）保持足够清晰范围，**绝不盲目虚化背景**；焦段切换或移焦（Rack Focus）必须由视线或动作事件触发。
   - **运镜必须有动机**：区分**推/拉（改变压迫或揭示环境）、横移/跟拍（跟随路线或穿越遮挡）、摇转（视线发现）、固定（让强表演自己成立）**。写清起始物理侧、触发原因、速度节奏和落点；禁止无动机的来回漂移。
   - **光源遵循世界连续**：同一场景的主光源（窗、门、主灯）在物理世界固定，反打后画面左右受光侧相应翻转，不能换机位就凭空换光源；材质只写本镜可见的真实反光与质感，不套统一滤镜词。

## 2. 灵活长短单元策略（不限死时间，彻底打破 PPT）

**核心原则：绝不机械规定“必须拆成 5 秒短段”或“必须凑满 15/30 秒”。生成单元的长短完全服务于“防穿帮 + 电影叙事收益”：**

### 何时用长视频节点（如 10–15s+）
- **适用**：连续走位与空间发现、一气呵成的动作因果（如收拾资料→起身→绕过桌沿走向出口）、情绪连续递进且**避免跨节点人物/服装/道具状态漂移**。
- **长节点反 PPT 硬要求（绝不允许 10–20s 固定机位站桩大头贴！）**：
  1. **要么有真实镜内调度（长镜头 LT 原则）**：相机跟随人物走位、推近/环绕换轴、焦点在人—物—人之间转移，或人物有连续的 Business（手上活）与距离变化；
  2. **要么在同视向内做多镜组合**：同一 16:9 场景视角下，自然拆成 2–3 个互补镜头（如 `双人侧向中景建立 → 桌上道具/手部特写 → 带角度单人逼近近景`），在不触发互斥视角冲突的前提下提供电影级镜头呼吸；
  3. 遵守连续镜头边界：全段一镜到底时只写 1 个时间块，动作节拍在正文自然推进，不假拆时间段；确有真实切镜才起新镜头块。

### 何时用短视频节点（如 3–8s）
- **适用**：强正反打交锋（需要互斥视角背景图）、高危复杂接触动作隔离、情绪重锤的精准听者反应镜、或配合后期 **L-cut / J-cut 声画错位**。
- **L-cut / J-cut 声桥破局法**：长台词不必等说话人念完 20 秒才切单元——可以让说话人连续念完原声，中间插切 **3–5 秒的听者无声反应短单元或道具短单元**，在剪辑备注里写明“保留说话人原声跨覆听者反应画面，听者保持倾听口型”。这是打破长对白 PPT 感最有效、最像真电影的手法。

### 多用双人关系镜，少用孤立单人轮切
- 单张 16:9 侧向场景图完全能容纳双人同框或过肩构图。长对白场次（含台词镜 ≥4 处或对峙戏）**必须包含至少 1 个双人同框或过肩关系镜**，让观众持续感知两人距离与力量对比，而不是两段孤立独白。

## 3. “第 N 秒追问”与 7 项拖沓/PPT 复检

在 Stage 2 定稿前，对每个镜头逐一追问：**“如果这个镜头长 8 秒，第 5 秒到第 8 秒承载了什么新的动作、反应、信息变化或有职责的悬念？”**

逐条清理以下 7 类常见 PPT 病灶：
1. **静态站桩念长词**：单人固定机位超过 6–8 秒，既无走位/手上活变化，又无景别/运镜/焦点推进，纯靠红眼眶干念台词 → **必改**（拆同视向多镜、加镜内调度/Business、或切听者反应+声桥）。
2. **机械听者反应镜**：每句台词后机械补一个无新态度变化的点头/愣住镜头 → 删并，只有态度、策略或信息真正改变时才切反应。
3. **无职责起势与拖尾**：起势无因果、反应已完成却为了等运镜停稳或凑时长白白多留几秒 → 收紧。
4. **重复状态碎切**：为覆盖一句话硬切多镜，每镜构图相近且重复交代相同状态 → 合并为连续表演或拉大景别/角度差异（≥30°）。
5. **全片固定/平视过量**：连续 ≥3 个镜头完全相同景别或全部固定平视正拍 → 重排机位高低与景别阶梯。
6. **无差别语速**：冲突急问与虚弱低语套同一种估时节奏 → 按真实情绪、重音和换气重估。
7. **无动机空镜凑数**：没有时空交代、缺席后果或情绪余韵职责的纯风景空镜 → 删去（非人物点缀镜通常占 10%–20%，按需穿插）。

## 4. 切点与转场（最小有效路线）

把转场当作**两个镜头共同完成的一次叙事动作**，按最小有效优先级选用：
1. **有动机硬切 / 声音桥（J-cut 声先画后、L-cut 声延画切）**（首选，覆盖 80%+ 接镜）；
2. **视觉匹配接镜**：动作顺接（跨镜保留短动作重叠，剪辑只留一次动作）、视线匹配、前景全遮挡切、图形/轮廓匹配、运镜方向延续；
3. **剪辑软件处理（`EDIT_ONLY`）**：叠化、入出点精剪、调色/声音交叉淡化；
4. **生成式过渡（`GENERATED_BRIDGE` / `IN_SHOT_GENERATIVE_TRANSITION`）**：仅在明确时空穿越、梦境或风格渐变时使用，只保 **1 个主铰链**，绝不把甩镜+闪白+形变+粒子堆在一起。

- 关键接点在《分镜执行表》或剪辑备注中写成 `A 出口状态 → 主铰链 → B 入口状态`，明确标注归属 `EDIT_ONLY` 还是需生成内容；**绝不把“J-cut / 视线匹配 / 无缝转场”这类术语裸写进视频模型正文**，只写模型能执行的可见动作与画面。
- **跨单元接镜严禁假长镜头**：两个独立生成单元之间，除非有明确动作重叠设计，否则优先用**明显的景别或角度变化**衔接，绝不把两个几乎一样的中景硬接在一起制造跳帧穿帮。

## 5. 八种大师电影镜头速查（按剧情触发，只写可见物理机制）

仅当剧情或用户需求真正需要时选用，**绝不为了炫技强加事件或堆砌导演姓名**：

| 观影目的 | 镜头类型 | 写入正文的可见物理机制（不写术语空壳） |
| --- | --- | --- |
| 突然意识到真相、危险或心理失衡 | 推拉变焦（希区柯克式） | 相机沿人物正前方后撤同时焦距拉长（或相反），人物在画内大小保持近似不变，身后走廊/背景明显拉伸或压缩逼近 |
| 角色登场、起身反击、取得全场主导 | 英雄环绕（迈克尔贝式） | 低机位贴近人物并沿水平弧线绕主体换侧（写明顺/逆时针与起止侧），背景建筑产生明显视差位移，而非人物原地自转 |
| 沿线索进入隐蔽核心 | 虚拟穿越（大卫芬奇式） | 稳定虚拟相机沿明确净空路径穿过具体开口（门缝/锁孔/窗隙）进入隐藏空间，写清穿前与穿后的可见锚点 |
| 俯视视角压迫 / 揭示箱内秘密 | 箱内固定视角（昆汀式） | 相机固定置于箱底/低位向上仰拍，由盖子打开、光洒入、人物俯身靠近与伸手拿取改变画面 |
| 与人物共历不断升级的危机现场 | 沉浸跟拍长镜头（阿方索式） | 一镜到底贴身跟随人物穿过事件现场，机位随人物发现自然摇移与重新构图，人物与环境危机同步发生 |
| 孤独、迷离、记忆流动 | 抽帧拖影跟拍（王家卫式） | 横向贴身跟拍行走主体，主体相对清晰而背景人流呈现抽帧低帧率与动态拖影（多需生成+后期配合，须注明） |
| 秩序压迫、诡异对称走廊 | 低位对称跟拍（库布里克式） | 低机位居中沿单点透视中轴匀速前推或后退跟拍，两侧重复结构严格对称向消失点收拢 |
| 穿过后门与社会反应交代人物身份 | 空间穿越长镜头（斯科塞斯式） | 连续跟拍人物穿过服务区/通道进入主场，沿途工作人员让路、招呼、递物的社会反应直接交代人物地位 |
