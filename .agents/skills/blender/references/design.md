# 需求与简化程度

## 分配控制责任

- **必须可见的事实**：机位物理侧、关键遮挡、主体入画/退出的位置、靠近/退开方向、不能错的人数、道具归属、动作起止、切点。
- **可用简化信号表达**：奔跑的根位移、闪避的横移和降身、攻击的逼近与接触时刻、受力退让、追击方向。不默认演算每一步。
- **外观/表演层**：脸、服装、肌肉、衣摆、四肢动作、步态、眼神、微表情、自然惯性。交给角色参考和下游模型，不在本项目白模里添加四肢来示范。

这不是模型能力保证。简化后仍要看清逼近或退开、道具属于谁、跨过哪扇门；表达不足时先调整整体轨迹、道具状态和机位，不添加四肢或机械跑步循环补救。

几何遵循最小够用：一个人物优先一个色块，朝向确有必要时才补最小轮廓；建筑只留空间边界和镜头中的地标，道具只留尺寸、朝向、归属与必要状态。省掉装饰、纹理、服饰、复杂灯光和无关特效模拟。灰白环境加稳定身份色即可，不能把“红白模”误解为所有角色只能共享一种颜色。

## 按镜头需求设计

| 需求 | 白模应明确 | 避免 |
| --- | --- | --- |
| 绕车跟拍、列车旁揭示骑手 | 起始透视，车/窗/道路占位，视差，揭示时刻，运动方向与末构图 | 无关车内细节、机械马腿动画；把不同案例的输入混为一条链 |
| 群像与过肩 | 固定座位/颜色，物理侧，肩部覆盖范围，对面人物可见区，注意力转移 | 仅检查中心点；前景滑出或遮住目标；为找说话者擅自改镜 |
| 倒退拉胶带、划地盘 | 起点、放带者、路线、连续增长、终点和观察者反应时间 | 只放大步幅；同速全程；雕家具却没让长线与意图入画 |
| 进出门/电梯/车辆 | 门轴、门洞、摄影机侧；接触、打开、跨越、落位先后 | 看不到门口的尾帧；坐标穿过平面冒充进入 |
| 递接/单武器转移 | 同一实体；释放方→过渡→接收方；可见支撑变化 | 复制/显隐留下双份；只修文字却上传旧视频 |
| 攻防、闪避、追逐 | 双方朝向；威胁→响应→接触或避开→受力/恢复→下一行动 | 无接触就退；受击方先退；双方一起漂移；无理由重复攻击 |
| 产品穿行/快切 | 尺寸、轨迹、转向、速度重音、间隙、停点和剪辑节奏 | 默认做标签/液体模拟；无合同就插黑场等模型补齐 |

## 喜剧、夸张与精确表演

要求“比原片更好笑/夸张”时，先拆解对照缺少的可见反差：准备认真而行动突然、动作规模与小事的反差、观察者反应滞后、急停后的自信停顿等。选与剧情相容的具体节拍，不默认全部加入。

用无四肢占位体的整体轨迹、高度与节奏表达准备→爆发→停顿/反应→收尾，正常速度检查这些节拍是否清楚。大位移不等于大表演；这类示意也不证明下游动作会自然。精确人体表演超出本白模的证明范围，不能自行增加绑定与步态后宣称满足。

## 四肢与走位

- 人物在所有镜头中都用没有手臂、手、腿、脚的色块、柱体或胶囊。底部位置表达整体路线，简单朝向标记表达面向；坐姿以占位体的高度和位置示意，不搭关节人偶。
- 不生成步态循环，也不保留局部手掌、鞋子等人体接触代理。不能以“这处接触需要”“有动作来源”“已经验收”作为自行加四肢的例外。
- 踩布、抓布、递接等用主体与同一道具的距离、道具约束解除、归属变化和连续轨迹示意。计算需要的接触锚点用不可渲染的空物体；干净视频不输出悬浮接触球、箭头、标签或手鞋替身。提示词说明谁踩、谁收、谁试走。
- 例如 EP11：橙色供应商占位先退离布端；同一纱幔解除约束后收拢到青色江砚秋一侧的花柱底座；通道清空后，蓝灰工作人员占位沿通道前进。保留先后与空间结果，抬脚、抓握和迈步由下游生成。若当前构图让布像无主自移、归属不明，先调整关系和构图；仍不清楚则标为未验证，不追加四肢。
- 下游可能继承僵硬四肢和固定脚姿；文字不能抹去这些像素。无四肢占位体的整体移动只是路线示意，不得把它宣称为已经验证的自然走路。

EP11试走案例的用户反馈：剧情大意成立，但末段人物腿不动而漂移；此前仅按接触与通道完成态判断通过，漏掉了运动参考的误导。用户明确要求以后白模只做示意、不要四肢，这是当前项目规则。旧输入资格应撤销；无四肢方案尚无下游实测，不能预先承诺效果。

## 动态路线与连续性

对话、持续运动和混合段按实际时间区间处理，不因一个动作词套整段打斗模板。对持续位移、追逐、连续避让或受力变化，先明确主体的运动目标、障碍和经过的地标；对话部分仍保留倾听、视线和呼吸的节奏。一个拍门动作只需补关键接触，不必重做整套动作系统。

- 地标同时表达尺寸和可行区域：地面、台阶下、平台上、门洞内各是什么；哪里能走、能站、能穿过、允许破坏。不能把“来到中央”自动解释成站上中央物体。
- 用人物身高、门高、台阶高或车辆长度建立尺度锚点。近景切全景保持真实尺寸，远处变小来自透视；前景、行动区域和背景分开，先留足路线和镜头视线。
- 普通奔跑/攻防用连续整体轨迹表达；只细化决定结果的接触或险避：威胁方向与距离→接触点/最小间隙→主要受力变化→可见结果→下一动作起点。结果可由必要的重心、道具偏转或环境痕迹表达，不固定要求特效数量。
- 中间路径节点通常表示经过；短暂停顿、制动和转向由动作意图决定。动作中切时继承位置、朝向、速度、动作阶段、手中道具和可见环境变化；剪辑本身不生成新的根轨迹。
- 烟、雪、火和法术只影响约定区域，不能用遮挡掩盖地标消失、角色误站或接触缺失。下游可以补细节，但白模必须先给出正确几何事实。

组装车辆、门或多部件道具时，用一个根对象携带整体运动，必要部件用独立枢轴；按环境、主体、运动 rig 和摄影机组织集合。尺寸相关的 bevel、boolean 或物理处理前检查 scale。朝向必须可读时增加最少轮廓标记，圆柱颜色本身不能说明正背面。

## 镜头角度、时间与速度

先设计镜头，再补足该镜头所需的几何。每镜明确：摄影机位于主体/门/桌的哪一侧、相机高度、平视/俯视/仰视、主观/客观视角、景别/焦距，以及起止构图。角度要服务于追击、压迫、搜寻或揭示等具体意图，不能默认整段同一个斜上方总览。过肩明确从谁的哪侧看谁；低机位不自动等于仰拍，抬高相机也不自动等于向上摇。

按可见节拍分配时间：建立关系、动作触发、变化过程、反应与完成态各需多久，写成秒数并换算为帧。按动作和信息落点切镜，不把总时长平均分给每镜；短镜头可作重音，关键揭示后留出看懂的时间。新增/删减镜头时，同步改后续时间、主体轨迹、相机、状态和声音位置，重新检查相邻切点；固定总时长装不下时重新分配，不能静默整体加速。

**整段不能一直一个速度。** 相机平移、相机转向、主体根运动分别安排速度阶段与触发点。可按需求用慢搜寻→快速揭示→减速落稳，或短暂蓄势→快速逼近→停留反应；不把这些例子固定成每镜必套的曲线。固定镜头可通过主体运动与镜头时长形成节奏，短暂匀速可承担跟随/经过，不能为凑变化添加无动机抖动。

- 在 brief 中分别写相机和主体各时段的慢/快、加速/减速/停留及叙事原因；需要精确控制时补关键位置、时间和速度值。不要只写“平滑运镜”。
- 速度由空间距离与时间共同决定。用不等间隔的关键时间/距离和合适的曲线建立缓急；`continuous` 能保持经过节点的余势，但两点同速输入仍可能匀速；`smooth` 每段归零，也可能做成重复起停。不能通过改一个插值名称代替设计。
- 保持持续动作的速度连续性；只有明确急停、撞击或甩镜才允许相应突变。相机与主体不必同时加速或停下，摄影机追上、落后、停住观察都需符合镜头目的。
- 正常速度回放检查观众是否感受到预期的快慢和重音，再结合逐帧平移速度、转向角速度与峰值时间定位问题。细小数值波动、曲线路径弯曲或手持微颤不能算有意义的速度变化。不要给所有题材硬套统一速度阈值。

## 相机与注意力

每段写清：起始景别/位置→触发事件→相机与主体相对运动→必要不变量→最终景别/位置或切点。跟拍不必永远居中，手持不必永远晃动。

“焦点”可能是注视方向、视觉注意力或景深焦平面：按上下文区分，必要时说明采用的解释。平移不是变焦；抬高不是仰摇。固定焦距要检查相机数据块，不能只看目标动画。

过肩用无四肢占位轮廓检查前景覆盖、目标上部/主体与道具的屏幕区域，连续检查运动段；不为检查肩部添加手臂。允许有意短暂遮挡，但须明确窗口与作用；中心点可见不能覆盖全身/道具验收。

相机位置与注视目标之间的距离太短时，小幅目标移动就可能造成快速旋转。逐镜检查角速度及其峰值帧，排除硬切帧后再判断；快甩镜和撞击响应可以有意存在，不设统一慢速上限。先修主运动和构图，再加次级手持；一次局部返修优先改一类变量并比较同一窗口。

## 信息揭示与分时状态

有悬念时，在镜头计划写清隐藏主体、必须不可见的时间窗、首次可见的触发事件/帧、揭示后的可读停留，以及遮挡物或画外位置。检查完整轮廓、道具和影子是否提前泄露；“允许遮挡”不等于“确保隐藏”。简化遮挡体应有明确职责，不能把随意出现的实心方块当成下游一定会理解的云雾。

例如先向下搜寻、后由画外冲入：先隐藏主体，慢速搜索形成期待，主体快速出现后机位转向并落稳。采用哪些速度阶段、是否切镜由当前剧情决定，不继承教程的固定三秒或最后 0.7 秒。

角色外观和道具绑定写成稳定 ID + LOOK/状态 + 生效镜头/帧段 + 资产，不把不同形态都描述为全程有效。形态变化沿用同一主体根对象，不能生成第二个人物。道具第一次出现、消失或换归属应有剧情依据；可以发生在约定的遮挡/画外区间，但不能靠随意显隐伪造连续动作。转绘提示词按正式格式逐镜引用生效状态；职责标签不会消除参考图中冲突的可见事实。

## 首帧与交接

有首帧时匹配地平线、消失方向、相机高度、主体占屏、关键边缘和前后关系。单图缺少尺度依据时说明估计，不假称精确重建。

白模与外观图冲突时，先排除单刀/双刀、门位置与开合侧、坐姿/站姿、人数和左右关系等事实冲突。必要时重做白模或换相容参考，不能用职责标签隐藏像素冲突。

剧情或道具改变会使相关视频参考失效。脚本改了但 MP4 没重导，不算同步。最后检查实际准备上传文件的哈希、起止帧、时间线和内容。
