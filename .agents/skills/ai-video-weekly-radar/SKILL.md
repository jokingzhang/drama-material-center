# AI 视频一周雷达

把一周热度调研收敛为两件能执行的事：一条值得复刻的练习，以及一条能从该练习继续拆出的教学内容。报告保存公开证据和判断边界，不承诺“全网榜单”。

## 开始前

1. 读取仓库根 `AGENTS.md`、`README.md`、`package.json`、Git 状态与本 Skill。
2. 完整读取 [报告契约](references/report-contract.md)。
3. 检查 `weekly-radar/reports/` 已有目录，确定本周窗口和下一个 `vNN`。不得覆盖历史版本。
4. 北京时间为唯一日期口径；默认窗口是结束日及此前 6 个自然日。用户指定窗口时以用户为准。
5. 这项工作只做调研、分析和页面报告，不生成 LibTV 视频，不消耗视频积分。

## 一、建立搜索样本

优先使用用户已有登录态的抖音网页完成平台内搜索和详情核对。无法访问详情页时保留为“搜索页样本”，不能补猜数据。

至少覆盖以下意图中的 5 组，并记录实际搜索词：

- 作品：AI视频、AI短片、AI漫剧、AI搞笑、AI情感、AI反转、LibTV。
- 技法：AI镜头角度、AI运镜、AI视频灯光、AI微表情、AI视频编剧、AI连续性、AI声音设计。
- 教学：AI视频教学、AI视频教程、AI短剧教程、爆款复刻。

采集 8–15 条严格窗口作品和 5–10 条教学样本。为每条保存：链接、标题、作者、发布时间原文与归一化日期、时长、当时可见的点赞/评论/收藏/分享、证据等级、快照时间。缺失指标写 `未显示`。

只把时间落在观察窗口内的作品计入严格周样本。较早但长期高互动的教程单列“历史常青对照”，不得混进本周数量。

## 二、核对和判断

进入能打开的作品详情页，复核发布时间、时长和公开互动。不要重复刷新制造伪精确；统一记录一次快照时间。

按报告契约的六项评分判断候选。最终必须给出：

- 主选 1 条：本周最值得复刻，说明只学什么结构、必须改掉什么具体表达、预计镜头数和积分等级。
- 次选 1 条：有余力再做，优先低积分、模板化且能引发评论接龙的形式。
- 暂不追至少 1 条：解释是长片成本、强 IP/音乐依赖、复杂动作还是与账号定位不合。
- 每个主/次选各配一个后续教学标题与最小练习。

推荐不是照搬。默认换角色、台词、造型、音乐、场景和具体事件，只提炼高概念规则、节奏、镜头或互动结构。

## 三、补齐教学地图

用本周样本回答“现在什么形式值得讲”，再用常青对照回答“哪些能力长期有人搜”。按基础、进阶、高级组织选题，每个题目必须包含：

- 可搜索标题；
- 一句观众钩子；
- 最小练习；
- 推荐载体（图文 / 短视频）；
- 预计积分成本（零 / 低 / 中 / 高）。

优先把零积分图文排在教学池前面。不要为了凑数量生成无消费者的样片。

## 四、生成 HTML 报告

输出一份自包含、可离线打开的 HTML。可用数据看板能力时复用其交互筛选和表格；否则实现无外部依赖的可访问单页。视觉与区块必须符合报告契约，并满足：

- 桌面与约 390px 手机宽度可读；
- 顶部编辑决策紧凑，不让白色大标题占据半屏；
- 外链标明目标，表格能横向滚动或响应式收纳；
- 互动筛选有真实作用，不能只是装饰；
- 报告写明快照时间、搜索抽样边界和不能推导的指标；
- HTML 中不得包含登录凭证、本机绝对路径或下载的第三方视频。

同时输出结构化 `evidence.json`，保留查询词、原始样本、教学样本、快照时间、归一化说明和编辑评分。分析结论不能覆盖原始字段。

## 五、登记历史版本

用项目脚本复制并登记报告；脚本会拒绝覆盖、计算哈希并原子落盘：

```bash
node .agents/skills/ai-video-weekly-radar/scripts/register-report.mjs \
  --id 2026-09-14--2026-09-20-v01 \
  --html /absolute/path/to/report.html \
  --evidence /absolute/path/to/evidence.json \
  --title "AI 视频一周雷达 · 2026.09.20" \
  --summary "本周主判断的一句话摘要" \
  --period-start 2026-09-14 \
  --period-end 2026-09-20 \
  --generated-at 2026-09-20T16:20:00+08:00 \
  --strict-week-samples 8 \
  --detail-verified 6 \
  --short-candidates 5 \
  --teaching-topics 13 \
  --primary-title "主选标题" \
  --primary-angle "只复刻的结构与改编边界" \
  --secondary-title "次选标题" \
  --secondary-angle "低积分做法" \
  --evidence-note "北京时间搜索抽样，不是平台全量榜单。"
```

登记后检查 `manifest.json`、HTML 和证据哈希。报告允许进入 Git；不要自动提交、推送或部署，除非用户另行授权。

## 六、验收

1. 运行本 Skill 的注册脚本测试和项目验证矩阵：`npm test`、`npm run typecheck`、`npm run build`、`npm run audit:git-boundary`。
2. 启动或复用 `http://127.0.0.1:4373/`，检查首页导航中的“AI视频一周雷达”。
3. 在列表页确认最新报告、历史排序、数量和主/次选摘要。
4. 点击详情，确认嵌入报告隐藏自带工具栏、顶部决策区已压缩、筛选仍能工作。
5. 直接刷新列表和详情深链，检查返回、前进、后退；桌面与约 390px 手机宽度均无关键溢出。
6. 检查控制台无新增错误，并实际查看最终截图。

最终分开报告：本周数据窗口与证据覆盖、主/次选结论、生成并登记的文件、页面读回、自动化检查、Git 状态与仍需人工判断的选题。
