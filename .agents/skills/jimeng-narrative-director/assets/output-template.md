# 导演意图与分镜输出模板

## 导演意图

- 项目 / 集数 / 场次 / 实际作者：
- 核心事件、观众知道什么、角色不知道什么：
- 情绪起点 → 变化 → 落点：
- 视觉基调、色板、主光方向、核心镜头语言：
- 对白、环境声、音画关系、关键声音时刻：
- 总时长、画幅、道具锚点、必要约束：

先安排观众怎样从上一镜接到下一镜，再分配生成单元。时长按剧情与实际入口能力确定，不照抄模板秒数；一个 Clip 可含多个镜头。区分必要动作与合理省略的日常过程，在现有备注说明有实际影响的拆合原因；不要求逐项填写无关风险。无需另建接镜表，关键连接直接写入下面的备注和接点栏。

接点写实际接法，如景别/角度变化、视线/声音承接或动作匹配；动作匹配说明重叠覆盖及拟采用的动作阶段，不能只写“自然衔接”。存在重叠时，Clip 时长记生成素材长度，全片时间范围按剪后净时长计算；具体入出点待实际媒体确认。

有待验证的声音组合、复杂动作或特殊效果时，在对应 Clip 旁说明试片观察与依赖结果的后续范围。声音跨反应画面时注明原声来源和覆盖关系；生成与后期分工写在执行说明，不混入模型正文。修改后同步本表实际镜数、顺序和时长，历史值保留在旧版。

## 逐 Clip 提示词

按目标入口或宿主的正式格式编写。明确 Clip 内真实镜头的时间范围、构图运镜、连续动作、逐字对白与声音，不把表演节拍拆成镜内时间轴；所有引用来自已核验映射。

## 完成状态

分别说明文本、输入素材、任务提交、媒体验收、索引接入；未执行项写明未执行。
