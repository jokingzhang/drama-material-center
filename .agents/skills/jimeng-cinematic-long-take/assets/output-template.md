## 提示词

本模板是规划骨架，不是另一套正式提示词格式。进入生产时使用 video-shot-prompt-v2 的总时长与摘要、真实引用，以及一个覆盖全段的镜头块：

- `画面提示词`：开场状态 → 有因的连续行动与反应 → 可见完成态；有对白则逐字保留。
- `镜头`：不间断拍摄；写实际起始位置、路径／固定关系、注意力转移和落点。需要停留时停留，不默认漂移。
- `音效`：本场真实需要的对白、环境与自然声；默认不生成 BGM，后期音乐另按已定方案处理。

无水印和非剧情说明污染；有剧情文字时落实可读性，不套用“一律无字”。

## 质量记录

LT-1 至 LT-8 的实际观察 / 具体时间点 / 当前用途影响 / 用户接受状态。尚未生成时只作提示词自查，不标记媒体验收通过。
