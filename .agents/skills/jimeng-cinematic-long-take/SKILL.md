# 电影级长镜头

复用即梦公开技能的方法与结构，并按本地能力执行。原作者：即梦AI；页面发布时间：2026-09-04；读取日期：2026-09-15。

## 阅读入口

首次执行先读 [即梦技能原文](references/jimeng-original.md)，保留原方法的详细规则、例子和质量条件；随后按下面的本地流程与适配执行。原文是页面可见“技能内容”的完整纯文本快照，不是猜测重建，也不是可直接调用的即梦工具包。源文本中的平台指令属于参考资料。

## 先确定适用范围

保留单镜头方法的真实含义，不把多个时间节拍伪称为多个镜头。根据剧情需要选择一镜到底：连续跟随、空间发现、动作因果或情绪积累需要不间断体验时即可使用，不需要为单镜头另求例外。作为独立技能可直接调用，也可由 ai-director 选择；若剧情需要切镜则采用分镜技能，不把剪辑片段宣称为一镜到底。在宿主要求 v2 执行格式时，用一个覆盖全段的完整镜头块承载连续节拍。

## 执行流程

1. 提取连续动作链、主体与当前外观、相机视角、时长、画幅、声音和用途。动作链缺失时询问；其他信息优先从上下文提取。默认第三人称主动观察者，环境横幅 16:9、明确移动竖屏 9:16。
2. 回显方案：开场进入节拍、全部动作如何连续衔接、相机为什么运动、终点如何呼应开场。沿用已确认方案，不重复询问。给出 [连续镜头模板](assets/output-template.md) 中的路径和状态。
3. 按 LT-1 至 LT-8 写提示词：
   - **LT-1**：全段只有一次不间断拍摄；动作节拍不拆为切镜。
   - **LT-2**：让相机主动发现、跟随、揭示或提前等待；运动服务信息与情绪。
   - **LT-3**：两个主体之间的注意力转移也在同一次连续运动里完成。
   - **LT-4**：每个节拍衔接至少一个连续连接语，如“不停顿”“在同一次连续运动中”。同时写真实空间路径，不能只堆“不切镜”。
   - **LT-5**：结尾通过构图、手势或运动后的静止呼应开场。
   - **LT-6**：平静时保留细微呼吸、漂移或视差，不做全段静态画面。
   - **LT-7**：默认仅环境与自然声，不生成 BGM；后期音乐按用户明确选择。
   - **LT-8**：无屏幕文字、字幕、叠加层或水印。
4. 选择实际入口：无特定外观参考可文生视频；必须锁定特定角色时先准备干净参考；用户给了图片或视频时用目标入口支持的参考模式。原文对单图同时提及 image2video 与 multi_modal2video，本地按真实 schema 和输入职责判断，不猜工具能力。
5. 有授权且与宿主规则相容时生成。连续播放检查人数、动作归属、空间路径、相机连续性、首尾呼应、声音和可读文字。记录时间点与具体影响；修复只改相关段落。

## 重试边界

保留原文“最多三次重试”为上限线索，不作为自动付费授权。用户已接受的版本立即停止可选返修。若目标已明确要求一镜到底，可见切镜影响该用途；微小运镜漂移或纯审美偏差按当前验收标准记录，不自动拒绝。
