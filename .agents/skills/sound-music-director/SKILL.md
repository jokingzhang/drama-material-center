# 声音与配乐设计

由当前主会话执行，可由 [ai-director](../ai-director/SKILL.md) 调用。表演技能处理可见反应，本技能处理听到的表达及连续性；转场技能处理需要联合设计的画面接点。声音需要贯穿分镜与后期，不在每个生成节点重新决定一遍。

## 进入条件与输入

整场设计含对白、环境／动作声或配乐需求时即调用，不必等用户提出“声音接不上”。用户指定无声、只做画面或已有完整声音方案时，保留该选择，只处理本次受影响内容。

恢复逐字台词与说话人、当前选定声音资产、场景空间、关键动作、生成单元和剪辑用途。有可用原声且本次只修画面时默认复用。文件存在不代表已试听；只在有真实试听证据时评价音色、情绪和可用性。规划可以标记缺失来源，不虚构已完成的音轨。

## 从剧情到声音安排

1. **确定声音承担的信息。** 哪些必须听清，哪些提示画外空间、动作接触或人物态度？是否需要音乐，还是留白更适合？先保完整对白及关键声音的可辨性，再决定氛围层。
2. **分开声音身份与本句表演。** 已选音色锚定角色身份；语气由当下意图、呼吸、重音和收尾决定。克制、犹豫或压怒应对应具体发声变化，同时与可见动作相容。不改词、不加未经确认的笑声或叹词作为台词，不用全句持续高强度替代情绪过程；估时包含换气和听者反应，不压缩尾音赶时长。
3. **逐句明确发声归属。** 多人对话区分画内说话、画外说话与倾听，嘴部动作跟随真正说话者。已选声音通过稳定资产引用到目标单元，不能靠同名标签或模型名称证明一致。实际入口不支持所需引用时说明限制，按现有规则设计授权内的分离发声／后期路线，不推定必须一人一个节点。
4. **设计环境与动作声。** 同一空间用相容底声跨切；关门、拿放、脚步等跟实际事件发生点和距离对应。动作重叠剪掉后声音也只保留一次。画外声可以先入或延续，但必须知道来自谁、哪里以及覆盖哪个画面；不能无因换场、突静或重复接触。
5. **按剧情变化安排音乐。** 明确进入事件、发展方式、退出或留白，以及怎样避让对白。节点边界不是换曲点；同一音乐可跨多个单元。情绪变化可以先由动作和环境声完成，音乐延后进入；反差配乐需要叙事依据。默认视频生成不自带随机 BGM，后期统一铺乐；用户另有已定方案则复用。
6. **把后期工作交给具体消费者。** 需要后期声音时，在现有执行／剪辑备注写明来源版本、目标镜头或视频、覆盖区间、同步事件、进入／退出和混音关系。已有媒体用实际入出点，无媒体时用明确剧情事件并标待落时间码。缺素材或未混音写真实待办，不用“加音乐”三个字宣称完成。

具体方法和案例边界按需查 [声音与配乐设计](../../../director-knowledge-base/分镜提示词/声音与配乐设计.md)，发声与可见反应互相冲突时回到 [微表情导演](../jimeng-micro-expression-director/SKILL.md) 修同一段表演，不改变确认台词。

## 写进分镜和剪辑

| 承载位置 | 必须可执行的内容 |
| --- | --- |
| 既有导演设计 | 本场声音在何处交代信息或改变感受，重要的音乐进出／留白决定 |
| 声音资产引用（实际使用时） | 角色、已选版本、职责与目标消费者；临时角色按项目规则处理，不扩建无用音色库 |
| `画面与动作` | 逐字对白、发声与倾听的可见行为；反应镜头不能让听者代说台词 |
| `音效` | 说话人及必要语气、画内／画外关系、环境底声、同步动作声；与正文同一份台词事实，不另写改词版本 |
| 既有剪辑备注 | 哪条真实音轨跨过哪个切点、音乐和音效如何覆盖及混音、尚缺什么 |

教学例：若确认剧情是“林遥回答，周宁听后改变决定”，可保留林遥同一条完整回答，画面切到周宁倾听，声音仍归林遥；周宁保持倾听口型。把音轨来源和覆盖画面写进剪辑备注；两个模型任务分别写“声音延续”不会自动得到同一条连续原声。台词内容沿用合同，本例不提供替换句。

## 检查与停止条件

- 文本：每句说话人、声音来源与画面关系一致；重要接触声有事件；音乐进出有落点；需要后期的工作有消费者。素材待补不阻止如实完成文本，但实际执行必须满足消费者的输入条件。
- 实际试听：对照合同逐句听内容、身份、起音尾音与口型窗口；跨切连听环境、动作声和音乐，检查突静、重复、音量突变、遮住关键对白或明显失真。ASR、波形和时长只辅助定位。
- 先修入出点、复用现有原声或调整混音，再判断是否确需重新生成；仅在已有授权范围执行。已接受的声音不因细微理想偏差重选，不自动增加选音、A/B 或付费次数。
- 设计完成、原声可用、混音完成、实际试听与人工接受分别报告。没有合成和试听时不宣称声画衔接已通过。

遵守 [SOP](../../../PRODUCTION_SOP.md) 和当前项目规则。音色来源、模型能力和授权以当前可核实事实为准；教学中的声音克隆或提取示例不构成使用他人声音的授权。
