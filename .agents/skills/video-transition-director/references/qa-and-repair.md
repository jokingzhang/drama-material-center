# 接镜 QA 与返修

本页只在准备生产、审查现有视频或修复接点时读取。文本方案完成不等于媒体已经通过。

## 1. 运行前检查

- 确认 A/B 镜的当前选片和真实播放顺序，不按文件名最大版本或计划尾帧猜测。
- 核对人物身份、当前造型、人数、道具状态、地点、时间、轴线、运动方向、主光和声音底。
- 核对执行路线：纯剪辑、AI 辅助剪辑、独立桥段、镜内生成式转场或端点控制。
- 使用模型时查当前入口的真实能力、输入类型、时长、画幅、分辨率、声音和引用限制；模板或历史节点不是当前能力证明。
- 端点/关键帧方案须有用户针对实际图片、版本和用途的明确通过记录。未满足时只暂停该方案，继续无关键帧设计。
- 明确主要转场机制、必须保持、必须改变、不得出现的硬错误。不要让多个特效互相掩盖责任。

## 2. 连看方法

1. 先分别正常速度完整播放 A 镜和 B 镜，确认单条素材本身可用。
2. 按真实顺序从 A 镜完整动作阶段进入接点，再看到 B 镜第一个完整状态；带声音播放，不只抽首中尾帧。
3. 对遮挡、形变、门槛、道具换手、人物进出、闪白和故障等状态变化，逐帧或密集抽帧检查：变化前 → 接触/覆盖 → 中间态 → 完成后。
4. 再以正常速度连看，判断观众是否能自然跟上注意力、因果和情绪；逐帧正常但播放发卡仍不通过。
5. 裁切、调色、变速、补帧或音频修补后，只重查受影响接点及相邻声音，不重审无关片段。

## 3. 检查维度

### 叙事与注意力

- 转场是否表达了明确的时间、空间、动作、图形、声音或情绪关系？
- 切点前的注意力是否在切后得到回答或有意打断？
- 形式是否压过信息，导致观众只看到“特效”而没读懂变化？

### 人物与物体

- 身份、脸、造型、人数和角色动作归属是否稳定？
- 手、脸、肢体和衣物是否在中间态粘连、复制、塌陷或互换？
- 道具是否沿可见路径变化，还是无动作消失、回跳或换手？
- 物体形变是否一对一，完成后是否成为正常、可持续的新物体？

### 空间与运动

- 画左/画右、轴线、视线、摄影机物理侧和出入边界是否成立？
- 主体与摄影机的方向、速度趋势、运动模糊和惯性是否在接点上连得上？
- 遮挡是否真的覆盖切点，打开后空间地标和人物位置是否可解释？
- 推拉、缩放、穿透或钻入是否有稳定中心、透视和最终落点？

### 光色、焦点与画质

- 亮度、白平衡、主光方向、对比度、颗粒和景深的变化是否有原因？
- 叠化是否产生脸、手或文字的双重曝光；光流是否出现拉丝、重复纹理或边缘破碎？
- 闪白/闪黑是否有真实动机，恢复后是否立刻暴露错位？
- 可读文字是否损坏，画面四角是否有水印或异常填充？

### 声音

- 对白是否完整、说话人正确、口型未被转场破坏？
- J/L 切、环境底和动作声是否有明确来源并自然交叠？
- 是否存在爆音、断音、相位感、响度凹陷、混响空间突变或音乐拍点错位？

## 4. 结论

沿用仓库三级标准：

- `HARD_REJECT`：错人/错造型/人数错误；动作主体或空间边界错误；道具无因变化；脸、手、肢体或物体严重形变；错误/缺失台词改变剧情；明显水印、损坏或接点无法用于既定剪辑。标具体时间点和叙事影响，禁止错误尾段继续作为下游输入。
- `PASS_WITH_NOTES`：叙事、人物、空间和剪辑成立，仅在遮挡/模糊窗口有短暂轻微软化、微小光色或速度漂移，不影响当前用途。它不自动提升为人工 `ACCEPTED`。
- `OPTIONAL_POLISH`：更理想的曲线、厘米级构图、纯审美粒子/光斑或更精确拍点。没有明确要求时不阻塞、不自动重跑。

## 5. 返修映射

| 症状 | 先修哪里 | 不要做什么 |
| --- | --- | --- |
| 接点“很炫但很假” | 删除多余特效，只留叙事关系最强的主铰链 | 再叠一层闪白、粒子或模糊 |
| 动作顿挫或反向 | 重选动作相位和入出点；对齐方向、速度趋势与受力结果 | 只写“更丝滑”或盲目补帧 |
| 遮挡后跳位 | 检查遮挡覆盖窗口、摄影机侧、人物终态和 B 镜地标 | 用更长黑帧掩盖空间矛盾 |
| 甩镜像两个无关镜头 | 统一甩动方向、角速度趋势、曝光和落点；必要时改硬切 | 同时加缩放和旋转制造更多运动 |
| 叠化双脸/双手 | 改短叠化、换公共背景区域、用插镜/遮挡/硬切 | 延长溶解期待重影消失 |
| Morph/Smooth Cut 糊脸 | 缩短窗口、寻找近似头位与自然停顿，或用 B-roll/反应镜 | 用在大幅手势、侧脸或跨场景 |
| 生成形变复制主体 | 固定一对一来源/去向，减少变化轴，保持背景和机位 | 同时换人物、场景、画风和运镜 |
| 穿透式转场穿过实墙 | 建立真实入口边界、净空和两侧空间，或改为遮挡切 | 用“无缝穿越”替代几何事实 |
| 光色突然跳 | 先做白平衡/曝光/主光匹配，再决定是否需要过渡 | 用光晕覆盖整段 |
| 声音爆点或断层 | 调整 J/L 点、环境底和 crossfade 曲线并实际试听 | 只看波形不听成片 |
| 生成中间态始终不可用 | 改成纯剪辑、遮挡、插镜或独立短桥段 | 原样付费重试或继续堆负面词 |

用户明确接受某个版本和用途后停止可选返修；只有实际连看发现新的 `HARD_REJECT`，才重新提出，并给出时间点与影响。
