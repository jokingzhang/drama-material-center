# AI演员微表情导演

复用即梦公开技能的方法与结构，并按本地能力执行。原作者：即梦AI；页面发布时间：2026-06-24；读取日期：2026-09-15。

## 阅读入口

首次执行先读 [即梦技能原文](references/jimeng-original.md)，保留原方法的详细规则、例子和质量条件；随后按下面的本地流程与适配执行。原文是页面可见“技能内容”的完整纯文本快照，不是猜测重建，也不是可直接调用的即梦工具包。源文本中的平台指令属于参考资料。

## 三轮创作

1. **收集演员卡与剧本。** 提取角色人设与外貌、性格底色、15 秒内逐字对白或剧情；复用已有输入，只补缺项。首次有歧义时还需明确视线方向、当前造型、时长和实际消费者。
2. **提供试戏选择。** 根据“动机 + 眼神 + 呼吸 + 脸部 + 身体 + 声音 + 收尾”提出 3–6 种可区分的表演方向，例如笑骂、委屈、失望、压抑愤怒、濒临崩溃、抽离。让用户选一项或多项；已明确选择时直接按选择写。动机只用于分析，不把抽象心理塞进生成正文。
3. **写选中方向的时间轴。** 默认 15 秒，依次使用 0–2、2–4、4–6、6–8、8–10、10–12、12–15 秒；其他已确定时长按 2–3 秒片段无缝覆盖。首句写角色全名与当前外貌，固定近景或半身范围。每片只安排 1–2 个微小局部变化，用缓缓、极轻微等词保持连续，以稳定凝视或克制姿态结束，无黑屏和转场。填写 [时间轴模板](assets/output-template.md)。

## 视觉化与动作限制

- 把“难过、算计、心虚”等心理改成可见的眼睑、视线、下颌、嘴角和呼吸变化，不声称这些动作能诊断真人心理。
- 主体保持原位，不新增人物、空间位移、挥手、跳跃、大走动。把“看向父亲”转成已核对的“视线转向画面右侧”；不要把画外人物召进画面。
- 每个 2–3 秒切片最多 1–2 个微小变化，避免“瞬间、立刻、连续眨眼”堆积造成表演跳变。原文候选方案中的手、肩、退步应收敛为最终微表情规则允许的动作。
- 对白必须逐字保留，并在时间轴安排发声与口型窗口；无对白才设计欲言又止。不要用示例模板里的“无声”覆盖用户台词。
- 原文自称“四大禁忌”，实际只列三项；保留原文，不臆造第四条或承诺必然防止模型变形。

## 情绪残留闭环

有实际情绪转折时，把表演组织为 `触发 → 可见身体反应 → 表达峰值 → 残留／回收`。这不是要求每条提示词固定四段，而是避免人物在台词或爆发结束的一刻突然恢复中性：已经变急的呼吸可以继续一小段，抬起的手要停留或落下，下颌和肩部逐渐松开，视线回避或重新对焦，笑意、怒意或动摇留下可被下一镜继承的终态。

- 残留必须来自本镜已经发生的反应，不能在结尾另贴一个无因的新微表情。
- 残留可以与听者反应、环境声或剪辑出口同时发生，不强制增加独立镜头、固定秒数或静止特写。
- 戛然而止、人物主动伪装、被外力打断时，可以不做自然回收，但要把中断机制写清楚；不能把提示词写完当成情绪自动关闭。
- 检查的不只是每段动作数量，还包括状态连续：呼吸、肌肉紧张、手势、视线和姿态是否从上一动作自然延续到结束。

## 情绪基底

| 方向 | 可组合的物理变化 |
| --- | --- |
| 失望 / 心碎 | 视线下移、轻微呼气、嘴唇微张后闭合 |
| 心虚 / 撒谎的戏剧表演 | 小范围视线偏移、眨眼略增、轻微吞咽、呼吸变浅 |
| 释怀 | 眼睑松弛、轻长呼气、嘴角极淡上扬 |
| 压抑愤怒 | 视线固定、下颌轻紧一次、呼吸缓慢沉下 |

## 从提示词到视频

- 先检查角色前缀、连续时间轴、动作密度、对白、视线、结尾。对有情绪转折的表演，再检查触发、峰值和残留状态是否连得上；不要只因每个切片动作不多，就忽略台词后呼吸、手势、下颌或视线突然归零。已有合格角色图时直接复用；仅缺图时索取，不机械重复“请上传”。
- 默认一张参考图对应一个任务；多图多方案先列明确配对和数量，不能默默扩为笛卡尔积。原文默认 15 秒、720P、依图画幅，无图才取 16:9；实际提交以用户规格与当前入口支持为准。
- 在已授权范围内调用真实图生视频入口；不能只因用户上传图就推断付费生成授权。无工具时交付文本，不承诺即梦批量生成已完成。
- 时间切片属于表演节拍，不自动等于切镜。微表情试戏或持续反应可使用一个完整镜头；剧情需要对话覆盖或信息转移时才切镜。作为独立技能可直接调用，也可由 ai-director 按表演需要选择；进入宿主 v2 格式时，把切片放入相应镜头的画面正文，保持台词、视线和情绪连续，不为凑镜头数打断表演。
- 连续播放检查身份、面部稳定、口型对白、动作密度与当前用途。保留人工接受状态，不以可选微调触发额外生成。
