# 微表情输出模板

## 演员卡

- 全名 / 外貌 / 当前造型：
- 性格底色：
- 当前逐字对白或剧情：
- 参考图 / 场次与镜头消费者 / 时长与画幅：

## 试戏选择

仅在方向未定且需要试戏时给可区分的选项，每项写“表演方向 | 眼神 → 呼吸 → 面部微动 → 声音 → 收尾”。已有明确方向直接沿用，不把所有方向同时塞进一条提示词。

## 选中方向的连续表演

- 沿用镜头与进入状态：[角色全名、当前外貌、构图、视线及已有动作]。
- 触发与回应：[发生了什么，眼神、呼吸或面部如何自然回应]。
- 表达与倾听：[逐字对白及口型、听者反应；只保留必要的局部变化]。
- 余波与接出：[呼吸、姿态、视线如何承接下一动作或下一镜]。
- 表演估时：[对白、停顿与动作所需时间；未演读时注明估计]。

以上是表演分析提示，可合并为简短连续描述，不是必须填满的分段或直接提交的正文。嵌入已有分镜时只补相关表演；正式 v2 提示词只在真实镜头标题写时间范围，不把这些节拍改名为镜头，也不插入固定秒数时间轴。对白不能省略或改写。
