# 微表情输出模板

## 演员卡

- 全名 / 外貌 / 当前造型：
- 性格底色：
- 15 秒内对白或剧情：
- 参考图 / 场次与镜头消费者 / 时长与画幅：

## 试戏选择

给 3–6 个选项，每项写“表演方向 | 眼神 → 呼吸 → 面部微动 → 声音 → 收尾”。记录用户选定方向，不把所有方向同时塞进一条提示词。

## 选中方向的时间轴

0-2秒：[角色全名与外貌前缀]，[固定构图、初始视线、一个微小动作]。
2-4秒：[承接上一状态，1–2 个局部变化]。
4-6秒：[承接变化；如有对白，安排准确原句及口型]。
6-8秒：[可见的反应，不重复上一片动作]。
8-10秒：[微小变化或呼吸回落]。
10-12秒：[向结束状态过渡]。
12-15秒：[稳定凝视或姿态；保留自然呼吸；无黑屏、无转场]。

每个方括号是待填写字段，不是直接提交的正文。短时长按相同规则调整切片；对白不能省略或改写。
