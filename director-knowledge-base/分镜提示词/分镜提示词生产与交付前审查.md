# 分镜提示词生产与交付前审查

这份方法用于新写、重写、批量审查和视频生产前复核，重点检查提示词能否清楚表达剧情并实际执行。

默认由主会话快速检查，不创建审查子代理或另开 Reviewer 任务。通读实际正文，核对剧情与逐字对白、人物造型与参考、动作归属和空间连续性、对白时间容量及模型硬约束；没有明显大问题就继续已授权制作。作者的最终通读可同时完成这次检查，不再重复一个审查阶段。

只有影响剧情、接镜、实际生产或明确硬约束的问题才阻塞。轻微表演、运镜、时长或审美差异记为非阻塞备注，不为理想效果反复返修。局部修复后只复查变更及相关接镜；上传同一资产、Mixed／Node 替换与布局变化只做执行一致性检查。十四维表仅在用户要求详细评分或批评时使用，缺少评分表或历史 Reviewer 报告不构成生产阻塞。

## 一、创作依据：剧情优先，旧提示词后置

按下面的优先级建立事实包：

1. 当前用户决定和项目生产合同；
2. 当前剧情、剧本、逐字台词、人物设定与连续性事实；
3. 本知识库的导演设计、镜头类型和专项写法；
4. 实际存在并核对过的图片、声音、模型与节点能力；
5. 旧分镜提示词、历史案例与失败结果。

第五层不能反向覆盖前四层。新建或明确要求全面重设计时，先从当前剧情回答观众必须知道、感到、期待什么，人物从什么状态变到什么状态，什么使局面不可逆；完成新设计后再用旧提示词检查回归。局部返修且输入稳定时，可先读当前提示词和已验证设计，保留有效选择，只修受影响部分及其连续性依赖；证据表明上游设计有错才重开该层，不能为了修一句话重新设计全场。

旧提示词中的剧情、造型、台词、时长、画幅、参考图和模型信息，也必须回到当前事实源逐项核实。未经核实的旧内容不能因“上一版已经这么写”而继承。

如果只找到旧提示词、找不到其对应的当前剧情或剧本定位，可以做缺陷诊断，但不能把重写稿宣称为剧情完整或事实已冻结。

## 二、先形成导演设计，再交给提示词作者

每个生成片段先形成一份独立导演设计，至少明确：

- 当前剧情原文定位；
- 本段唯一的主要叙事任务，以及观众需要知道、感到、期待的内容；
- 开始状态、按因果排列的可见节拍、转折或接触点、结束状态；
- 每个内部镜头的准确时间区间；
- 景别及其起始构图，观众需要看清的主体和信息优先级；
- 摄影机实际位于哪里、朝向哪里、使用什么拍摄方式；
- 相机保持固定还是运动；若运动，写清方向、距离或角度、速度变化、跟随对象和最终落点；
- 角色的动作链、微动作、视线、呼吸、表情变化和可观察情绪；
- 台词或内心独白的说话人、逐字正文、意图、时间、嘴部可见性与听者反应；
- 视觉效果、环境声、动作声、沉默或音乐是否需要，各自服务什么；
- 内部切点、转场依据、声音桥，以及给下一段的画面、动作、视线或声音出口；
- 人物、道具、轴线、地理、光线、声音和状态连续性；
- 最小参考集合、主要失败风险和过载时的最小拆分点。

“固定机位”是有效的导演选择，但必须说明摄影机位置、画面主次和为什么让表演承担变化。“推镜”“环绕”“大师级运镜”不是完整指令；必须补齐起点、方向、幅度、速度变化、跟随主体和最终落点。一个全景不能同时承担多人的口型、微表情、细小手势和群演反应；信息权重冲突时先切镜、转移焦点或删去非主要任务。

## 三、Seedance 2.0 通用十五秒档案

用户提供的“15 秒、5–6 个内部镜头”是一种可选生产档案，不是所有项目的永久参数。当前任务明确采用该档案，且没有更高优先级的项目、节点或模型合同冲突时，执行：

- 每个独立视频总时长严格为 15 秒；
- 根据剧情节奏在 5–6 个内部镜头间选择，不让所有片段机械使用同一数量；
- 高燃或快节奏内容多用 2–3 秒短镜头；慢情绪和重对话可用 3–4 秒镜头；
- 2 秒对白不超过 6 字，3 秒不超过 9 字，4 秒不超过 12 字；
- 2 秒内心独白不超过 8 字，3 秒不超过 12 字，4 秒不超过 16 字；
- 无对白、无内心独白的镜头通常不超过 3 秒；超过时必须说明它承担的环境建立、动作完成、情绪停留或剪辑作用；
- 双人或多人连续对话要设计说话与倾听视角的变化，通常使用正反打、越肩、双人关系镜与反应镜组合，不能用固定全景记录到底。

逐字台词不能为满足字数而擅自删改。超长台词应增加真实说话时长，或在动作、视线和听者反应成立的位置跨多个内部镜头连续表达。已经有确认声音时，实际朗读或声音时长优先于字符估算。

如果当前任务已明确为 10 秒、其它模型、其它节点时长或其它镜头数，使用当前合同，并把通用十五秒档案记为“不适用”。不能为了套模板偷偷改变总时长、模型、画幅或剧情。

最终正文使用 `video-shot-prompt-v2` 的开头引用、全局美学设定和逐镜分块；新写和返修不沿用旧五段式。通用十五秒档案规定的是内容完整度，不替代项目模板。每个内部镜头都要把适用的景别、拍摄方式、运镜或固定、切点、画面主次、动作、表情、情绪、逐字对白或内心独白、效果与声音写进对应时间段；审查评分表放在提示词正文之外，不能污染可直接复制的模型输入。

对白统一写清角色名和逐字引号正文。内心独白必须使用第一人称，标明它是画外音、没有口型、人物嘴部不张合；它必须增加画面无法提供的私人判断，不能重复旁白剧情。内容必须符合目标平台的真实安全规则，不使用规避审核的技巧。原剧情包含不能直接表现的内容时，可以用镜外动作、遮挡、光影、声音、人物反应或结果状态表达；如果安全表达无法保留核心因果与情绪走向，报告冲突，不得静默改写剧情。

## 四、可选的十四维详细评分

只有用户明确要求详细评分时，才在其指定范围逐项给出分数和证据；普通创作、返修和生产跳过评分表：

- `2`：具体、可视、可执行，和其它维度一致，足以进入生产；
- `1`：没有硬伤，当前用途可执行，但仍有明确的非阻塞精修空间；
- `0`：缺失必要设计、含糊到无法执行、与剧情或其它维度冲突，或者存在物理、时长、连续性、模型和合规硬伤；
- `N/A`：本段确实不需要，并写明理由。用 `N/A` 躲避本来需要的设计，按 `0` 处理。

| 维度 | 评分时必须回答 | 常见硬伤 |
| --- | --- | --- |
| 景别 | 起始与结束景别能否看清本镜主要信息，切换是否有信息动机 | 全景要求清晰口型和微表情；近景又要求看见垂在身侧的手或完整路线 |
| 拍摄方式 | 机位高度、角度、物理侧、固定／手持／跟拍／越肩等是否明确且合理 | 只写“双人中景”；正反打没有肩位、视线和机位侧 |
| 运镜 | 固定或运动是否有目的；运动的起点、方向、幅度、速度变化和落点是否齐全 | 只写“缓慢推镜”“高级运镜”；不知道推向谁、停在哪里 |
| 转场与剪辑 | 每次切换由动作、视线、声音、遮挡、图形或时空变化驱动吗，结尾有出口吗 | 随意换角度；该切反应却仍留在说话者；结尾主体不明 |
| 画面内容 | 每一拍的主次、前中后景和观众视觉落点是否唯一清楚 | 同时要求多人口型、微表情、手势、道具和群演反应，无焦点交接 |
| 角色动作 | 动作是否具体、可见、有因果，接触与状态变化是否完整连续 | “走过来”“发生打斗”；开门、递接、跨越、换手过程跳失 |
| 表情 | 表情是否由可观察的眼神、肌肉、呼吸或停顿表现，并与景别相容 | 只写“震惊”“愤怒”；远景要求瞳孔或嘴角细节 |
| 情绪 | 情绪是否有触发、压抑或释放过程，并改变表演、距离或节奏 | 用抽象情绪词替代行为；人物反应与刚发生的事件不符 |
| 台词 | 说话人、逐字正文、意图、时间、嘴部、听者反应和声音职责是否明确且装得下 | 台词被改写；长句挤在过短时间；同一画面要求多个清晰口型 |
| 内心独白 | 是否确有必要、使用第一人称、标明画外音和无口型，并与画面形成新信息 | 重复画面；第三人称解说；人物嘴部错误开合。没有内心独白时可 `N/A` |
| 视觉特效 | 是否由剧情和物理原因触发，强度与真人表演、场景连续性一致 | 为“电影感”堆粒子、闪白、速度线；特效遮住动作因果。无需特效时可 `N/A` |
| 环境音效 | 是否建立空间、跨切连续并给对白留出清晰度 | 只有“氛围音”；声场与地点、天气或镜头切换冲突 |
| 动作音效 | 是否对应可见动作和准确接触点，是否出现画面没有的动作声 | 写关门声却没有关门动作；碰撞声提前或滞后。没有动作时可 `N/A` |
| 场景氛围 | 时间、地点、空间布局、光线、天气和整体气氛是否具体且跨镜一致 | 只写“高级、压迫”；相邻镜天气、光向、背景人群和空间突然变化 |

景别、拍摄方式、运镜、转场与剪辑、画面内容、角色动作是重要检查方向，`2` 是创作目标，不是默认交付门槛。`1` 对应非阻塞精修；评分指出的问题只有具备实际剧情或执行影响时才触发修复，不能为了补齐分数继续循环。

## 五、跨维度硬伤

当前用户明确要求多个镜头：每个待生产单元至少两个完整镜头块，各自有时间、相机、构图／运镜与画面，并有实际切镜设计。一个全长镜头块下堆多个时间段、或伪装成多个编号的同一连续构图，属于明确格式硬伤，先修本地稿再同步运行；已有可用视频不因此追溯返工。结构校验只能数完整块，主会话在同一次通读里判断切镜是否真实、有动机。

检查对象是将要发送给模型的完整正文，不能用导演设计表里的好意图补齐正文缺失。含对白、梗或情感落点时，使用已读的 [对白、梗与情绪的分镜写法](对白、梗与情绪的分镜写法.md)，从正文核对说话、换气、轮次、动作与反应的时间安排，区分有依据的同时发生和必须依次发生。只有平均字速、没有表演余量依据，不能据此给出台词可执行的结论；未实测估时如实标记，不要求为文字预审额外生成音频或重建一套证明材料。

逐镜重点交叉核对：裁切是否真的容纳所写动作；机位朝向与每张输入图的可见背景是否相容；台词合同与镜内逐字句是否一致；切点依赖的动作声是否被其它声音句排除；方法论是否形成了实际镜头选择。不得以浅景深掩盖相反场景方向，或用通用“只有衣料与杯声”排除正文依赖的脚步声。

以下用于定位风险。只有具体证据表明它改变剧情、破坏关键可见动作或接镜、违反明确硬约束或使模型无法执行时，才将受影响单元判定 `PREFLIGHT_FAILED`。不因措辞不够丰富、没有理想运镜幅度或评分不满而拒绝：

- 人物、造型、场景、道具、逐字台词、剧情因果或结束状态与当前事实源冲突；
- 时间轴存在空档、重叠、总时长不符，或对白、动作和反应明显装不下；
- 景别裁切与要求看见的动作或细节物理冲突；
- 摄影机侧、轴线、视线、背景地理、人物运动方向或光源前后矛盾；
- 开门、进出、递接、换手、跌倒、打斗、变形等状态链缺少关键可见阶段；
- 一拍内存在多个无法同时成立的视觉中心，没有切镜、焦点转换或信息取舍；
- 运镜的主体或关键路径无法确定，或与空间、动作冲突；不要求每个镜头都精确到厘米或角度；
- 切镜丢失必要信息，导致剧情因果、人物关系或动作状态无法理解；
- 结尾状态无法与既定下一镜衔接，且没有可用的剪辑处理；
- 参考图片的可见事实与提示词冲突，或把拼板、文字、重复人物和影棚背景误当生成输入；
- 文字描述违反当前模型、节点、媒体数量、时长、画幅、声音或平台安全合同；
- 只通过标题、字段、哈希、节点引用和格式校验，却没有完成上述摄影语义检查。

## 六、通过、返修与可见证据

主会话检查后，同时满足以下条件即可给出 `PROMPT_PREFLIGHT_PASS`；轻微问题附非阻塞备注：

1. 当前剧情与生产合同已经绑定；
2. 实际正文没有影响剧情、连续性或执行的明显硬伤；
3. 模板、引用、时长和逐字台词等适用的确定性校验通过。

有硬伤时先定位剧情事实、导演设计、正文、参考映射或模型合同中的最早出错层，在既有记录里简记证据、影响和最小修复。当前选定作者生成新版本：主会话默认写作与返修；用户指定豆包时交回豆包并保留原始返回。主会话完成局部复查与本地更新后继续，不另开 Reviewer，也不重评分或重写其它已验证单元。只读审查请求不授权改稿；不能把新作者改写冒称为原作者未改动的输出。

默认只保留简短的“检查范围／版本、硬伤或无硬伤、必要修复、结论”，具体问题附原句或时间点。不为每条镜头建立完整评分报告，不重复记录未变化的证据；没有大问题即可继续。实际资产缺失、模型不支持和未完成的媒体验收仍如实列出，不用文字通过掩盖这些状态。

用户明确要求详细评分时，可使用下面的信息结构；证据指向具体时间段或原句：

```text
镜头 ID / 版本：
当前剧情来源：
生产档案：15秒通用档案 / 当前项目合同 / 其它已确认合同

景别：分数｜证据｜问题或无
拍摄方式：分数｜证据｜问题或无
运镜：分数｜证据｜问题或无
转场与剪辑：分数｜证据｜问题或无
画面内容：分数｜证据｜问题或无
角色动作：分数｜证据｜问题或无
表情：分数｜证据｜问题或无
情绪：分数｜证据｜问题或无
台词：分数｜证据｜问题或无
内心独白：分数或N/A｜证据或不适用理由
视觉特效：分数或N/A｜证据或不适用理由
环境音效：分数或N/A｜证据或不适用理由
动作音效：分数或N/A｜证据或不适用理由
场景氛围：分数｜证据｜问题或无

跨维度硬伤：无 / 逐条列出
结论：PROMPT_PREFLIGHT_PASS / PREFLIGHT_FAILED
返修要求：观察到的问题｜证据｜必须修正｜必须保持不变
```

评分审查的是提示词能否进入生成，不能替代成片连续播放和人工验收。提示词通过后生成的视频仍可能失败；成片结论继续按项目的视频验收门槛处理。

## 七、已有出片时，先判断是否值得再生成

连续播放后先看当前用途是否成立。开场能建立地点并接入主戏，就不因尾帧与理想构图、人物大小或像素位置不同而自动重跑；持续接触等提示词约束也要回到剧情与实际接镜判断，不能只因偏离文字便拒收。

怀疑接镜有问题时，先用实际候选试入出点和组接。局部裁切、声音连接或改用已有有效段能解决且不损害必要信息时，优先使用；如实保留清晰度、取景或节奏代价。只有可定位的问题确实妨碍剧情、剪辑用途或明确交付要求，且现有素材没有合理处理办法时，才在授权范围内选择最小重生成。

首个结果已满足用途，便记录必要备注并继续下一个单元，不自动追加“更自然”“接得更完美”的候选。用户接受后立即停止可选返修。代表性试片服务尚未验证的具体风险，不能成为已有可用结果后继续精修的通行理由；简记问题与决定即可，不另建评分或审批流程。

反例见 [EP05 开场的过度返工](../案例/EP05制作复盘-单镜过载与过度返工.md)：首个成功开场用户认为已够用，后来仍追加退镜生成与本地倒放。文件版本号还包含失败提交和本地导出，不能直接当作生成次数或扣费次数。

[EP06 局部修复](../案例/EP06制作复盘-谈判连续性与生成排障.md) 保留一版正确发言和另一版正确离席，接成可用片段；交笔后错误签署则保留交笔、只补女方亲签。复用时明确源版本与有效时间窗，对新剪辑连续播放，不把原拒绝片整体提升为通过。转写正确也不代表可见说话人、口型归属、音色或情绪正确；辅助分析与实际视听的覆盖范围分别记录。

## 八、通用生成失败时怎样排查

平台返回通用失败且没有视频时，不能据此判定导演设计不合格。沿用当前主会话检查和运行记录，区分以下情况，不另建审查流程：

1. **实际输入不一致**：修改参考后，除正文、媒体列表与入边，还要核对当前入口实际返回的混合列表或缓存是否残留旧素材。已暴露的表示互相矛盾时先修复再提交；某字段没有返回，不等于它必须补齐。EP06 删背景后 `mixedList` 残留旧图是明确错误，但干净节点后来仍失败，不能用它解释全部失败。
2. **输入一致但仍失败**：缺少具体错误信息时只记录假设。同一通用错误反复出现且没有新诊断信息，就停止原配置盲试，在已授权范围内按戏剧切点降低单次复杂度，保留完整对白和必要反应。一次同时改变时长、音频数量和动作负荷后成功，只能记为有效恢复方案，不能宣布唯一根因或发明模型硬上限；成功后继续制作，不为证明猜测追加付费实验。
3. **实际状态与用户所见不同**：取得任务回执后才报告已提交；用实际任务 ID 判断运行结果。选片改变后，本地映射和画布当前预览应指向同一结果，历史失败节点明确标记，不能仍用原主标题掩盖已有成功片段。版本数不等于运行数，返还提示不等于退款到账。

EP06 的短段、单音色引用拆分属于历史成功绕行，不能照搬为当前单镜格式豁免。后续新写、返修或再次生产的每个单元仍执行至少两个完整、独立计时且实际切换的镜头块；已可用历史片段不因此重生成。
