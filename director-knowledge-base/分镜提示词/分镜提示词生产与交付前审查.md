# 分镜提示词生产与交付前审查

这份门槛用于新写、重写、批量审查和视频生产前复核。它解决的不是 Markdown 格式问题，而是提示词有没有真正完成摄影、表演、声音和剪辑设计。

## 一、创作依据：剧情优先，旧提示词后置

按下面的优先级建立事实包：

1. 当前用户决定和项目生产合同；
2. 当前剧情、剧本、逐字台词、人物设定与连续性事实；
3. 本知识库的导演设计、镜头类型和专项写法；
4. 实际存在并核对过的图片、声音、模型与节点能力；
5. 旧分镜提示词、历史案例与失败结果。

第五层不能反向覆盖前四层。新写或重做分镜时，先不沿用旧提示词的句式、时间轴、机位和运镜，从当前剧情重新回答：观众必须知道什么、感到什么、期待什么；人物从什么状态变到什么状态；哪个动作、回答或证据使局面不可逆。完成新的导演设计后，才能打开旧提示词检查遗漏、回归和已经出现过的失败。

旧提示词中的剧情、造型、台词、时长、画幅、参考图和模型信息，也必须回到当前事实源逐项核实。未经核实的旧内容不能因“上一版已经这么写”而继承。

如果只找到旧提示词、找不到其对应的当前剧情或剧本定位，可以做缺陷诊断，但不能把重写稿宣称为剧情完整或事实已冻结。

## 二、先形成导演设计，再交给提示词作者

每个生成片段先形成一份独立导演设计，至少明确：

- 当前剧情原文定位；
- 本段唯一的主要叙事任务，以及观众需要知道、感到、期待的内容；
- 开始状态、按因果排列的可见节拍、转折或接触点、结束状态；
- 每个内部镜头的准确时间区间；
- 景别及其起始构图，观众需要看清的主体和信息优先级；
- 摄影机实际位于哪里、朝向哪里、使用什么拍摄方式；
- 相机保持固定还是运动；若运动，写清方向、距离或角度、速度变化、跟随对象和最终落点；
- 角色的动作链、微动作、视线、呼吸、表情变化和可观察情绪；
- 台词或内心独白的说话人、逐字正文、意图、时间、嘴部可见性与听者反应；
- 视觉效果、环境声、动作声、沉默或音乐是否需要，各自服务什么；
- 内部切点、转场依据、声音桥，以及给下一段的画面、动作、视线或声音出口；
- 人物、道具、轴线、地理、光线、声音和状态连续性；
- 最小参考集合、主要失败风险和过载时的最小拆分点。

“固定机位”是有效的导演选择，但必须说明摄影机位置、画面主次和为什么让表演承担变化。“推镜”“环绕”“大师级运镜”不是完整指令；必须补齐起点、方向、幅度、速度变化、跟随主体和最终落点。一个全景不能同时承担多人的口型、微表情、细小手势和群演反应；信息权重冲突时先切镜、转移焦点或删去非主要任务。

## 三、Seedance 2.0 通用十五秒档案

用户提供的“15 秒、5–6 个内部镜头”是一种可选生产档案，不是所有项目的永久参数。当前任务明确采用该档案，且没有更高优先级的项目、节点或模型合同冲突时，执行：

- 每个独立视频总时长严格为 15 秒；
- 根据剧情节奏在 5–6 个内部镜头间选择，不让所有片段机械使用同一数量；
- 高燃或快节奏内容多用 2–3 秒短镜头；慢情绪和重对话可用 3–4 秒镜头；
- 2 秒对白不超过 6 字，3 秒不超过 9 字，4 秒不超过 12 字；
- 2 秒内心独白不超过 8 字，3 秒不超过 12 字，4 秒不超过 16 字；
- 无对白、无内心独白的镜头通常不超过 3 秒；超过时必须说明它承担的环境建立、动作完成、情绪停留或剪辑作用；
- 双人或多人连续对话要设计说话与倾听视角的变化，通常使用正反打、越肩、双人关系镜与反应镜组合，不能用固定全景记录到底。

逐字台词不能为满足字数而擅自删改。超长台词应增加真实说话时长，或在动作、视线和听者反应成立的位置跨多个内部镜头连续表达。已经有确认声音时，实际朗读或声音时长优先于字符估算。

如果当前任务已明确为 10 秒、其它模型、其它节点时长或其它镜头数，使用当前合同，并把通用十五秒档案记为“不适用”。不能为了套模板偷偷改变总时长、模型、画幅或剧情。

最终正文仍使用当前项目指定的 `video-shot-prompt-v1` 或用户明确要求的其它格式。通用十五秒档案规定的是内容完整度，不替代项目模板。无论使用哪种格式，每个内部镜头都要把适用的景别、拍摄方式、运镜或固定、切点、画面主次、动作、表情、情绪、对白或内心独白、效果与声音写进对应时间段；审查评分表放在提示词正文之外，不能污染可直接复制的模型输入。

对白统一写清角色名和逐字引号正文。内心独白必须使用第一人称，标明它是画外音、没有口型、人物嘴部不张合；它必须增加画面无法提供的私人判断，不能重复旁白剧情。内容必须符合目标平台的真实安全规则，不使用规避审核的技巧。原剧情包含不能直接表现的内容时，可以用镜外动作、遮挡、光影、声音、人物反应或结果状态表达；如果安全表达无法保留核心因果与情绪走向，报告冲突，不得静默改写剧情。

## 四、十四维评分

每个候选提示词逐项给出分数和证据：

- `2`：具体、可视、可执行，和其它维度一致，足以进入生产；
- `1`：没有硬伤，当前用途可执行，但仍有明确的非阻塞精修空间；
- `0`：缺失必要设计、含糊到无法执行、与剧情或其它维度冲突，或者存在物理、时长、连续性、模型和合规硬伤；
- `N/A`：本段确实不需要，并写明理由。用 `N/A` 躲避本来需要的设计，按 `0` 处理。

| 维度 | 评分时必须回答 | 常见硬伤 |
| --- | --- | --- |
| 景别 | 起始与结束景别能否看清本镜主要信息，切换是否有信息动机 | 全景要求清晰口型和微表情；近景又要求看见垂在身侧的手或完整路线 |
| 拍摄方式 | 机位高度、角度、物理侧、固定／手持／跟拍／越肩等是否明确且合理 | 只写“双人中景”；正反打没有肩位、视线和机位侧 |
| 运镜 | 固定或运动是否有目的；运动的起点、方向、幅度、速度变化和落点是否齐全 | 只写“缓慢推镜”“高级运镜”；不知道推向谁、停在哪里 |
| 转场与剪辑 | 每次切换由动作、视线、声音、遮挡、图形或时空变化驱动吗，结尾有出口吗 | 随意换角度；该切反应却仍留在说话者；结尾主体不明 |
| 画面内容 | 每一拍的主次、前中后景和观众视觉落点是否唯一清楚 | 同时要求多人口型、微表情、手势、道具和群演反应，无焦点交接 |
| 角色动作 | 动作是否具体、可见、有因果，接触与状态变化是否完整连续 | “走过来”“发生打斗”；开门、递接、跨越、换手过程跳失 |
| 表情 | 表情是否由可观察的眼神、肌肉、呼吸或停顿表现，并与景别相容 | 只写“震惊”“愤怒”；远景要求瞳孔或嘴角细节 |
| 情绪 | 情绪是否有触发、压抑或释放过程，并改变表演、距离或节奏 | 用抽象情绪词替代行为；人物反应与刚发生的事件不符 |
| 台词 | 说话人、逐字正文、意图、时间、嘴部、听者反应和声音职责是否明确且装得下 | 台词被改写；长句挤在过短时间；同一画面要求多个清晰口型 |
| 内心独白 | 是否确有必要、使用第一人称、标明画外音和无口型，并与画面形成新信息 | 重复画面；第三人称解说；人物嘴部错误开合。没有内心独白时可 `N/A` |
| 视觉特效 | 是否由剧情和物理原因触发，强度与真人表演、场景连续性一致 | 为“电影感”堆粒子、闪白、速度线；特效遮住动作因果。无需特效时可 `N/A` |
| 环境音效 | 是否建立空间、跨切连续并给对白留出清晰度 | 只有“氛围音”；声场与地点、天气或镜头切换冲突 |
| 动作音效 | 是否对应可见动作和准确接触点，是否出现画面没有的动作声 | 写关门声却没有关门动作；碰撞声提前或滞后。没有动作时可 `N/A` |
| 场景氛围 | 时间、地点、空间布局、光线、天气和整体气氛是否具体且跨镜一致 | 只写“高级、压迫”；相邻镜天气、光向、背景人群和空间突然变化 |

景别、拍摄方式、运镜、转场与剪辑、画面内容、角色动作是结构核心维度。交付前它们必须全部为 `2`。其余适用维度不得为 `0`；`1` 必须写出具体、非阻塞的精修项，不能用“基本可以”代替证据。

## 五、跨维度硬伤

出现以下任一情况，整条提示词直接判定 `PREFLIGHT_FAILED`，不能被平均分抵消：

- 人物、造型、场景、道具、逐字台词、剧情因果或结束状态与当前事实源冲突；
- 时间轴存在空档、重叠、总时长不符，或对白、动作和反应明显装不下；
- 景别裁切与要求看见的动作或细节物理冲突；
- 摄影机侧、轴线、视线、背景地理、人物运动方向或光源前后矛盾；
- 开门、进出、递接、换手、跌倒、打斗、变形等状态链缺少关键可见阶段；
- 一拍内存在多个无法同时成立的视觉中心，没有切镜、焦点转换或信息取舍；
- 运镜只有术语，没有主体、路径、幅度、速度和落点；
- 切镜或转场没有叙事、动作、视线、声音、遮挡或时空依据；
- 结尾没有明确停在谁、什么状态，或没有给下一段可继承的出口；
- 参考图片的可见事实与提示词冲突，或把拼板、文字、重复人物和影棚背景误当生成输入；
- 文字描述违反当前模型、节点、媒体数量、时长、画幅、声音或平台安全合同；
- 只通过标题、字段、哈希、节点引用和格式校验，却没有完成上述摄影语义检查。

## 六、通过、返修与可见证据

只有同时满足下面条件，结论才是 `PROMPT_PREFLIGHT_PASS`：

1. 当前剧情与生产合同已经绑定；
2. 六个结构核心维度全部为 `2`；
3. 其余适用维度没有 `0`；
4. 不存在跨维度硬伤；
5. 模板、引用、时长和逐字台词等确定性校验也通过。

失败时，不要等待用户指出该怎么改。先定位最早出错层：剧情事实、导演设计、提示词翻译、参考映射或模型合同。给出“观察到的问题、证据、必须修正、必须保持不变”，回到该层生成新版本，再完整重评分。不能在旧提示词上只追加几个运镜词，也不能由事实校验者静默改写创意正文。

对单条或少量提示词，向用户展示完整十四维评分。批量任务必须为每条提示词保存完整评分，汇总时至少显示：镜头 ID、六个核心分、其它维度中的 `0/1/N/A`、硬伤、返修版本和最终结论。不得只给一个总平均分或一句“已审查通过”。

单条审查至少使用下面的信息结构，证据要指向具体时间段或原句：

```text
镜头 ID / 版本：
当前剧情来源：
生产档案：15秒通用档案 / 当前项目合同 / 其它已确认合同

景别：分数｜证据｜问题或无
拍摄方式：分数｜证据｜问题或无
运镜：分数｜证据｜问题或无
转场与剪辑：分数｜证据｜问题或无
画面内容：分数｜证据｜问题或无
角色动作：分数｜证据｜问题或无
表情：分数｜证据｜问题或无
情绪：分数｜证据｜问题或无
台词：分数｜证据｜问题或无
内心独白：分数或N/A｜证据或不适用理由
视觉特效：分数或N/A｜证据或不适用理由
环境音效：分数或N/A｜证据或不适用理由
动作音效：分数或N/A｜证据或不适用理由
场景氛围：分数｜证据｜问题或无

跨维度硬伤：无 / 逐条列出
结论：PROMPT_PREFLIGHT_PASS / PREFLIGHT_FAILED
返修要求：观察到的问题｜证据｜必须修正｜必须保持不变
```

评分审查的是提示词能否进入生成，不能替代成片连续播放和人工验收。提示词通过后生成的视频仍可能失败；成片结论继续按项目的视频验收门槛处理。
