# 分镜提示词可选评分与档案

仅在用户明确要求详细评分或采用特定生产档案时读取相关部分。普通创作、局部返修和执行不加载本文件。评分不是新的生产门槛；默认检查与停止条件见 主会话审查（仓库 `.agents/skills/ai-director/references/review-mode.md`）。原入口与章节定位保留在 [审查导航](分镜提示词生产与交付前审查.md)。

## 三、Seedance 2.0 通用十五秒档案

用户提供的“15 秒、5–6 个内部镜头”是一种可选生产档案，不是所有项目的永久参数。当前任务明确采用该档案，且没有更高优先级的项目、节点或模型合同冲突时，执行：

- 每个独立视频总时长严格为 15 秒；
- 根据剧情节奏在 5–6 个内部镜头间选择，不让所有片段机械使用同一数量；
- 高燃或快节奏内容多用 2–3 秒短镜头；慢情绪和重对话可用 3–4 秒镜头；
- 2 秒对白不超过 6 字，3 秒不超过 9 字，4 秒不超过 12 字；
- 2 秒内心独白不超过 8 字，3 秒不超过 12 字，4 秒不超过 16 字；
- 无对白、无内心独白的镜头通常不超过 3 秒；超过时必须说明它承担的环境建立、动作完成、情绪停留或剪辑作用；
- 双人或多人连续对话要设计说话与倾听视角的变化，通常使用正反打、越肩、双人关系镜与反应镜组合，不能用固定全景记录到底。

逐字台词不能为满足字数而擅自删改。超长台词应增加真实说话时长，或在动作、视线和听者反应成立的位置跨多个内部镜头连续表达。已经有确认声音时，实际朗读或声音时长优先于字符估算。

如果当前任务已明确为 10 秒、其它模型、其它节点时长或其它镜头数，使用当前合同，并把通用十五秒档案记为“不适用”。不能为了套模板偷偷改变总时长、模型、画幅或剧情。

最终正文使用 `video-shot-prompt-v2` 的开头引用、全局美学设定和逐镜分块；新写和返修不沿用旧五段式。通用十五秒档案规定的是内容完整度，不替代项目模板。每个内部镜头都要把适用的景别、拍摄方式、运镜或固定、切点、画面主次、动作、表情、情绪、逐字对白或内心独白、效果与声音写进对应时间段；审查评分表放在提示词正文之外，不能污染可直接复制的模型输入。

对白统一写清角色名和逐字引号正文。内心独白必须使用第一人称，标明它是画外音、没有口型、人物嘴部不张合；它必须增加画面无法提供的私人判断，不能重复旁白剧情。内容必须符合目标平台的真实安全规则，不使用规避审核的技巧。原剧情包含不能直接表现的内容时，可以用镜外动作、遮挡、光影、声音、人物反应或结果状态表达；如果安全表达无法保留核心因果与情绪走向，报告冲突，不得静默改写剧情。

通读时从候选模型正文及声明输入复述开场可见状态、触发后的动作与反应、结束状态，不从剧本替提示词补情节；再对照当前剧本与对白合同，定位关键信息何时、以何种景别或声音被接收。核对无关危险边界、重复参考警告或术语是否淹没主动作；只有遗漏、歧义、矛盾或时间过载等实际问题才要求局部修复，单纯长度或措辞偏好不阻塞。结论简记在既有记录中，不进入模型正文。

## 四、可选的十四维详细评分

只有用户明确要求详细评分时，才在其指定范围逐项给出分数和证据；普通创作、返修和生产跳过评分表：

- `2`：具体、可视、可执行，和其它维度一致，足以进入生产；
- `1`：没有硬伤，当前用途可执行，但仍有明确的非阻塞精修空间；
- `0`：缺失必要设计、含糊到无法执行、与剧情或其它维度冲突，或者存在物理、时长、连续性、模型和合规硬伤；
- `N/A`：本段确实不需要，并写明理由。用 `N/A` 躲避本来需要的设计，按 `0` 处理。

| 维度 | 评分时必须回答 | 常见硬伤 |
| --- | --- | --- |
| 景别 | 起始与结束景别能否看清本镜主要信息，切换是否有信息动机 | 全景要求清晰口型和微表情；近景又要求看见垂在身侧的手或完整路线 |
| 拍摄方式 | 机位高度、角度、物理侧、固定／手持／跟拍／越肩等是否明确且合理 | 只写“双人中景”；正反打没有肩位、视线和机位侧 |
| 运镜 | 固定或运动是否有目的；运动的起点、方向、幅度、速度变化和落点是否齐全 | 只写“缓慢推镜”“高级运镜”；不知道推向谁、停在哪里 |
| 转场与剪辑 | 每次切换由动作、视线、声音、遮挡、图形或时空变化驱动吗，结尾有出口吗 | 随意换角度；该切反应却仍留在说话者；结尾主体不明 |
| 画面内容 | 每一拍的主次、前中后景和观众视觉落点是否唯一清楚 | 同时要求多人口型、微表情、手势、道具和群演反应，无焦点交接 |
| 角色动作 | 动作是否具体、可见、有因果，接触与状态变化是否完整连续 | “走过来”“发生打斗”；开门、递接、跨越、换手过程跳失 |
| 表情 | 表情是否由可观察的眼神、肌肉、呼吸或停顿表现，并与景别相容 | 只写“震惊”“愤怒”；远景要求瞳孔或嘴角细节 |
| 情绪 | 情绪是否有触发、压抑或释放过程，并改变表演、距离或节奏 | 用抽象情绪词替代行为；人物反应与刚发生的事件不符 |
| 台词 | 说话人、逐字正文、意图、时间、嘴部、听者反应和声音职责是否明确且装得下 | 台词被改写；长句挤在过短时间；同一画面要求多个清晰口型 |
| 内心独白 | 是否确有必要、使用第一人称、标明画外音和无口型，并与画面形成新信息 | 重复画面；第三人称解说；人物嘴部错误开合。没有内心独白时可 `N/A` |
| 视觉特效 | 是否由剧情和物理原因触发，强度与真人表演、场景连续性一致 | 为“电影感”堆粒子、闪白、速度线；特效遮住动作因果。无需特效时可 `N/A` |
| 环境音效 | 是否建立空间、跨切连续并给对白留出清晰度 | 只有“氛围音”；声场与地点、天气或镜头切换冲突 |
| 动作音效 | 是否对应可见动作和准确接触点，是否出现画面没有的动作声 | 写关门声却没有关门动作；碰撞声提前或滞后。没有动作时可 `N/A` |
| 场景氛围 | 时间、地点、空间布局、光线、天气和整体气氛是否具体且跨镜一致 | 只写“高级、压迫”；相邻镜天气、光向、背景人群和空间突然变化 |

景别、拍摄方式、运镜、转场与剪辑、画面内容、角色动作是重要检查方向，`2` 是创作目标，不是默认交付门槛。`1` 对应非阻塞精修；评分指出的问题只有具备实际剧情或执行影响时才触发修复，不能为了补齐分数继续循环。

## 详细评分的可选记录

用户明确要求详细评分时，可使用下面的信息结构；证据指向具体时间段或原句：

```text
镜头 ID / 版本：
当前剧情来源：
生产档案：15秒通用档案 / 当前项目合同 / 其它已确认合同

景别：分数｜证据｜问题或无
拍摄方式：分数｜证据｜问题或无
运镜：分数｜证据｜问题或无
转场与剪辑：分数｜证据｜问题或无
画面内容：分数｜证据｜问题或无
角色动作：分数｜证据｜问题或无
表情：分数｜证据｜问题或无
情绪：分数｜证据｜问题或无
台词：分数｜证据｜问题或无
内心独白：分数或N/A｜证据或不适用理由
视觉特效：分数或N/A｜证据或不适用理由
环境音效：分数或N/A｜证据或不适用理由
动作音效：分数或N/A｜证据或不适用理由
场景氛围：分数｜证据｜问题或无

跨维度硬伤：无 / 逐条列出
结论：PROMPT_PREFLIGHT_PASS / PREFLIGHT_FAILED
返修要求：观察到的问题｜证据｜必须修正｜必须保持不变
```

评分审查的是提示词能否进入生成，不能替代成片连续播放和人工验收。提示词通过后生成的视频仍可能失败；成片结论继续按项目的视频验收门槛处理。
