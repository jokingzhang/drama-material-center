# 分镜提示词写法

## 有对白、梗或情感落点

先继续读取 [对白、梗与情绪的分镜写法](对白、梗与情绪的分镜写法.md)。那一页说明怎样把逐字台词、人物声音、潜台词、听者反应、梗、情感余波、OS/VO和真实说话时长放进分镜；本页保留通用镜头骨架。

## 通用骨架

每条提示词按下面顺序组织：

1. **镜头任务**：这一镜必须让观众知道、感到或期待什么，主要职责是什么。
2. **参考图片**：逐张说明图片是谁、是什么，只承担什么责任。
3. **开始状态与空间关系**：人物、道具、站位、视线、轴线、光源和环境从哪里开始。
4. **动作或表演节拍**：按发生顺序写可观察动作、物理原因和环境反馈，不用抽象词代替动作。
5. **导演设计**：只写帮助当前任务的景别、角度、构图、人物调度和相机移动，并说明最终落点。
6. **光影与环境连续性**：写清当前镜头必须保持或发生变化的光源、色温、天气和空间事实。
7. **对白与声音**：逐字台词、说话人、意图、听者反应、嘴部策略，以及必要的环境声、效果或音乐。
8. **结束状态与剪辑出口**：最后停在哪里，以动作、视线、声音、遮挡还是实际尾帧接下一镜。
9. **必要禁止项**：只针对当前最可能失败的问题。

## 把术语翻译成可见约束

- 不只写“电影感”“高级运镜”“压迫感”或“真实质感”，要写观众实际会看见什么。
- 命名技巧必须补充主体、相机、方向、幅度、节拍和结果。例如推拉变焦要说明主体画面大小基本不变、背景透视改变，而不是只写技巧名称。
- 关键站位、构图、空间地理、光源方向和首尾状态优先锁在场景图或关键帧中；视频提示词负责可见过程，不负责凭空修复冲突的输入。
- 情绪改写为眼神停顿、呼吸、肌肉受力、手势、汗水或与环境的交互，并控制强度。
- 环境动态必须有原因。写“风吹动衣摆并带起地面薄尘”比同时堆入粒子、烟雾、雨水和镜头晃动更可控。
- 相机运动与人物运动分开写。相机静止也是主动选择，不需要每镜都运镜。

## 不同类型的写法重点

### 双人对白

写清说话人、逐字台词、表达意图、嘴部是否可见、听者在台词前后怎样反应。不要只写“二人激烈争吵”。完整方法见 [对白、梗与情绪的分镜写法](对白、梗与情绪的分镜写法.md)。

### 动作接触与打斗

写清起始站位、运动方向、接触点、道具归属、反作用和结束状态。不要只写“激烈打斗、电影感运镜”。

### 状态变化

写成触发 → 初步变化 → 扩散或操作 → 完成 → 终态停留。前后状态图片必须对应同一人物或物件。

七案例反复出现的可见状态阶梯有两种：

- 生物或物体内部变化：普通状态 → 一个局部先异常 → 表层材质变化 → 结构或体型变化 → 新状态主动作用于环境。
- 穿戴或开合操作：前状态动作 → 手和道具沿明确路径移动 → 遮挡或闭合完成 → 后状态主动作 → 终态停留。

前后图片锁定边界，提示词必须负责解释中间过程；不能只写“从图一变成图二”。

### 短机制与接触喜剧

- 机械启动可写成：同机位前状态 → 目标部件点亮或运动 → 可见输出 → 主体产生位移 → 镜头受到反作用。
- 接触动作可写成：谁靠近 → 谁用哪个身体部位阻止 → 接触准确位置 → 受力方向 → 表情或姿势反应 → 终态。

这两类通常只需要一个清楚机制。五秒内不要同时塞入不相关的走动、取物、进食或环境蒙太奇。

### 多角色映射

在写动作前先列 `角色名 → 实际图片或节点 → 当前造型 → 本镜职责`。逐张看图后再绑定；角色名写对但节点接反，视频仍会错。武器和声音也要分别绑定给正确人物。

### 追逐移动

写清空间路径、障碍、人物距离变化和相机路线。追逐不是简单地重复“跑得很快”。

近景跟随通常强化速度与迫近，远景更便于读清路线、距离和环境。选择取决于本镜主要信息，不能同时要求所有景别优势。

### 蒙太奇

每个插镜只承担一个对象、一个动作和一个信息作用。镜头之间用共同的时间、光色、节奏或声音联系起来。

## 一个镜头什么时候应该拆

如果同一条提示词同时要求完整对白、复杂变身、近身打斗、多人队形、重大转场或多地点切换，先拆成多个片段。提示词越长不代表模型越能执行。

长镜头、多镜头连续生成和多人物接触必须先做代表性试片并实际播放。模型或课程展示过某种能力，不等于当前输入已经通过。

## 交付前检查

- 剧本事实、人物造型、场景、道具和图片内容一致。
- 对所有手机、卡片、文件、证件、包和其它剧情道具执行“摄影机消失测试”：人物的持握、朝向、视线、受力与放置即使没有观众也仍然合理；否则先改自然互动，再另拆可读插镜。
- 引用的每张图都实际存在且已经打开核对。
- 时间范围能容纳所有动作和反应。
- 对白时长已经通过朗读或试演估算，不靠猜测硬塞进节点时长。
- 对白没有漏掉说话人、听者和嘴部策略。
- 轴线、视线、肩位、背景地理、光源方向和人物运动方向与相邻镜一致；若有意打破，原因明确。
- 光影和环境变化存在物理原因，没有为“氛围感”添加互相冲突的效果。
- 结束状态明确，可以被下一镜继承。
- 已写清声音来源、动作同步点和剪辑出口；转场有时间、空间、动作、图形或声音依据。
- 没有虚构图片、节点 ID、模型能力或已经通过的验收结果。
- 原提示词里的画幅、时长和画质词与真实节点参数一致；真实参数优先于文字里的“4K”“21:9”等描述。
- 参考案例只复用动作骨架、图片职责和限制条件，不整段复制题材、风格堆词、旧节点 ID 或已经暴露的矛盾。
