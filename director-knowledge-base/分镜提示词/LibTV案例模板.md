# LibTV 案例模板

这里不是只读提示词的文本库。每个案例都同时展示输入图片、进入生成链的原始提示词和实际结果视频，只有三者合看才能判断一段提示词为什么有效、哪里失败、换素材后还能不能复用。

## 从分镜角度看什么

1. 这个镜头真正要完成的观众效果是什么。
2. 提示词里的固定骨架：开始状态、动作顺序、接触或变化机制、结束状态和剪辑出口。
3. 可以替换的角色、场景、道具、台词与风格变量。
4. 模型、模式、时长、画幅、引用数量和声音条件是否兼容。
5. 结果视频只证明了什么，哪些部分仍然没有经过连续播放、声音或人工选片确认。
