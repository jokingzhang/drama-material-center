# 分镜提示词知识：先判断镜头要完成什么

分镜提示词不是把剧本换成更长的形容词，而是把一个剧情任务翻译成模型能执行、观众能看懂的镜头。

## 工作顺序

1. 先说明观众在这段剧情里必须知道、感到和期待什么。新分镜或重大重设计中有关键未定选择时，由 AI Director 一次讨论一个问题并给推荐；沿用已有决定，响应用户补充，不重问文件已能回答的事实。
2. 区分叙事主镜、关系情绪镜、呼吸过渡镜和主观特殊镜；职责不是重要性排名。
3. 有对白、梗或情绪时，先按 [对白、梗与情绪的分镜写法](对白、梗与情绪的分镜写法.md) 明确说话意图、倾听、反应和余波，再分配时长；按完整剧情阶段安排视点与接法，再组合为可生成片段。一个生成单元可以包含多个摄影镜头，连续视频不自动要求一镜到底；[景别/角度变化、动作匹配和剧情阶段组接](导演设计方法.md#continuity-editing)服务成片连贯，不按模板秒数切段。
4. 按 [剧情驱动的技巧选择](剧情驱动的技巧选择.md) 选择服务本场的开场、表演、构图、景深、光影、运镜、剪辑和声音；将观看目的转成可见／可听机制，不堆术语或要求技巧齐套。
5. 根据镜头职责决定哪些事实由当前造型人物标准图、干净场景及必要道具图负责，哪些由提示词负责。默认不使用关键帧；例外须先展示实际图并经用户通过具体用途。
6. 写清开始状态、可见节拍、环境反馈、结束状态和剪辑出口。
7. 用 `video-shot-prompt-v2` 写成“总时长与全局摘要＋逐项引用＋真实镜头的画面提示词／镜头／音效”，让逐字台词、声音、动作和反应在镜内同时成立；核对正常表演和接点的时间容量，再按实际入口安排任务。
8. 作者收尾通读按 主会话审查（仓库 `.agents/skills/ai-director/references/review-mode.md`） 检查具体问题；与姓名、对白、格式、时间和引用校验一起在正式绑定前完成，不再增加一个审查阶段。

新建分镜或明确要求全面重设计时，先从当前剧情、用户决定、台词与连续性事实完成新设计，再用旧提示词检查回归。仅修局部问题且输入稳定时，先核对当前提示词与已冻结设计，保留有效选择，只修改受影响单元及相邻连续性；发现上游错误才重开对应设计。只读审查不自动创建替代稿。

镜头包含逐字对白、OS/VO、喜剧节拍或情感落点时，继续读取 [对白、梗与情绪的分镜写法](对白、梗与情绪的分镜写法.md)，把说话、倾听、潜台词、表演节拍和真实时长一起写进分镜。

方法要体现在实际镜头选择中。只有某个取舍值得说明或会影响后续执行时，才在既有设计或执行表补一句原因；不要求逐镜记录方法来源和正文映射。普通单元可在同一轮写作中完成设计，无需先交一份独立设计包。

先完成本地正式分镜、台词合同、正文和索引，并在素材中心页面核对当前版本，再创建或更新 LibTV。完整顺序遵守仓库 `AGENTS.md`；远端画布不能领先于本地故事事实。

镜头包含手机屏幕、文件、卡片或工作牌等可读信息且需要选择拍法时，读取 [导演设计方法](导演设计方法.md) 的“互动主镜与可读插镜分责”；只有正在选择或修复关系参考图时才读 [关系关键帧与连续性帧](../图片素材/关系关键帧与连续性帧.md)。关系帧按角色视线和动作摆放道具；观众读字使用角色 POV、越肩或局部插镜，不为可读性强迫道具朝摄影机。

## 输出给用户的《分镜执行表》

| 字段 | 用户需要看到什么 |
| --- | --- |
| 镜头编号 | 对应哪段剧情 |
| 剧情作用 | 观众在这一镜必须看懂什么 |
| 镜头类型 | 为什么选择这种镜头 |
| 导演设计 | 只列对本镜有用的景别、角度、构图、调度、相机、光影、声音和剪辑决定 |
| 时长 | 暂定时长或目标模型的实际时长 |
| 图片参考 | 使用哪些现有图，还缺什么图 |
| 分镜提示词 | 可以直接进入生产的最终文本 |
| 生产前检查 | 主会话检查范围、明显硬伤或无硬伤、必要修复与结论；详细评分仅在用户要求时提供 |
| 失败时怎么拆 | 任务过载时的最小拆镜方案 |
