# 分镜提示词知识：先判断镜头要完成什么

分镜提示词不是把剧本换成更长的形容词，而是把一个剧情任务翻译成模型能执行、观众能看懂的镜头。

## 工作顺序

1. 先说明这段剧情对观众的作用。
2. 把过多的剧情拆成若干可生成片段。
3. 每个片段选择一个主要镜头类型。
4. 根据镜头类型决定需要哪些图片参考。
5. 写清开始状态、动作或表演过程、结束状态和剪辑出口。
6. 最后才补充机位、景别、运镜、声音、光影和必要的禁止项。

## 输出给用户的《分镜执行表》

| 字段 | 用户需要看到什么 |
| --- | --- |
| 镜头编号 | 对应哪段剧情 |
| 剧情作用 | 观众在这一镜必须看懂什么 |
| 镜头类型 | 为什么选择这种镜头 |
| 时长 | 暂定时长或目标模型的实际时长 |
| 图片参考 | 使用哪些现有图，还缺什么图 |
| 分镜提示词 | 可以直接进入生产的最终文本 |
| 失败时怎么拆 | 任务过载时的最小拆镜方案 |
