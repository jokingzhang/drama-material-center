# 分镜提示词知识：先判断镜头要完成什么

分镜提示词不是把剧本换成更长的形容词，而是把一个剧情任务翻译成模型能执行、观众能看懂的镜头。

## 工作顺序

1. 先说明观众在这段剧情里必须知道、感到和期待什么。
2. 区分叙事主镜、关系情绪镜、呼吸过渡镜和主观特殊镜；职责不是重要性排名。
3. 把过多的剧情拆成若干可生成片段，每个片段选择一个主要镜头类型。
4. 只选择会改变观众理解的景别、角度、构图、调度、运镜、光影和声音，不堆摄影术语。
5. 根据镜头职责决定哪些事实由人物标准图、场景图或关键帧锁定，哪些由提示词负责。
6. 写清开始状态、可见节拍、环境反馈、结束状态和剪辑出口。
7. 最后补充逐字台词、声音时间线、必要禁止项和失败时的最小拆镜方案。
8. 按 [分镜提示词生产与交付前审查](分镜提示词生产与交付前审查.md) 对每条候选提示词逐维评分；存在硬伤时先返修并重新评分，不进入视频生产。

设计新分镜或重做旧分镜时，先从当前剧情、用户决定、台词与连续性事实重新完成导演设计，再打开旧提示词做回归比较。旧提示词可以暴露错误或保留经当前事实独立核实的约束，但不能作为新一版摄影与剪辑设计的底稿。

镜头包含逐字对白、OS/VO、喜剧节拍或情感落点时，继续读取 [对白、梗与情绪的分镜写法](对白、梗与情绪的分镜写法.md)，把说话、倾听、潜台词、表演节拍和真实时长一起写进分镜。

镜头包含手机屏幕、文件、卡片或工作牌等可读信息时，读取 [导演设计方法](导演设计方法.md) 的“互动主镜与可读插镜分责”，并同时读取图片域的 [关系关键帧与连续性帧](../图片素材/关系关键帧与连续性帧.md)。关系帧按角色视线和动作摆放道具；观众读字使用角色 POV、越肩或局部插镜，不为可读性强迫道具朝摄影机。

## 输出给用户的《分镜执行表》

| 字段 | 用户需要看到什么 |
| --- | --- |
| 镜头编号 | 对应哪段剧情 |
| 剧情作用 | 观众在这一镜必须看懂什么 |
| 镜头类型 | 为什么选择这种镜头 |
| 导演设计 | 只列对本镜有用的景别、角度、构图、调度、相机、光影、声音和剪辑决定 |
| 时长 | 暂定时长或目标模型的实际时长 |
| 图片参考 | 使用哪些现有图，还缺什么图 |
| 分镜提示词 | 可以直接进入生产的最终文本 |
| 生产前审查 | 十四维评分、跨维度硬伤、返修版本与最终结论 |
| 失败时怎么拆 | 任务过载时的最小拆镜方案 |
