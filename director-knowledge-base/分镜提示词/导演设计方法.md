# 分镜设计方法：先安排观众怎样理解，再决定怎样拍

这份方法用于把剧情作用翻译成可执行的导演选择。它不要求每一镜都填满摄影术语；只保留会改变观众理解、表演调度或生成结果的选择。

## 一、先回答三个问题

1. **观众要知道什么**：地点、人物、动作因果、关系变化还是关键道具。
2. **观众要感到什么**：亲近、压迫、悬念、失衡、孤立、速度或短暂喘息。
3. **观众接下来要期待什么**：下一动作、反应、揭示、转折还是剪辑点。

如果一镜同时有两个以上都不能丢的主要答案，先拆镜。摄影设计不能替代信息取舍。

## 二、先分镜头职责层

职责层回答“这一镜为什么存在”，不是质量或重要性排名。

| 职责层 | 主要任务 | 常见用法 | 不应承担 |
| --- | --- | --- | --- |
| 叙事主镜 | 交代必须看懂的事件、空间或因果 | 人物出场、动作接触、道具操作、状态变化 | 同时塞入无关气氛展示 |
| 关系与情绪镜 | 让观众读到态度、权力和情绪变化 | 倾听反应、微表情、距离变化、视线交换 | 重复主镜已经清楚的信息 |
| 呼吸与过渡镜 | 调整节奏并连接时间、地点或视线 | 环境插镜、动作续接、声音先行、短暂留白 | 用空泛风景拖延剧情 |
| 主观与特殊镜 | 把观众放进特定感知或制造有意异常 | POV、眩晕、记忆、监控视角、时间冻结 | 只为炫技而破坏叙事连续性 |

一组分镜可以有不同职责；单镜仍只保留一个主要职责。

## 三、按信息量选景别

| 景别 | 更适合传递 | 常见代价 |
| --- | --- | --- |
| 极远景、远景 | 地点、规模、人物与环境关系 | 面部情绪和细小动作难读 |
| 全景 | 全身动作、路线、多人站位 | 微表情权重较低 |
| 中景 | 人物互动、手势、关系和一定表情 | 大环境信息有限 |
| 近景、特写 | 情绪、眼神、局部道具和关键细节 | 容易丢失动作全貌与空间方向 |

同一运动在近景跟拍中通常显得更快、更迫近，在远景中更像被观察。先决定观众要读什么，再决定景别，不用“特写更高级”之类的价值判断。

## 四、角度决定观众站在哪里

| 角度 | 可服务的叙事感受 | 使用条件 |
| --- | --- | --- |
| 平视 | 同等、直接、自然观察 | 默认选择，不等于没有设计 |
| 俯视 | 暴露、弱小、受困，或交代平面关系 | 必须与当下关系和空间相符 |
| 仰视 | 压迫、权力、规模或英雄感 | 避免把临时机位误写成人物固定属性 |
| 背面、三分之四背面 | 未知、孤立、行动方向与环境关系 | 要保留足够的身份和动作信息 |
| 侧面 | 克制、距离、并行关系 | 对话时同时检查视线与轴线 |
| 越肩、正反打 | 说听关系和空间归属 | 肩位、视线方向、背景地理必须连续 |
| 主观镜头 | 让观众直接占据角色感知位置 | 明确是谁的主观，何时进入和退出 |
| 倾斜机位 | 失衡、危险、心理异常 | 必须是有意异常，不能当通用电影感 |

高低机位、人物站立高度和画面占比可以表达一场戏里的临时权力变化，但不是脱离情境的固定公式。

## 五、构图必须解释关系

| 构图选择 | 可见作用 | 适合锁在哪里 |
| --- | --- | --- |
| 对称 | 秩序、仪式、控制，也可能形成压迫 | 场景图或关键帧 |
| 居中 | 明确优先级；周围空旷时也可形成孤立 | 场景图或关键帧 |
| 三分与留白 | 为视线、运动方向或对手留出空间 | 关键帧 |
| 引导线 | 把视线引向人物、出口或运动目的地 | 场景设计和机位 |
| 框中框 | 表达观察、束缚、边界或隐藏关系 | 场景图或关键帧 |
| 对角线 | 增加方向感、速度或不稳定 | 关键帧和动作路径 |
| 前景遮挡 | 增加纵深、窥视感或空间层次 | 场景图；不得遮住必要信息 |

构图类型可以组合，但每个选择都要回答剧情问题。关键站位、留白和地理方向应尽量在输入图或关键帧中锁定，不能只靠视频提示词临场发明。

## 六、先画清空间，再调度人物和相机

### 空间连续性

- 先确认人物、出口、家具、关键道具和光源的相对位置。
- 对话或对峙先定轴线和双方视线方向。正反打的肩位、画面左右与背景地理不能互相打架。
- 同一主体连续切镜且不想制造跳切时，机位变化要足够明显；课程给出的常用经验是至少约 30°。越轴或跳切可以使用，但必须是明确的叙事选择，并先重建观众的方向感。
- 下一镜的连续性依据是上一条成片的**实际有效尾帧**，不是计划中的理想尾帧。

### 人物调度

- 向镜头靠近通常增强迫近感；横向移动更利于展示人物与环境关系；沿纵深或对角线运动可增加空间深度和能量。
- 正面更直接，四十五度更便于自然表演，侧面更克制，背面更强调行动方向或未知。
- 人物之间的距离、前中后景层级和高低差可以表达关系变化。把变化写成动作，例如“他后退半步，二人之间第一次露出门框”，不要只写“关系疏离”。
- 前中后景可以承载多个事实，但模型无法稳定维持时应拆镜，不能因为理论上能调度就强塞进单次生成。

### 相机运动

相机运动要说明观众的位置怎样变化，并与主体运动分开写：

- 跟随：维持主体关系，同时让环境掠过。
- 推近或拉远：改变信息权重，而不是单纯制造“高级感”。
- 环绕：揭示关系或空间，但要写清方向、幅度和最终落点。
- 手持或轻微晃动：增加现场感或不稳定，只在剧情需要时使用。
- 静止：让表演、构图或突发运动成为重点，也是一种主动选择。

命名技巧必须翻译成可见约束。例如“推拉变焦”应写清主体在画面中的大小基本不变、相机与变焦反向配合、背景透视发生变化；只写术语不能证明模型会正确执行。

## 七、光影和环境必须参与因果

- 记录主光方向、软硬、明暗反差、色温和空间来源；同场连续镜头保持这些事实一致。
- 侧光可加强冲突或暧昧，逆光可分离轮廓，顶光可制造威胁或神秘，柔光与硬光决定质感和阴影边界。它们都是当前剧情里的选择，不是固定情绪按钮。
- 环境不能像静止布景。风、雨、水汽、尘土、车流、布料、头发和阴影只在有物理原因时响应。
- 情绪写成可观察结果：视线停顿、呼吸变化、嘴角受力、手指收紧、汗水、湿发、眼眶变化，而不是只写“悲伤”“震撼”。
- 物理链写成“原因 → 主体反应 → 环境或道具反馈”。这比堆叠“真实、电影感、氛围感”更可验收。

## 八、声音和剪辑也是分镜的一部分

- 对白镜头先朗读或试演，再给时长；逐字台词、说话人、意图、嘴部可见性和听者反应要同时落到时间线。
- 声音至少区分对白、环境声、动作效果和音乐。只写当前镜头确实需要的层，不默认每镜都有音乐。
- 可用画外声或声音先行，在画面揭示前建立因果或期待；必须写清声音来源在画内还是画外。
- 动作效果要与接触点同步，环境声应支持空间而不是掩盖对白。
- 每镜都要有剪辑出口：动作停点、视线方向、声音延续、遮挡点、实际尾帧或下镜要继承的状态。
- 转场只在时间、空间、图形、动作或声音关系成立时使用，不拿特效掩盖接镜问题。

## 九、把决定锁到正确的生产资产

| 要锁定的事实 | 首选载体 | 提示词负责什么 |
| --- | --- | --- |
| 人物身份、当前造型和状态 | 与当前场景完全匹配的人物标准图 | 表演、动作和本镜可见变化 |
| 空间结构、家具、光源与地理方向 | 干净场景图、场景母版 | 环境动态和本镜调度 |
| 关键站位、接触关系、构图和首尾状态 | 单独关键帧 | 两个状态之间的可见过程 |
| 相机路线、动作节拍和声音时间线 | 分镜提示词与节点参数 | 可执行顺序、时长和限制 |
| 下一镜连续性 | 上一条成片的实际有效尾帧 | 只延续确认过的可见状态 |

参考越多不等于越稳定。每镜只接入彼此兼容、职责单一的最小参考集合；身份、造型、空间、光影或道具方向冲突时先停下修正。

## 十、AI 生成的适配边界

- 可以调整：可替代的机位、动作拆分、参考图职责、镜头时长和生成单元。
- 不可以为了模型方便改写：用户决定、角色身份、剧情因果、逐字台词、关键道具归属和已冻结的连续性事实。
- 长镜头、多地点、多人物接触或多次状态变化必须先做代表性试片；“模型支持多镜头”不等于当前输入一次就能稳定完成。
- 试片要实际播放，检查身份、体型、轴线、背景地理、光影、动作因果、声音和剪辑出口。节点装配正确只证明输入写入成功。
- 失败时先判断是事实冲突、参考错位、任务过载还是模型能力边界，再决定局部改写、补关键帧或拆镜，不盲目重试。
- 不使用规避平台审核或安全规则的文字技巧；能力和政策变化按当时真实 schema 与规则重新核对。

## 单镜导演决策卡

交付一镜前，用下面这张卡做最小检查：

1. 主要职责是什么，观众必须读到哪一个变化？
2. 需要多少环境、动作和表情信息，景别是否匹配？
3. 观众站在哪里，角度和构图怎样支持关系？
4. 人物、道具、视线、轴线和移动方向是否明确？
5. 相机为什么动；若不动，重点落在哪里？
6. 光源和环境有哪些真实响应，是否与相邻镜连续？
7. 台词、环境声、效果和音乐各自承担什么？
8. 开始状态、可见节拍、结束状态和剪辑出口是否可验收？
9. 哪些事实已被图片锁定，哪些只由提示词负责？参考之间是否兼容？
10. 若生成失败，最小拆镜点在哪里？
