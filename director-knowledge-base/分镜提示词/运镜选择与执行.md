# 运镜选择与执行

本页用于选择或返修一个具体镜头的运动，把已有导演设计写进 `video-shot-prompt-v2` 的逐镜字段。依据用户提供的九张运镜图解提炼，并校正其中的绝对化口诀；它是通用方法，不是经核实的“诺兰公式”，也没有目标视频模型的效果保证。

## 先决定观众为什么需要这个位置变化

先说明镜头让观众靠近谁、跟随谁、发现什么、等待什么，或感受到怎样的距离和压力。再比较固定构图与移动：表演、遮挡或声音已经足够时，可以固定；需要改变观看关系、持续沉浸或揭示空间时，可以移动。新信息并非必须靠运镜呈现，运镜也可以维持一种有意义的体验，不把“信息不变就不能动”当规则。

在现有导演设计或执行表中，用一句话连起五件事，不另建卡片或评分表：

1. **目的与触发**：在哪个动作、视线、回答或声音之后动，为什么此时动。
2. **起始关系**：相机物理位置、朝向、景别，主体位于哪里；人物运动与相机运动分别是什么。
3. **路径与节奏**：从哪里到哪里、朝哪个方向、相对主体靠近还是保持距离；匀速、渐进还是由冲击触发。
4. **必要稳定项**：本镜需要保留哪些身份、道具、空间和摄影条件，哪些变化恰好是设计目的。
5. **落点与接镜**：结束时观众看见什么，停多久才读得懂，下一镜承接哪条动作、视线或声音。

如果只剩“电影感、紧张、震撼”，继续补可见机制。例如从有环境的中景靠近面部以集中注意力，或者移出柱子遮挡，让原本看不见的入口显露。不要给每镜都加推进，也不要为证明运镜有用而修改剧情。

## 从任务选择运动

下表是候选方案。实际情绪来自剧情、表演、声音和剪辑，不是某个运动名称自动产生的效果。

| 需要观众怎样看 | 候选方式 | 写清的物理关系与落点 | 常见误用 |
| --- | --- | --- | --- |
| 集中注意力、靠近判断或反应 | 推近／拉远（dolly in/out） | 相机相对主体靠近／远离；焦距固定时，主体尺度怎样变化、最终留下多少环境 | 推近静止人物却同时要求固定焦距、固定距离、主体大小完全不变 |
| 持续看清人物行动与沿途障碍 | 平行跟拍（side tracking） | 相机在主体哪侧、运动方向、距离保持还是逐渐变化；前景与背景怎样产生视差 | 只写向右，不区分相机、人物和画面方向；把正常视差当背景漂移 |
| 看见行动中的脸或随人物发现前方 | 前导／后随（leading/following） | 前导时相机在人物前方朝人物并后退；后随时在人物后方朝行进方向前进；终点与停步关系明确 | 只写“向前跟拍”；相机穿过人物或拐弯后无依据换边 |
| 从人物揭示地理，或从环境落到人物 | 升降／航拍（crane/aerial） | 相机高度与观察方向怎样变化，最终揭示哪条路线、距离、障碍或尺度 | 把抬头俯仰当升降；认为升高必然使人物变小；每次开场都用航拍 |
| 随视线转向另一个对象 | 原地摇／俯仰（pan/tilt） | 相机位置不变，朝向水平／垂直转动，明确从哪个对象转到哪个对象 | 用转动朝向冒充横移、升降或穿过遮挡 |
| 揭示人物与另一个人或背景的关系 | 弧线／环绕（arc/orbit） | 起始侧、弧线路径、终止侧、朝向与新背景；需要恒距时才约束半径 | 把 90° 当通用上限；只写顺时针，不交代从哪侧到哪侧；忘记轴线或参考图只支持一侧 |
| 让隐藏信息逐步显露、连接两处空间 | 遮挡揭示／穿门（reveal/through-space） | 谁遮住了什么，相机或遮挡物怎样移动；穿门时门的开合、净空和两侧空间真实成立 | 人物穿门与摄影机穿门混写；从一张静帧臆造门后空间；让摄影机穿过关闭的门 |
| 靠近人物体验，或让冲击被感知 | 轻微手持／受控震动 | 自然扰动还是具体撞击；幅度、疏密、触发及恢复，主体与关键动作仍可读 | 用全程乱抖制造紧张；固定机位无漂移与持续手持同时出现 |
| 有依据地改变平衡感 | 绕光轴旋转（roll） | 旋转对象、轴、方向、幅度和结束倾角；需要时说明何时恢复 | 相机 roll、倾斜构图、旋转布景与重力变化混为一谈 |

极远景是景别，载具是承载方式，都不能单独说明相机怎样运动。变焦改变焦距和视角，不等于相机移动；推拉变焦是有目的的组合，需要相机位移与变焦配合才能让主体尺度近似稳定而背景透视改变。模型是否执行这些差异仍靠实际结果判断，英语术语和具体毫米数不构成能力证明。

## 稳定什么，允许什么改变

锁定与本镜目的相容的必要条件，不能把“脸、衣服、距离、焦距、主体尺度、地平线、全部背景”机械地全锁。

- **推近／拉远**：静止主体与固定焦距下，主体尺度变化是正常结果。需要尺度稳定时，先明确是恒距跟拍、变焦补偿还是其它已设计关系。
- **恒距跟拍**：相机与主体的相对位置应近似稳定，不要求任何曲线路径上的速度数字永远相等。追赶、落后、超越和停步都是可设计的关系变化。滑步要看脚与地面接触、步幅及身体位移，不能仅凭镜头速度下结论。
- **升降／环绕**：高度、观察距离和俯仰共同决定构图。背景应随机位产生合理视差与遮挡变化；不得为了“背景不变”阻止必要揭示，也不能把无依据的建筑变形说成正常视差。
- **手持／冲击**：控制可读性和恢复即可；不为“真实”强造震源，也不将轻微自然扰动一律认定为硬伤。
- **有意 roll**：地平线变化属于设计；普通稳定跟拍才要求它不无故倾斜。相机转动不代表场景或人物的重力方向同时改变。
- **空间边界**：摄影机穿门与人物过门分别写状态链。参考不足时按既有最小参考闸门选择机位、拆镜或必要关系帧；学习运镜不授权补图。

每个摄影镜头默认只保留一个主要运动，帮助分清职责和降低冲突。它不禁止有动机的摇移配合、跟随加轻微手持或已设计的推拉变焦；需要组合时写清谁主导、哪些同时发生、哪些先后发生，复杂到无法读清就按叙事切镜。

这里的“摄影镜头”是一个独立计时的 `镜头N`，不是整个生成单元。继续遵守当前至少两个真实切换镜头的要求，不能把“单一主运镜”误改成整段一镜到底。3—5 秒、90°、35mm、人物占画面 1% 都只能是当前任务的选择或训练示例，不写成通用硬约束。

## 运镜怎样接入剪辑与时间结构

先决定空间、时间与动作关系，再决定方向匹配和速度感。

- 分开描述**世界中的路线**与**画面上的运动方向**。同向运动可帮助跨切衔接，但不能证明两个空间相连、两条时间线同时发生；真实转身、换向或跨轴要有可理解的依据，不为方向统一抹掉剧情转折。
- 区分相机移动速度、主体动作速度、播放速度与切镜频率。节奏升级可以来自其中一项或组合；不能把“更紧张”一律变成快跑、快推、快说或缩短所有镜头。
- 多时间线先绑定各自的时间状态、人物目标和汇合因果，再用动作、视线、尺度或声音作切点。单纯把特写与大全景交替不能证明时空逻辑成立。
- 反向行走、相机后退、画面向左运动与倒放／时间逆转是不同事件。原剧情没有时间逆转时，不为“诺兰感”倒放素材或添加逆向物理。
- 结束构图需要给下一镜真正可继承的状态。模型生成后的连接以已检查结果为准；理想运镜路线不能覆盖实际尾段的错误位置或道具归属。

## 写入 v2，而不是增加一套提示词格式

`相机：`写起始物理侧、视角、景别及有用的焦段；`构图／运镜：`写相机路径、相对主体关系、速度行为、必要稳定项和落点；`画面：`写触发运动的事件、可见行动、对白／声音与反应。创作理由和检查结果放在现有执行资料，模型正文只保留执行需要的事实。

下面是虚构的八秒**结构示例**，不属于任何项目，不具备真实资产引用或生产资格。它只展示“一个主要推进＋一个固定反应镜”，不是承诺八秒适合任何对白，也不能作为完整生产任务直接运行。

```text
【全局美学设定】
画幅：9:16，写实人物场景。
影调：办公室午后柔光，窗光来自画左。
摄影：镜头均在桌子南侧，朝向桌后人物，保持平视。
地点：办公室，林遥坐在桌后中央，周宁坐在林遥画右；开场桌面空置，林遥手持一张无字白色信封。

正文：分镜执行动作
镜头1｜00:00.0—00:04.0｜4秒
相机：桌子南侧平视，林遥中景，固定焦距。
构图／运镜：林遥放下信封后开始平缓推近，至林遥近景停止；林遥在画面中逐渐变大，窗框随接近产生自然透视变化。
画面：林遥把信封平放在桌面中央，松手后抬眼看向画右周宁。相机随这一视线变化靠近林遥，最后停在林遥等待回应的表情上。纸张落桌声后只余室内底噪，无对白。

镜头2｜00:04.0—00:08.0｜4秒
相机：切至桌子南侧正对周宁的平视近景。
构图／运镜：沿林遥看向周宁的视线切到周宁，固定机位；周宁向画左回望，肩部与面部保持可见。
画面：周宁先保持回望，随后缓慢点头，肩部放松，末段停留在周宁缓和的表情。室内底噪跨切延续，无对白。
```

## 在现有通读中检查

核对相机与人物是不是同一套可实现的相对运动，起始侧与终点是否得到当前参考支持，关键动作是否在实际裁切内可见，尺度／地平线的变化是否符合意图，落点能否接下一镜。只修复会破坏剧情、接镜、实际执行或明确硬约束的矛盾；精确角度、理想匀速、轻微漂移等仍按既有 QA 分级处理，不新增评分或自动重跑理由。
