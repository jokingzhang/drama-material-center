# 镜头类型索引

选择标准只有一个：**观众在这个片段里最需要看懂的主要事件是什么。**

## 先判断这一镜为什么存在

| 职责层 | 核心作用 | 常见镜头 |
| --- | --- | --- |
| 叙事主镜 | 交代必须看懂的事件、空间或因果 | 场景建立、人物出场、动作接触、状态变化、道具操作 |
| 关系与情绪镜 | 让态度、权力和情绪变化可见 | 倾听反应、微情绪、距离或视线变化 |
| 呼吸与过渡镜 | 连接时间、地点、动作或声音并调整节奏 | 环境插镜、动作续接、声音先行、短暂留白 |
| 主观与特殊镜 | 把观众放进特定感知，或制造有意异常 | POV、记忆、眩晕、监控视角、时间冻结 |

职责层不是质量或重要性排名。先定职责，再从下表选一个主要镜头类型；完整的景别、角度、构图和调度判断见 [导演设计方法](导演设计方法.md)。

| 镜头类型 | 什么时候用 | 默认需要的图片 | 提示词必须写清 |
| --- | --- | --- | --- |
| 场景建立 | 主要信息是地点、尺度、气氛或环境变化 | 干净场景；必要道具 | 信息出现顺序、空间纵深、环境运动、最后落点 |
| 人物出场 | 主要信息是角色怎样被看见 | 人物标准图、场景 | 入口、揭示顺序、移动路线、观察者反应、终态 |
| 单人表演 | 主要信息由一个人的动作、仪式或情绪承担 | 人物标准图、场景、必要道具 | 表演意图、动作节拍、眼神手势、起止姿势 |
| 双人对白 | 主要信息由说话、倾听和反应传递 | 两人人物标准图、场景；必要声音 | 谁说什么、意图、嘴部是否可见、听者反应、情绪落点 |
| 微情绪反应 | 主要信息是眼神或关系变化 | 人物标准图、触发对象 | 触发、眼神、微动作、呼吸、最终表情 |
| 动作接触 | 主要信息是一次触碰、推拉、扑咬或喜剧因果 | 人物图、场景、关系关键帧 | 谁向谁移动、方向、接触点、反作用、终态 |
| 追逐移动 | 主要信息是路线和追逃关系 | 主体、路线场景、障碍物 | 起点、方向、障碍、相机路线、距离变化、结果 |
| 打斗冲击 | 主要信息是攻防和力量结果 | 战斗者、武器、场景、开场关系 | 武器归属、攻击路径、接触、反击、受力和胜负结果 |
| 状态变化 | 主要信息是从 A 状态变成 B 状态 | 变化前、变化后、场景 | 触发、可见阶段、完成判据、终态停留 |
| 短机制启动 | 主要信息是某个装置由静止变为工作并造成结果 | 同机位前状态、后状态；必要色彩或结构参考 | 启动部位、输出方向、物理结果、镜头反作用 |
| 道具操作 | 主要信息是物件被打开、交换、破坏或使用 | 道具状态、操作者 | 手物关系、操作顺序、特写角度、完成状态 |
| 群体调度 | 主要信息是领头人物和队形变化 | 主角、群演类型、场景、队形关键帧 | 人数、主角唯一性、起止阵型、同步规则、遮挡 |
| 转场与续接 | 主要任务是衔接上一镜或只修一个问题 | 干净连续性帧、失败项相关图片 | 必须保持、只修改什么、起止状态和接镜出口 |
| 蒙太奇 | 多个简单插镜共同表达时间、氛围或主题 | 每个插镜的最小图片 | 每镜一个对象、一个动作、一个信息作用和共同节奏 |

## 怎样消歧

- 有逐字台词且说听关系重要：选“双人对白”，不要归到普通双人互动，并读取 [对白、梗与情绪的分镜写法](对白、梗与情绪的分镜写法.md)。
- 观众必须看清 A 变成 B：选“状态变化”。
- 主要是接触点和接触后果：选“动作接触”。
- 主要是持续路线和追逃距离：选“追逐移动”。
- 主要是攻防与力量胜负：选“打斗冲击”。
- 主要是局部机构启动和一个物理结果：选“短机制启动”，不要扩成整段世界观说明。
- 同一片段有两个以上都必须读清的高风险任务：优先拆镜，不要给它起一个更复杂的名字。
- 只是摄影技巧不同但主要事件相同：仍保留原镜头类型，把技巧写进导演设计，不另造类型名。

## 时长判断

- 4–6 秒：通常只承担一个清楚动作或情绪落点。
- 8–15 秒：通常承担三到五个连续阶段。
- 对白和细腻表演需要给反应留下时间。
- 高速动作可以更短，但复杂因果不能靠增加提示词长度解决。

时长最终以目标模型和节点的真实能力为准；模型未定时只给暂定范围，不伪造精确时间码。
