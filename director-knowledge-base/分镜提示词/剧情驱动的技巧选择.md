# 剧情驱动的技巧选择

这不是技巧清单考试，而是把已经学到的方法用在当前戏里的入口。用户讨论故事和观看感受，AI Director 负责选择并落实手段。来源事实与本地归纳的边界见 [本轮来源校正](../来源/2026-09-21-抖音导演方法整合与来源校正-v01.md)。

## 先确定要拍成什么体验

读完当前剧情，先形成一句有因果的判断：

> 因为本场发生了什么、人物作出什么选择，所以希望观众在何时发现什么，并从什么感受走到什么感受。

剧情已经确定，不再询问人物和事件。真正未定、会改变效果的选择，按 AI Director 的分镜讨论方式一次讨论一个，并给推荐；没有必要让用户挑“微表情、长镜头、黄金开场”等名称。

然后走这条短链：

```text
剧情与人物选择 → 观众的知情顺序、感受 → 可见／可听的机制 → 镜头、提示词与剪辑 → 实际连看连听
```

“角色心软了”不是机制；“收回要递出的钥匙，却把雨伞推过去”才是可拍行动，但也只有当前剧情确有钥匙、雨伞和这个选择时才能使用。方法不能替剧本发明事实。

## 按本场问题选择，不按教程标题选择

以下是候选，不是每场必填的八个维度。相同效果可用不同手段；优先选择当前人物、空间和素材能支持的简单表达。

| 本场需要解决什么 | 可选择的视听机制 | 落到哪里 | 何时不要用／怎样取舍 |
| --- | --- | --- | --- |
| 开头没有让人想继续看 | 已发生的冲突但结果未定；日常中的异常；先给人物局部行动再揭示身份；空间中的反常细节；先给结果留一个待解问题 | 现有开场的观看顺序、首镜主体、声音先入与后续揭示 | 不给普通温情戏强加危险、奇观或谜案；不用无法兑现的钩子冒充剧情。五类思路来自开场教程 |
| 知道发生了什么，却感受不到人物选择 | 给行动前的触发、说话者和听者不同反应；表情与手势、姿态、语气一致或有因地相反；保留情绪余波 | `画面提示词`中的动作、逐字对白与倾听；必要语气放`音效` | 不枚举全部面部肌肉，不让小景别细节与全身动作抢注意力；不靠新增特写凑表演 |
| 关系和权力变化看不出来 | 人物间距离、谁占前景、谁被遮挡、谁让出位置、谁回避或迎上视线 | 调度、构图、机位侧和变化后的终态 | 不把低角度恒等于强者；镜头形式须与人物行动一起成立。既定关系不因教程示例改变 |
| 画面漂亮但重点不清 | 明确谁／哪件物清晰，什么环境必须可辨；前景层次、景别和注意力转移 | `镜头`里的景别、清晰范围、必要焦段／景深意图；素材按实际用途配合 | 不默认背景全糊；剧情依赖后景动作时须保留可读性。24/50/85mm只是作者的创作口诀，不能代替机位与实际画面 |
| 氛围不贴剧情或两镜不像同一场 | 从已建立的窗、门、灯具等光源确定方向、明暗与人物可读性；变化须有剧情或时间依据 | 已有场景参考、全局摘要及必要的逐镜光线变化 | 不叠加互相矛盾的顶光／底光／逆光；不为“高级感”改掉已确定时间、空间或人物肤色 |
| 运镜很忙却没有意义 | 固定等待反应；跟随行动；靠近判断；移出遮挡揭示信息；以距离变化承载关系 | `镜头`的起始位置、物理侧、路径、触发与落点 | 表演足够时可以不动；连续跟随有价值才用长镜头，不为减少节点强行一镜到底 |
| 每个片段成立，接起来却断 | 视线接对象、说话接倾听、动作相位匹配、声音跨切、场景变化处的明确时空线索 | 分镜切点、A出口与B入口、实际剪辑；生成只负责两端所需内容 | 普通切镜已经清楚就不用特殊转场；不能用遮挡、音效或快切掩盖错人、错道具或省掉必要动作 |
| 情绪和声音接不上，或音乐抢戏 | 同一人物声音保持相容；环境底声承接空间；动作音对准接触；音乐跟随剧情变化进入、发展、退出或留白 | `音效`负责本镜声音；后期负责跨片段的音乐与混音 | 不每节点随机配乐，不每切一次换曲；不是所有小角色都要新增永久音色库；声音仍须实际试听 |

## 每个选择要落成什么

在现有分镜的“剧情作用／导演设计”留一句必要理由即可，例如“让观众先察觉关心，人物后发现；先看推伞，再跟视线看湿肩”。不用增加逐镜技巧标签、出处表、评分或固定精彩镜头比例。

正式提示词继续使用同一套 `video-shot-prompt-v2`，不把分析笔记另变成第四个字段：

| 承载位置 | 写什么 |
| --- | --- |
| 总时长与全局摘要 | 当前单元共同的剧情、人物、地点、必要视听条件；总时长按真实表演估计与入口容量安排 |
| 逐项引用 | 已核实素材的主体、当前状态及唯一职责；缺失就标明，不编造输入 |
| `画面提示词` | 谁因为什么做什么、逐字对白、倾听、可见变化及结束状态 |
| `镜头` | 观众从哪里看、看清什么、何时与为何发生视点／焦点／位置变化；连续镜内不另加秒级时间轴 |
| `音效` | 本镜对白归属与必要语气、环境声、动作声和声音状态；不要另造与画面冲突的对白 |
| 现有剪辑备注，不进入模型正文 | 真实切点、声画错位、配乐进出、文字或音效后期消费者与完成状态 |

设计说“听者动摇”，正文就必须给听者可见或可听的改变；设计说“观众暂时不知道”，取景、对白和声音都不能提前泄露。微表情未被景别看见、推近没有落点、音乐未落实到剪辑，都仍只是想法。

## 一个贯穿例子：同一剧情，不同观看选择

虚构教学场景，不属于任何项目，也不是可运行提示词：林遥与周宁在檐下等雨。两人刚争执过；林遥把伞推向周宁，周宁发现林遥肩膀淋湿，把伞移回两人中间。剧情和无对白设定已定。

推荐先让观众读懂林遥的关心，再让周宁发现。这里不需要增加新的秘密或台词：

1. **关系先成立。** 同框让距离、伞的位置和林遥湿肩可见，周宁仍望向檐外。林遥把伞推向周宁后，手回收到身侧，身体仍未靠近。观众先看懂“行动先让步，姿态还克制”，不是装饰性拍手。
2. **发现改变回应。** 周宁先看被推近的伞，再看林遥的湿肩；此时重点是周宁从没有留意到发现关心的反应，不重复展示观众已看清的道具。是否切镜，取决于当前构图能否读清视线和态度变化；不能让关键事实不可见，却要求观众理解照顾。
3. **结束落在共同选择。** 周宁把伞移回两人中间，林遥没有再推开。此处可停留同框，让关系变化成为终态，不必用两个大特写或绕拍证明心动。

声音用同一场雨连接这些视点，伞柄移动给出轻微动作声。是否加音乐，取决于想让“共同撑伞”成为明确温暖落点，还是继续保持未说出口；不是画面一甜就自动上钢琴。

如果用户补充“不要让观众提前看懂，和周宁一起发现”，只调整信息入口：开头不提前暴露湿肩，沿周宁视线揭示，再接推回伞的选择。保留既定事件、人物、雨声和可用素材，不重开整套人设、风格和 Skill 选择。

这个例子组合了信息顺序、关系调度、表演余波、清晰范围、接镜和声音；没有因为学过奇观、低角度、底光、长镜头而全部使用。

## 需要时深入

- 故事没有事件或选择：回到编剧方法，分镜不私自改写已确定剧情。
- 整场信息与覆盖：AI Director 选择叙事分镜 Skill；摄影和关系机制查 [导演设计方法](导演设计方法.md)。
- 表演和潜台词：[对白、梗与情绪的分镜写法](对白、梗与情绪的分镜写法.md)，必要时调用微表情 Skill。
- 相机路径：[运镜选择与执行](运镜选择与执行.md)，确需连续体验才调用长镜头 Skill。
- 声音与音乐：[声音与配乐设计](声音与配乐设计.md)；具体跨场连接需要完整两端设计时再调用转场 Skill。

最终以实际成片能否表达当前目的为准。格式正确、教程有示例、术语写得专业，都不证明目标模型执行成功；尚未拍出的设计不写成已验证的质量提升。
