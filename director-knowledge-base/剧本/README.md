# 剧本知识：从想法到能拍的故事

这里帮助 AI Director 判断输入成熟度，并把它推进到可以规划素材和镜头的状态。

## 先判断用户给了什么

| 输入 | 应该做什么 | 不应该做什么 |
| --- | --- | --- |
| 一句话想法 | 补出类型承诺、人物目标、阻力、赌注和故事推进方式 | 直接跳到几十条分镜提示词 |
| 人物设定或故事梗概 | 补齐人物关系、规则、冲突升级和分集推进 | 擅自改变用户已经明确的核心设定 |
| 未完成剧本 | 找出真正阻碍观看和制作的问题，给出修改方案 | 只做文字润色却不解决因果问题 |
| 完整剧本 | 先确认版本和范围，再进入图片与分镜规划 | 为显示能力而重写已经成立的剧情 |

## 一个故事至少要回答什么

1. 观众为什么愿意继续看：题材承诺、第一钩子和主要爽点或情感期待是什么。
2. 主角想得到什么：目标必须能转化成行动，而不是只有情绪和身份介绍。
3. 谁或什么在阻止主角：对抗力要能持续制造选择和后果。
4. 失败会失去什么：赌注要具体、可见，并会随着剧情升级。
5. 为什么现在必须行动：给出期限、逼迫条件或不可逆事件。
6. 人物关系为什么能持续：双方目标不能完全兼容，对同一事件可以有不同解释。
7. 每一集改变了什么：必须出现新信息、选择、可见后果，并在结尾打开下一步行动。

## 处理关键创作分支

只有会改变故事类型、主角功能、核心关系、结局或资产规模的问题才需要让用户选择。此时提供两到三个真正不同的方案，说明各自效果和代价，并明确推荐一个。

局部台词、连接动作和不改变方向的小修正由 AI Director 直接处理，不把维护工作推给用户。

## 对白不是越短越好

短剧要快的是局面、关系和观众情绪的变化，不是把每个人都写成只说任务口令。关键选择至少要让观众听懂“为什么现在”“为什么找这个人”“不这样做会失去什么”；重要对话要有目标冲突、策略变化、听者反应和场后变化。

只要本轮要创作、改写或诊断场景对白，必须继续读取 [对白、梗与情绪节拍](对白、梗与情绪节拍.md)。单次创作输出上限不够时缩小任务范围，不以删掉动机、情绪和关系轮次来换取格式通过。

## 输出给用户的《故事方案》

- 一句话故事与题材定位。
- 世界或高概念规则。
- 主角、对手及主要关系。
- 故事发动机：目标、阻力、赌注、期限。
- 目标范围内的剧情推进或分集阶梯。
- 需要用户确认的关键决定；没有则明确写“无”。
- 进入图片规划前仍缺少的事实。
