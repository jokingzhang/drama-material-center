# 关系关键帧与连续性帧

## 什么时候需要关系关键帧

按根 `AGENTS.md` 的“视频参考与关键帧决策闸门”，只有精确静态关系是镜头主要失败风险，且文字与现有最小相容参考不足时，才增加一张干净关键帧。下面是候选用途，不是每类镜头的必备补图清单：

- 谁在左、谁在右，谁靠近镜头。
- 两个人怎样拥抱、压制、搀扶或骑乘。
- 手、武器或道具在哪里接触。
- 巨物和人物之间的尺度关系。
- 群体队形、包围关系或复杂遮挡。
- 镜头结束时必须留下的构图。

关键帧主要负责构图和关系，不替代人物标准图中的身份和造型。

普通对话、走路、自然表演和简单左右调度默认不加关系关键帧。把候选图所有可见像素都当作模型可能照收的条件；有重复人物、冲突造型、拼板或文字时先解决输入冲突，不靠“仅参考”标签掩盖。

真实案例中的“猫爪挡脸”说明，复杂接触还要明确动作主体、身体部位、接触对象、准确接触位置、力度和反作用。人物图只能告诉模型“是谁”，不能替代这类接触关系；邻近的手机、手臂等高风险误接对象还要单独排除。

## 关系主镜和可读信息插镜要分责

手机、卡片、文件、工作牌等道具既可能参与人物互动，也可能承担观众必须读懂的信息。不要为了让观众读字，就让关系关键帧里的所有人物把道具正面举向摄影机。那会把正常交流拍成产品展示，也会破坏视线、动作动机和人物关系。

关系关键帧优先锁定故事世界里的自然关系：

- 屏幕朝向正在查看或操作它的角色；卡片可以平放、斜递或朝向接收者。
- 人物看对方、看道具或看动作结果，除非剧情明确要求直视镜头，否则不看摄影机。
- 观众在这张图里要先看懂“谁在核实、谁在交付、谁在隐藏、谁在施压”，不要求同时逐字读清道具正文。
- 道具正反面和持握关系仍需正确，但“文字面朝角色”是正常状态，不是缺陷。

观众必须读清文字时，另做一张正视 clean plate，并在分镜中安排有动机的可读插镜：角色主观、越肩近景、视线落点或动作后的局部特写。常用剪辑顺序是：

1. 互动主镜交代人物关系和操作动作；
2. 沿角色视线切到屏幕或道具插镜，只停留到足以读懂主信息；
3. 切回说话者或听者的反应，让信息产生后果。

插镜期间可以延续现场对白、环境声或动作声。只有画面无法提供必要背景时才补短 OS/VO；能一眼读懂的信息不必再逐字念一遍。关系关键帧与文字 clean plate 可以共同服务同一时刻，但两者分别验收，不能把文字可读性变成关系关键帧的硬门禁。

例如，宾客拍婚礼现场时，群像关系帧应看到手机背面或侧面朝向红毯、宾客探头议论、当事人承受围观；“霍家婚礼，新娘跑了？！”则在单独的手机插镜里清楚出现，再切回当事人的反应。角色把证件展示给另一个角色时，证件应朝接收者；需要读字时使用接收者 POV，而不是让角色越过对方把证件展示给观众。

## 通用硬闸门：道具先在故事世界里成立

关系关键帧的最低要求不是“信息都露出来”，而是画面不能穿帮、不能违反正常使用习惯。交付前必须逐项回答：

1. 如果摄影机不存在，角色仍会这样拿、递、看、放这个道具吗？
2. 道具正面朝向真正的查看者或接收者了吗？人物视线是否落在同一个目标上？
3. 手指、手腕、接触点、重力与支撑面是否合理；道具是否被无缘无故悬空、竖举或正对镜头？
4. 同一人物是否为了让观众看字，同时做出与剧情动机冲突的展示姿势？
5. 如果观众必须读字，是否已经拆出角色 POV、越肩或局部插镜，而不是继续扭曲关系主镜？

任一项答不上来，这张关系关键帧即为 `REPAIR_REQUIRED`，不得进入视频生成。常见错误包括：把作品集举成展板、把停车卡递给角色却让正面朝摄影机、同时把背包拎成商品图、人物看着对方但手中屏幕却朝观众。修复时先恢复自然动作，再用独立 clean plate 和有动机插镜补信息。

## 穿越门、车门和其它空间边界

人物进出门、车辆或电梯时，先冻结摄影机所在侧、边界开合方式、人物起点、操作顺序、跨越路径和完成态。不默认准备两张关系帧。现有参考与正向动作描述足够时直接使用；精确静态关系确实是主要风险时，按当前消费者选择一张必要关系帧，候选职责为：

1. **跨越前关系帧**：门框、门槛或其它边界完整可见；所有人物分处规定的两侧；摄影机所在侧、把手位置、门扇开向和操作手能被读清。
2. **跨越后关系帧**：执行人物的双脚和躯干已经完整进入目标空间；门槛位于身后或侧后方；留下的人仍在规定一侧；下一段对白或动作的站位已经成立。

以上两种职责不要求同时生图。结束状态需要作为下游连续性输入时，优先从已经连续播放通过的结果取真实有效帧，不在生产前用理想尾帧冒充。仅在实时模型 schema 明确支持首尾控制且变化为一个简单可见的 A → B 时，才采用对应首尾输入。

静态帧不携带运动路径、先后、动作归属或准确时长。转换过程复杂时优先拆镜，或采用模型明确支持并已验证的运动／视频参考；不得继续补“手碰把手／一脚跨门槛”的中间静态帧来代替动作链。验收时仍须连续播放并观察接触前、接触、转换中和完成后。

实际尾帧如果没有拍到门、通道或目标空间，只能继承它真实可见的人物姿态、持物、光色和构图，不能凭提示词把它解释成离场路线。反过来，门口关系帧也不能替代人物标准图中的脸、服装和体型。可复用案例见 [门槛进出的双状态关系帧补片](../案例/可复用镜头/门槛进出的双状态关系帧补片.md)。

## 什么时候使用连续性帧

下一镜必须紧接上一镜的站位、动作、光色或道具状态时，从已经验收的视频中选取干净有效帧。

连续性帧必须：

- 对应正确人物、服装、伤情和道具。
- 没有字幕、水印、明显运动模糊或错误画面。
- 能看清下一镜需要继承的起始状态。

正确的静态接触只证明该帧的可见关系，不能保证后续整段持续揽肩、握手或持物。失败片段中的局部帧，只有其动作窗口经连续播放、明确核对并单独限定用途后才可复用；错误尾段仍不得进入下游。反复从正确姿态开始却丢失接触时，应检查动作与镜头职责，不只追加关键帧或重复“始终保持”。参见 [EP05 揽肩反例](../案例/EP05制作复盘-单镜过载与过度返工.md)。

动作换人时，真实帧也要重新检查。上一人签完的纸面帧若带着其手、衣袖或身体，就同时约束了人物；不能只写“参考纸面”便交给下一人签署。先判断能否选到只保留所需道具状态的干净有效裁切；不能分离时，使用与新动作主体相容的参考，由文字或后期层承接纸面状态，不把冲突整帧继续送入。EP06 曾出现交笔后黑袖男方再次写字，后来保留有效交笔并单独处理女方亲签，见 [EP06 连续性与签字复盘](../案例/EP06制作复盘-谈判连续性与生成排障.md)。

如果人物在尾帧里太小、背对镜头或脸部不清楚，仍然要同时使用人物标准图。

## 常见失败

- 把带网格、箭头和说明文字的整张分镜板直接输入视频。
- 用远景尾帧替代人物身份参考。
- 历史尾帧来自另一套造型或另一处场景。
- 关键帧站位正确，但人物、服装或道具事实错误。
- 为了让文字可读，让手机、卡片或工作牌统一正对摄影机，人物也因此看向镜头或形成展示姿势。
- 把正常互动、完整 UI、所有文字和人物反应塞进同一张图，结果关系、信息和情绪都不清楚。
- 用前后静态图要求复杂变化，缺少动作链时继续叠加中间图；应先拆镜或使用经验证的运动／视频控制，并实际播放检查完整过程。
- 连续性帧里根本看不到门或通道，却要求人物沿指定出口离场；或者只有一脚跨门槛，就把它当作完整进出终态。
