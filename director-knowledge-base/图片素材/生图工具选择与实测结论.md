# 生图工具选择与实测结论

2026-09-23，用户认可江砚秋人物对比结论，并在场景、道具与白龙对比后要求将方向固化为项目 Harness。执行时读取仓库 `PRODUCTION_SOP.md` 的 `image-generation-routing` 小节；这里保留选择理由和边界，不维护第二份参数表。

## 两轮实测改变了什么选择

- **人物标准图与多角度头像：优先 Lib Image。** 本轮皮肤、发丝与棉麻细节自然，四视图完整。标准图仍是一人一造型一张，头像组只在有独立用途时追加；不能把这次允许变脸的对比当作跨图身份稳定性证明。
- **电影关键帧：优先 imagegen。** 江砚秋 v02 的肤色、面部阴影与表情更自然。改善来自具体光照关系：脸在屋檐阴影内，右后方阳光勾勒发丝和面颊，庭院反射提供弱补光，脸部亮度低于轮廓高光，Halation 只包裹高光。冷白逆光和光晕仍未完全复现，不宜把“更自然”写成“精确复刻”。v02 是提示词版本，不是模型名；其它镜头要重建自己的光源机制，不能照搬屋檐和庭院。
- **大场景昼景与夜景：优先 Lib Image。** 本轮密集城市的空气透视、铜与瓦的反光更自然；夜景暗部较克制，少量暖窗和冷月光分离清楚。两条路线都演绎了额外建筑细节，并非原参考的几何复刻。
- **精致道具：优先 imagegen。** 皮革黄铜卷轴筒的雕花、三枚蓝灯、卡扣、光圈旋锁与肩带两端连接更清楚。Lib Image 的皮革起伏、金属氧化也自然，但本轮锁具结构较简化。判断精致度需看部件能否合理连接和使用，不只看纹理密度。
- **白龙：优先 Lib Image。** 鳞片和鬃毛层次柔和，四肢可辨，云海干净；imagegen 本轮增加山峰、强日光及更规整华丽的鳞甲。两者仍有奇幻设计感；把该选择用于相近生物是默认取舍，不是对所有生物的实测结论。

## 纯文生没有解决的连续性

两条路线各自的昼夜图虽然共用同一段城市几何描述，仍然改变钟楼、远塔、屋檐与飞艇。世界观和风格相近不证明是同一个可对位布景；其它视角或道具状态的独立文生图也不能据此推定几何一致。

需要严格连续性且允许图像输入时，以确认的母版做受控变化，再核对机位、轮廓、地标和固定物。仍要求纯文生时，尊重零图片输入，交付时如实说明漂移。参考 [场景、道具与状态图](场景道具与状态图.md) 中的空间与状态检查。

## 证据范围与回查位置

人物实验查看了 13 张输出；场景、道具与白龙实验使用四条相同文字提示词分别调用两条路线，共查看 8 张输出。两轮均未把用户图片传给生成模型，也没有验证后续视频效果。原生分辨率、候选数与预算并不完全相同，这些是用户认可的项目选型依据，不是等预算统计榜单；工具更新或新对象出现具体问题时再在授权范围内调整，不默认重做对比。

以下是默认工作区中的研究证据定位，不是可跨项目直接使用的生产引用；实际工作区以配置为准。当前项目若要复用图片，仍须复制、校验并建立自己的绑定。
