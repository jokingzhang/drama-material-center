# 真实案例与可复用做法

这里不是孤立的图片画廊。每个案例都把输入图片、原始提示词和实际结果视频放在一起，先看图片在真实生成中承担了什么职责，再判断这种素材准备方式是否值得复用。

## 从图片角度看什么

1. 每张图究竟锁定身份、当前造型、场景、道具、前后状态还是困难构图。
2. 哪些职责可以合并在一张复合板，哪些必须拆成专项图。
3. 结果视频是否真的使用了图中的脸、服装、轮廓、接触点和状态差异。
4. 哪些图片只是上游母版或色彩参考，不应默认直接接入每个视频节点。
5. 复用案例时需要替换哪些图，以及替换后的图片是否彼此兼容。

下面的案例与“分镜提示词 → LibTV 案例模板”是同一批 Markdown 事实源，只是这里默认突出输入图片。

## 九宫格先检查覆盖，不直接承担生成

九宫格适合在一个场景或一个完整情绪段进入视频生产前，检查是否同时拥有空间全景、人物察觉、方向变化、对手进入、情绪反应、动机或回忆、关系双人、关键接触和离场余韵。每格必须有不同的剪辑职责；九张相似中景不算完成覆盖。

九宫格是 `INTERNAL` 导演预演板，不是人物标准图、场景母版或正式关键帧。拼板会把多个景别、人物状态和地点放进同一张图，容易出现脸、服装、手部、光线和背景互相污染。选中某格后，应按它的职责另做一张无网格、无编号、无说明文字、无水印的干净单帧；不要把整张拼板接入视频节点，也不要直接裁格当正式生成输入。

九宫格是否真的参与生成必须看节点引用和出边，不能只看它出现在画布上。《雨中重逢到告别的分段切镜》里两张 `multi_camera_grid_9` 都没有任何出边，正式视频也没有引用它们；这证明它们只支持人工规划，不证明九宫格能直接提高身份或连续性稳定度。
