# 图片素材知识：先决定做什么图

图片素材的任务是稳定人物、场景、道具、状态和困难构图。不是参考越多越好，而是每张图解决一个明确问题。

## 从剧本列素材

按剧情范围依次寻找：

1. 会反复出现的具名人物及其每套造型或状态。
2. 会反复出现的主要场景。
3. 观众必须看清形状、归属或状态变化的重要道具。
4. 受伤、换装、变身、损坏等前后不同的状态。
5. 拥抱、压制、骑乘、群体队形等普通人物图无法说明的关系关键帧。
6. 需要精确接续上一镜时的干净尾帧。

## 常用图片类型

| 类型 | 解决的问题 |
| --- | --- |
| 人物标准图 | 同一人物在某一套造型或状态下的脸、体型和服装结构 |
| 场景标准图 | 空间布局、材质、入口、纵深、时间和光线 |
| 道具图 | 形状、持握、开合、损坏或剧情状态 |
| 状态图 | 同一人物、怪物或道具在变化前后的明确差异 |
| 关系关键帧 | 站位、视线、尺度、接触点和终态构图 |
| 连续性帧 | 延续上一镜已经成立的站位、动作、光色和状态 |

## 输出给用户的《图片素材清单》

每行只需要说明：

- 图片名称。
- 图片类型。
- 必须出现和禁止出现的内容。
- 对应的造型或状态。
- 用在哪些剧情或镜头。
- 已有、需要生成、需要修复还是需要用户选择。
