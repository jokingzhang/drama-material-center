# 门槛进出的双状态关系帧补片

> 适用于“门外敲门 → 门内人物开门 → 来访者完整跨过门槛 → 双方在室内站稳”，以及其它需要把人物从空间 A 明确送到空间 B 的短过门镜。

- 模型与参数：`Wan 3.0`、`mixed2video`、`9:16`、`720P`、补片 `8 秒`、声音开启
- 证据状态：五张实际输入图均已在生产回合中打开核对；三条对照视频均完成连续播放和动作窗口检查。补片完成全流解码，逐动作确认“敲门、开门、跨门槛、室内站稳”顺序成立，并用于版本化返修装配；声音只完成流与解码检查，未完成主观听辨。补片与装配仍为 `DRAFT / HUMAN_EPISODE_ACCEPTANCE_PENDING`，不是人工成片验收。

## 案例用途

原 22 秒长镜同时承担敲门、开门、进门、催租、递单、回答和离场。实际结果在开门前就把来访者和室内人物生成在同一侧，人物仍继续开门，动作因果穿帮。修复没有把整段继续写长，也没有按每句对白拆碎，而是只拆出一个 8 秒空间状态转换：用开始关系帧锁“门关闭、两人分处内外”，用原片 4.35 秒的真实有效帧锁“来访者已经进入、两人均在室内”，再把生成任务限定为两帧之间的过门动作。

这个方法的核心不是“门口镜头用 8 秒”，而是：**空间归属发生变化时，起点和完成态都要有可见证据；一镜到底不能替代状态锁定。**

## 可复用方法

1. 先用自然语言写状态链，不先写景别或运镜：`门关闭、甲在外乙在内 → 乙开门 → 甲跨门槛 → 甲乙均在内`。
2. 固定摄影机的物理侧，再决定画左画右；同一提示词的总空间说明和时间轴不能切换成相反机位。
3. 为跨越前和跨越后分别准备关系帧。前帧要看见门槛和两侧归属，后帧要看见身体完整跨过、下一段站位成立。
4. 把高风险空间转换拆成短过门镜，把较稳定的室内对白留在原片或下一镜。拆点按状态变化，不按一句话一个镜头。
5. 生成后连续播放整个动作窗口，并检查敲门前、手接触门、门打开、第一只脚跨越、第二只脚跟进和站稳后的密集帧。只有完成态成立，才能使用其尾帧。

## 限制与未知

- 这个案例证明“双状态关系帧 + 短过门镜”在本次 `Wan 3.0 / 8 秒 / 9:16 / 720P` 输入中得到可用技术结果，不证明所有模型、门型、人物数量或时长都能复现。
- 补片视频节点与同排文字节点在 `2026-09-03` 的正文 SHA-256 并不一致：视频为 `f4cc4d…`，文字节点为 `dbb3e2…`。可见结果仍成立，但这不是允许提示词漂移的证据；相反，它要求生产运行前重新做本地稿、文字节点和视频节点三方逐字校验。
- 本案例未主观验收声音内容，也没有把技术通过提升为人工成片验收。
