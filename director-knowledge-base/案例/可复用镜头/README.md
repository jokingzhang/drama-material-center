# 可复用镜头案例

这里保存可以直接看懂效果的完整镜头案例。每个案例必须同时具备：

1. 实际输入图片及每张图的职责；
2. 进入生成链的原始提示词；
3. 对应的实际结果视频；
4. 从结果中能确认的做法、不能确认的边界和替换方法。

七个 LibTV 画布是来源，不等于七个固定模板。一个画布可以拆出多个镜头案例；缺少输入、提示词或结果视频的链路只留在来源档案，不进入这里。

## 使用方法

- 从图片问题进入时，先看每张输入图承担身份、造型、场景、道具、状态还是构图职责。
- 从分镜问题进入时，先看镜头任务、时间结构、动作因果和提示词中的固定骨架。
- 复用时只替换明确标出的角色、场景、道具、台词和风格变量，不盲目复制所有形容词。
- 当前项目事实、已经冻结的资产和目标模型实时限制始终优先。
- 技术生成成功、视频可解码或多时点画面正常，不等于创作者已经选片，也不等于成片通过人工验收。

## 媒体保存

Markdown 保存画布 UUID、node key、原始资源地址和方法结论。能够下载的代表视频另存到本机 `director-knowledge-base/.media/LibTV/`，该目录被 Git 忽略；Web 优先播放本地片段，远程地址用于溯源和缺失时回查。
