# 可复用镜头案例

这里保存可以直接看懂效果的完整镜头案例。每个案例必须同时具备：

1. 实际输入图片及每张图的职责；
2. 进入生成链的原始提示词；
3. 对应的实际结果视频；
4. 从结果中能确认的做法、不能确认的边界和替换方法。

LibTV 画布是来源，不等于固定模板。一个画布可以拆出多个镜头案例；缺少输入、提示词或结果视频的链路只留在来源档案，不进入这里。

## 新增学习案例

- [四人依次入镜到战术集结](四人依次入镜到战术集结.md)：用同一条横移与焦点接力完成四人亮相和集结冲锋，并用同画布其余十一段验证镜头负载、引用污染、声音映射和逐文件水印验收的边界。
- [雨中重逢到告别的分段切镜](雨中重逢到告别的分段切镜.md)：九宫格只做覆盖预演，四个多镜头段落用真实尾段续写并经过候选选片，最终再由后期完成片名、字幕和宏观节奏；同时保留人物标准图污染、角色节点错绑和禁止项冲突等反例。

## 使用方法

- 从图片问题进入时，先看每张输入图承担身份、造型、场景、道具、状态还是构图职责。
- 从分镜问题进入时，先看镜头任务、时间结构、动作因果和提示词中的固定骨架。
- 复用时只替换明确标出的角色、场景、道具、台词和风格变量，不盲目复制所有形容词。
- 当前项目事实、已经冻结的资产和目标模型实时限制始终优先。
- 技术生成成功、视频可解码或多时点画面正常，不等于创作者已经选片，也不等于成片通过人工验收。
