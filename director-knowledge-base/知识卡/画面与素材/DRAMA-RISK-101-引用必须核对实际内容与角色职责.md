# DRAMA-RISK-101｜引用必须核对实际内容与角色职责

## 问题

为什么节点名正确、连线齐全、接口成功，仍可能从根上装错素材？

## 银幕事实

《山海驯兽师》“雪女出场关键帧”实际是空城市；《今天不宜约会》候选把男性家属写成护士、女性手术服角色写成丈夫；《万物生变》描述蛇的提示词错误引用人物节点。

## 机制

分析判断：名称、prompt 占位符和边只证明标识被使用，不证明标识对应的实际像素、角色和状态正确。错误映射会在生成前就把事实合同破坏。

## 适用条件

- 所有使用外部画布、历史资产、同名节点或自动装配的任务。
- 人物、服装、道具或状态有多个近似版本。
- 节点名可能由历史操作遗留。

## 不适用条件

- 没有任何外部引用的纯文本规划；但生成前仍需重新核对实际资产。

## AI 制作转译

先读取 node key 和原图，建立 `expected responsibility → asset ID → actual content` 对照；再核对 prompt 引用、媒体列表顺序和实际入边。名称不唯一或内容不符时停止。

## 验收

每个可见人物、道具、场景和状态都能由实际查看的唯一资产承担；Node key、显示名、prompt 语义、媒体列表与入边一致；不存在同名歧义。

## 失败信号

- 只看节点名或上游生图 prompt，不看产物。
- 女性角色板被当成丈夫或男性板被当成护士。
- prompt 声明的参考职责与媒体顺序不同。
- 错误映射直到视频结果才被发现。
