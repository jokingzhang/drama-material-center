# 抖音方法蒸馏工作区

这个目录用于维护“已点赞且属于目标作者”的视频清单、单条视频处理 SOP 和可重复执行脚本。它不属于任何短剧项目素材，也不进入 `workspace/` 的故事索引。

- `queue.json`：唯一任务清单；以 `videoId` 去重并记录处理阶段。
- `SOP.md`：从浏览器下载、分轨合并、转写、证据校正到方法蒸馏的操作约定。
- `scripts/process-video.mjs`：处理一条已经下载到本机的视频；不接管登录态，也不抓取抖音页面。
- `../.local/douyin-method-distillation/`：原视频、音轨、转写和逐条蒸馏结果。该目录被 Git 忽略。

当前范围固定为：2026-09-21 在登录账号“喜欢”页中可见、作者标记为“李一帆”的 29 条视频。后续轮询只增量加入新出现的匹配视频，不自动纳入作者合集中的未点赞内容。

**2026-09-21 校正：** 旧详细稿曾由固定内容批量写入“已复核”，发现公式归属和示例混写问题；相关 25 条回到 `transcribed`，媒体、转写和旧笔记均保留，待逐条来源复核。不能把 29 条归档说成 29 条方法全部验证。当前采纳范围见 [来源校正](../../director-knowledge-base/来源/2026-09-21-抖音导演方法整合与来源校正-v01.md)，实际制作通过 [剧情驱动的技巧选择](../../director-knowledge-base/分镜提示词/剧情驱动的技巧选择.md) 按需调用。两个历史批量创作写入脚本均已停用。

状态按以下顺序推进：

```text
queued -> downloaded -> media_ready -> transcribed -> distilled
```

遇到分轨缺失、转写异常或证据不足时使用 `blocked`，并在 `status.note` 写清原因。只有生成了 `method-notes.md` 且完成证据校正，才可以标记为 `distilled`。
